# 부모 표면을 따르는 목 윤곽

평면 목 윤곽이 기존 부모 프로파일 내부에 놓이는 경우를 위해 별도 `surface-neck-proposal/1` 후보를 생성한다. 기존 평면 설계·부모 형상·허용오차를 수정하지 않는다.

`propose_surface_neck`는 기존 타원의 각 점에서 지정된 normal 방향의 ray를 만들고, 부모 반경 프로파일의 안쪽에서 바깥쪽으로 넘어가는 표면 교차를 찾는다. 명시한 탐색 범위 양 끝의 부호와 표본 교차 수를 검사하고, 한 교차 구간만 이분법으로 정밀화한다. 여러 교차·미포함·비유한 값·과도한 표본 요청은 거부한다. 64개 윤곽 표본의 검사는 연속 표면이나 내강 topology의 증명이 아니다.

출력은 원본 revision·평면 명세 hash·좌표계·ray 설정·3D 윤곽·normal 이동량·투영 폭/깊이·표면 방정식 잔차를 포함한다. 투영 2×1 mm를 유지하는 비평면 윤곽이며, 평면 목의 3D 치수나 같은 병변 정의로 자동 대체하지 않는다.

## 실제 양측 MCA

전체 원본 snapshot의 기존 우측/좌측 설계를 사용했다. 탐색 범위 ±1 mm, ray 간격 0.05 mm를 사전에 지정했다.

| 경로 | normal 이동 범위 mm | 투영 폭×깊이 mm | 표면 방정식 최대 절대 잔차 mm |
|---|---|---|---|
| FJ1692:e0 | −0.264727 ~ +0.406883 | 2×1 | 1.74e−13 |
| FJ1692M:e0 | −0.162683 ~ +0.466725 | 2×1 | 2.65e−14 이하 |

두 윤곽 모두 CANDIDATE다. 잔차는 파생 프로파일과의 수치 일치이며 원본 mesh·해부학적 정확도 오차가 아니다. 저장된 이동량 그림을 열람했으며, 좌측 일부 구간에는 기울기 변화가 남는다. 이 윤곽만으로 매끄러운 접합을 주장하지 않는다.

검사: 원통 해석해와 대조, 굽은 부모의 양방향 이동, 원본 보존, bracket 부족·다중 교차 거부 및 프레임/명세 회귀 **30 passed, 1.20초**.

재현: `PYTHONPATH=src python scripts/inspect_surface_neck.py`. [실행 근거](evidence/surface-neck-inspection.json), 로컬 그림 `exports/surface-neck/offsets.png`.

다음 단계는 비평면 윤곽과 주머니 사이의 연결 표면 생성, 목 정의에 맞춘 치수 측정, 열린 내강·접합 매끄러움·충돌 검사다. 완성 병변 표면·마스크·앱 적용은 NOT RUN이다.
