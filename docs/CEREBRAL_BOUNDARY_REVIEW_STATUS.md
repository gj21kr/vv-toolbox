# 뇌혈관 12개 경계군 검사 현황

검사일: 2026-10-20. 원본: BodyParts3D 4.0. 좌표: native LPS, mm.

## 12개 경계 재대조: 그림과 연결 증거

ACA와 MCA를 분리해 문서·JSON·로컬 그림을 읽기 전용으로 재검토했다. ACA 그림 2개와 MCA 좌우 각 4개 sheet를 열람했다. Docker의 통합 근거 검사와 주석 회귀 검사도 다시 실행했으며 **12개 경계 ID·그림 10개 무결성 PASS, 32 tests PASS**였다. 새로운 정확한 경계 승인 근거는 확보하지 못해 **0/12, UNKNOWN**을 유지한다.

이번 대조에서 확인한 적용 제한:

- ACA의 계단 형태 파생 polyline에서 얻은 위치 안정성은 해부학적 위치나 절단 평면 법선의 정확성을 보증하지 않는다. 뇌량 단면 위의 혈관 Y/Z 투영을 혈관 자체의 단면 교차로 해석하지 않는다.
- MCA sheet의 개별 source part와 배경 M1 표시만으로 여러 part를 잇는 연속 daughter 경로가 입증되지는 않는다. 먼저 part 간 연결을 확인한 뒤 해당 경로에서 경계를 표시해야 한다.
- FJ1660/M과 FJ1694/M의 굴곡 탐색점은 서로 다른 경로의 점이다. 하나의 공통 genu로 합치지 않는다.
- FJ1670/M·FJ1673/M처럼 짧은 원위 조각에서 근위 경계 통과를 추정하지 않는다. FJ1662/M의 여러 skeleton edge를 같은 수의 cortical daughter로 세지 않는다.

다음 판독은 아래 12행의 입력을 기준으로 진행한다. ACA A1/A2는 양측 접합부의 열린 내강·ostium, 나머지 ACA 네 경계는 전환 영역 내 명시적 운영 절단 규칙, MCA 여섯 경계군은 연속 분지 경로와 해당 지형 표지를 함께 확보해야 한다. 운영 규칙으로 정한 좌표는 합성 출처로 저장하며 해부학적 정답과 구별한다. 원본 형상·앱 주석·확정 라벨은 변경하지 않았다.

기존 문헌 링크 두 개의 온라인 재열람은 접근 확인 화면으로 본문을 확보하지 못했다. 이번 판정은 보관된 근거와 로컬 형상 그림의 재대조이며, 새로운 문헌 검증이나 독립 임상 판독 완료가 아니다.

- [ACA 추가 검사](ACA_BOUNDARY_FOLLOWUP.md), [MCA 추가 검사](MCA_BOUNDARY_FOLLOWUP.md).
- [통합 근거 검사](evidence/boundary-followup-verification.json): 정확히 12개 unique 경계 ID, 원본 ZIP·중심선 fingerprint, 보고서 2개와 그림 10개 SHA-256 대조 **PASS**. 해부학적 정확성 검사가 아니다.
- `scripts/verify_boundary_followup.py`를 Docker에서 실행했다. 주석·구간 분할의 기존 회귀 검사 `test_atlas_annotations.py`, `test_segment_materialization.py`는 **32 passed**. 이는 후보가 확정 주석으로 잘못 적용되지 않도록 하는 코드 검사다.
- 원본 형상, 앱의 확정 구간 라벨, 기존 주석은 변경하지 않았다. 판독 결과의 저장과 앱 적용은 구분한다.

## 근거와 제한

- [ACA 상세 검사](ACA_BOUNDARY_REVIEW.md): 실제 뇌량 sagittal 단면, oblique 3D, ACom axial 단면. 4개 검토 영역의 bounds와 중심선 표본 index를 [JSON](evidence/aca-boundary-review.json)에 기록했다.
- [MCA 상세 검사](MCA_BOUNDARY_REVIEW.md): 원본 60개 형상, 혈관 46개 요소, 파생 중심선 120개 edge. 주변 operculum을 덮는 gyri는 존재한다. [JSON](evidence/mca-boundary-review.json)에 원자료 해시·분지별 대응·탐색점을 기록했다.
- 파생 skeleton edge 수는 실제 해부학적 분지 수가 아니다. 좌우 형상 유사성은 독립 표본 검증이 아니다.
- ACA `landmark_reviewed`는 `localization_scope=region_only`, `position=null`과 함께 해석한다. 이를 점 경계 주석이나 확정 구간 마스크로 자동 변환하지 않는다.
- 원본 형상과 기존 앱 초안을 변경하지 않았다. 합성 보충과 운영 절단면은 별도 출처를 가진 단계로 구현한다.
