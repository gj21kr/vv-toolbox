# VV Toolbox 개발계획서

| 항목 | 내용 |
|---|---|
| 프로젝트 | Virtual Vessel Toolbox (VV Toolbox) |
| 문서 버전 | 0.1 |
| 작성일 | 2026-10-20 |
| 개발 대상 | 해부학적 Atlas 편집기 및 혈관 변이·질환 합성 데이터 생성 도구 |
| 실행 환경 | 로컬 PC 웹 애플리케이션 및 일괄 생성 명령어 |

## 1. 프로젝트 목적

VV Toolbox는 대퇴동맥에서 뇌혈관까지의 해부학적 구조와 연결 관계를 확인하고, 개별 혈관의 형상과 문헌 기반 변이를 편집하며, 협착·동맥류가 포함된 3D 합성 데이터를 생성하는 연구용 도구다.

혈관·질환 분할과 중심선·연결 그래프 추출에 활용할 수 있도록 형상, 중심선, 연결 그래프, 질환 및 혈관 구간 라벨, 3D 마스크를 일관된 좌표계로 제공한다. 데이터의 출처와 생성 조건을 추적하고, 동일 조건에서 결과를 재현할 수 있어야 한다.

## 2. 제품 범위

### 2.1 해부학적 범위

- 좌우 대퇴동맥 접근과 좌우 경동맥 경로의 네 조합을 지원한다.
- 대퇴–장골–대동맥–대동맥궁–경동맥–뇌혈관 경로를 포함한다.
- 뇌혈관은 좌우 ACA A1–A3, MCA M1–M3를 포함한다.
- 대상 경로의 주요 분지와 접합부를 함께 표현한다.
- 첫 버전은 동맥계를 대상으로 한다.

경로 검사는 지정한 시작점에서 종점까지의 그래프 연결을 확인한다. 카테터의 물리적 통과 가능성이나 혈류 해석은 별도의 기능으로 취급한다.

### 2.2 편집 및 생성 범위

| 기능 | 범위 |
|---|---|
| 혈관 형상 편집 | 반경, 굴곡, 공간적 비틀림, 분지 각도 등 |
| 해부학적 변이 | 문헌 기반 대동맥궁 및 ACA/MCA 분지 변이 프리셋 |
| 연결 관계 변경 | 지정된 프리셋에 따른 변경 |
| 질환 생성 | 전체 대상 동맥의 협착과 동맥류 |
| 분기점 병변 | 분기부 동맥류 및 분지 입구 협착 |
| 다중 병변 | 사례별 여러 병변, 개수·위치 제한 및 최소 간격 적용 |
| 생성 방식 | 수동 편집 및 일괄 생성 |

병변끼리의 겹침은 허용하지 않는다. 각 질환의 형상과 파라미터 허용 범위는 혈관 부위별로 정의한다.

### 2.3 제외 범위

첫 버전에는 정맥·문맥, 척추–기저동맥 및 PCA 접근 경로, 자유로운 연결 그래프 편집, 가상 X-ray/DSA 영상 생성, 다중 사용자 서버, 학습 모델 구현 및 성능 평가를 포함하지 않는다. CFD, 카테터 접촉역학, 환자별 진단 및 임상적 유효성 검증도 개발 범위에 포함하지 않는다.

## 3. 사용자 작업 흐름

앱은 영어와 한국어를 지원한다. 화면 오른쪽 상단의 언어 전환 버튼으로 변경하며, 선택은 새로고침과 화면 이동 후에도 유지한다. 언어 변경은 혈관 형상, 그래프, 사례 파일, 검사 판정 및 원본 식별자를 변경하지 않는다. 메뉴·설명·입력 안내·검사 진행 및 오류 메시지를 두 언어로 제공한다.

1. 기준 해부 모델을 불러오고 혈관명·좌우·구간으로 검색한다.
2. 혈관을 선택해 양 끝과 중간 분기, 연결 근거 및 3D 위치를 확인한다.
3. 형상 파라미터 또는 해부학적 변이 프리셋을 지정한다.
4. 협착·동맥류의 위치, 개수 및 형상 조건을 설정한다.
5. 연결·형상·병변·라벨 검사를 실행하고 결과를 확인한다.
6. 수정 사항을 되돌리거나 설정과 결과를 저장한다.
7. 일괄 생성 조건과 목표 사례 수를 지정하고 통과 데이터와 실패 기록을 확인한다.

## 4. 자료 및 기준 모델

### 4.1 자료 선정

공개 Atlas와 이용 가능한 공개 CTA/MRA·혈관 모델을 활용한다. 각 자료의 해부학적 범위, 주석 수준, 좌표·단위, 결손, 라이선스, 표본 및 독립 검증 가능성을 비교해 기준 자료를 선정한다.

자료마다 출처, 버전, 파일 해시, 이용조건 및 표본 식별 정보를 기록한다. 서로 다른 표본을 결합한 형상은 합성 구성임을 명시한다.

### 4.2 기준 모델과 합성 모델

| 모델 | 목적 | 관리 원칙 |
|---|---|---|
| 기준 모델 | 구조 열람, 관계 검토 및 편집 기준 | 원본 형상·명칭·출처와 연결 근거 보존 |
| 합성 모델 | 형상 변이, 결손 보충 및 질환 생성 | 기준 모델 참조, 생성 규칙, 변경 범위와 이력 기록 |

원본에 결손이 있는 구간은 별도 합성 모델에서 보충한다. 원본 구간, 생성 구간 및 미확인 구간을 구분해 표시하고 출력한다.

기준 모델 하나에서 편집–생성–품질 검증–출력을 완성한 뒤 여러 기준 모델로 확장한다.

### 4.3 연결 관계의 근거

문헌과 독립 영상·모델의 대조가 일치하면 해당 검토 범위에 대해 ‘근거 대조 확인’으로 판정한다. 사용한 자료, 관계, 위치 및 검토 이력을 기록한다.

다른 표본의 자료는 일반적인 관계의 타당성 근거로 사용한다. 특정 표본의 접합 위치 확인과 구분하며, 이 판정을 임상 검증으로 표시하지 않는다. 전문가 검토는 첫 버전의 필수 완료 조건으로 요구하지 않는다.

## 5. 데이터 설계 원칙

| 데이터 | 필수 내용 |
|---|---|
| 혈관 | 고유 ID, 해부학적 명칭, 좌우, 구간, 원본 구조 대응 |
| 접합점 | 참여 혈관 구간, 부착 위치, 분기·합류·문합 유형 |
| 연결 근거 | 출처, 검토 범위, 판정, 미확인 사유 |
| 형상 | 표면, 중심선, 반경, 좌표계, 단위, 원본 및 파생 버전 |
| 접근 경로 | 시작점, 종점, 통과 구간과 검사 결과 |
| 병변 | 유형, 위치, 영향 구간, 형상 파라미터, 병변 ID |
| 생성 설정 | 기준 모델, 프리셋, 분포, 파라미터, seed, 생성기 버전 |
| 출력 사례 | 형상·라벨 파일, 좌표 대응, 품질 결과 및 데이터 세트 소속 |

혈관의 양 끝 연결과 중간 분기를 실제 부착 위치에 따라 표현한다. 해부학적 말단, 원본 파일 경계, 자료 결손, 추출 실패와 미확인 연결을 서로 다른 상태로 관리한다.

개념 분류 관계와 실제 혈관 연결 관계를 구분한다. 거리·표면 접촉·체적 겹침은 연결 검토의 증거로 사용하되 단독으로 연결을 확정하지 않는다. 후보 데이터의 보관과 화면 표시 개수 제한은 분리한다.

ACA A1–A3와 MCA M1–M3의 구간 경계는 해부학적 기준으로 정의한다. 연결 그래프, 혈류 방향 및 접근 경로는 별도 데이터로 관리한다.

## 7. 합성 데이터 생성

### 7.1 파라미터 추출

문헌·측정 자료에 근거한 통계 분포와 파라미터 간 상관관계를 적용한다. 근거가 부족한 파라미터는 출처가 기록된 기준값으로 고정한다. 기준값도 확보되지 않은 항목은 미지원으로 명시한다.

혈관 부위, 분지 구조 및 질환 유형에 따른 조건을 함께 검사한다. 파라미터와 허용오차는 검증 전에 정의한다.

### 7.2 사례 생성 및 실패 관리

목표 개수는 품질 검사를 통과한 사례 수로 센다. 최대 시도 횟수에 도달하면 종료하고 부족한 개수와 실패 내역을 보고한다.

실패 모델은 정상 데이터에서 제외하며 실패 원인, 설정, seed를 별도 보관한다. 시도·탈락·통과 내역과 최종 파라미터 분포를 기록해 품질 필터에 따른 분포 변화를 확인할 수 있게 한다.

### 7.3 출력 구성

- 3D 혈관 형상 및 중심선.
- 혈관 구간·접합점·연결 근거를 포함한 그래프.
- 혈관/배경, 좌우 혈관 구간 및 질환 영역 라벨.
- 전체 대상 동맥의 3D 마스크 볼륨.
- 병변 주변 고해상도 마스크 볼륨과 전체 좌표계로의 변환 정보.
- 기준 모델, 생성 설정, 출처, seed, 생성기 버전 및 품질 검사 결과.

혈관 구간 라벨과 질환 라벨은 함께 표현할 수 있도록 설계한다. 병변마다 식별 정보를 유지하며, 실제 저장 형식과 해상도는 출력 계약에서 정의한다.

### 7.4 데이터 세트 분리

기준 해부 모델 단위로 학습·검증·시험 세트를 나눈다. 같은 원본에서 파생된 형상 변형, 병변 사례 및 고해상도 부분 볼륨은 모두 같은 세트에 속한다.

기준 모델 하나로 개발하는 단계에서는 독립적인 학습·검증·시험 세트를 제공한다고 표시하지 않는다. 본 프로젝트의 범위는 데이터 생성과 품질 검증이며 모델 학습·성능 평가는 포함하지 않는다.

## 8. 검증 계획

| 검증 영역 | 검사 항목 | 완료 조건 |
|---|---|---|
| 출처 | 구조 대응, 원본 해시, 좌표·단위, 결손 및 이용조건 | 대상 자료의 추적 정보 확보 |
| 해부학적 관계 | 필수 연결 목록, 문헌·독립 자료 대조, 위치 근거 | 검토 범위별 판정과 근거 기록 |
| 그래프 | 양 끝 및 중간 연결, 경로 도달, 누락·잘못된 연결 | 명세와 일치하고 미확인 상태가 보존됨 |
| 형상 | 접합 연속성, 접합부 매끄러움, 비접합 혈관 관통, 중심선·반경·표면 일치 | 사전에 정의한 허용오차 충족 |
| 병변 | 위치·유형·치수·영향 범위, 분기부 조건, 병변 간 간격 | 의도한 질환 조건 및 보존 조건 충족 |
| 라벨 | 혈관 구간·질환·배경, 볼륨 좌표, 해상도 간 대응 | 형상 및 생성 설정과 일치 |
| 편집 | 선택·변경·검사·복원·저장·재로드 | 동일 사례의 전체 작업 흐름 확인 |
| 재현성 | 설정·seed·버전과 결과 대응 | 명시한 실행 조건 및 허용오차에서 재현 |
| 일괄 생성 | 목표 수, 시도 상한, 실패 분리, 분포 기록 | 정상 데이터와 실패 기록의 완전성 확인 |

판정은 `PASS`, `FAIL`, `NOT RUN`, `UNKNOWN`으로 기록하며 대상과 검사 범위를 명시한다. 미확인 연결이 남은 경로는 해부학적 기준 경로의 완료로 판정하지 않는다. 합성으로 보충한 경로는 합성 모델의 검사 결과로 별도 보고한다.

프로그램 검사, 생성 규칙에 따른 라벨 일관성, 해부학적 근거 대조, 임상적 유효성을 서로 다른 검증 대상으로 관리한다.

## 9. 개발 단계와 산출물

| 단계 | 개발 내용 | 산출물 | 진입·완료 기준 |
|---|---|---|---|
| M1 | 범위 명세 및 자료 조사 | 필수 혈관·구간 목록, 자료 비교표, 문헌 프리셋 목록 | 범위와 자료별 가용성·결손·이용조건 정의 |
| M2 | 기준 모델 및 데이터 설계 | 기준 자료, 연결 근거 모델, 그래프·형상·라벨 계약 | ID·좌표·구간 경계·관계 상태와 결손 처리 정의 |
| M3 | 기준 접근 경로 구성 | 네 접근 조합, ACA/MCA 모델, 연결·형상 검사 결과 | 근거 확인 구간과 합성 구간을 구분한 기준 버전 확보 |
| M4 | Atlas 편집기 | 검색·선택·관계 표시·형상 수정·복원·저장 기능 | 실제 브라우저에서 전체 편집 흐름과 검사 동작 확인 |
| M5 | 변이 및 질환 생성 | 분지 프리셋, 협착·동맥류, 분기부·다중 병변 | 개별 생성 규칙과 조합 조건 검증 |
| M6 | 일괄 생성 및 출력 | 생성 명령어, 마스크·그래프·라벨, 실패 보고서 | 단일 기준 모델에서 전체 생성·검사·출력 과정 완료 |
| M7 | 다중 기준 모델 지원 | 기준 모델 관리와 세트 분리 | 서로 다른 원본의 독립 관리 및 파생물 분리 확인 |

개발은 고정 기한 대신 검증 단계의 통과를 기준으로 진행한다. 개별 기능과 단일 변화부터 검사하고 분기부 병변, 다중 병변 및 일괄 생성으로 확장한다. 첫 버전의 기능 완료는 M1–M6의 요구사항 충족으로 판단하며, 다중 기준 모델과 독립 세트 분리는 M7에서 별도로 확인한다.

## 10. 상세 설계 항목

다음 항목은 자료 조사와 설계 단계에서 명세한다.

1. 기준 Atlas 및 독립 대조 자료의 선정과 이용조건.
2. 필수 혈관 목록, ACA/MCA 구간 경계 및 접합점 주석 기준.
3. 문헌 기반 변이 프리셋과 지원 가능한 파라미터 분포·상관관계.
4. 부위별 협착·동맥류 모델, 분기부 보존 조건 및 병변 최소 간격.
5. 전체·부분 볼륨 해상도, 출력 형식 및 좌표·라벨 계약.
6. 기하 검사와 재현성 허용오차, 실행 자원 및 최대 시도 횟수.

각 설계 결정은 관련 요구사항, 근거와 검증 방법을 함께 기록한다. 개발계획서와 상세 명세는 저장소에서 버전 관리한다.
