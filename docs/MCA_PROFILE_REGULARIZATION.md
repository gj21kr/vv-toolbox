# MCA 병변 모혈관의 중심선·반경 평활화

브라우저에서 보이는 표면의 반복 굴곡을 조사하기 위해 우측 MCA `FJ1692:e0`의 파생 중심선과 반경을 별도 합성 사례에서 평활화했다. 원본 Atlas의 정확한 표면 복원이나 임상 오차 허용 판정은 아니다.

실행 전에 공학적 설정을 고정했다: Gaussian sigma 0.6 mm, 재표본 간격 0.1 mm, 중심선 최대 이동 한도 0.3 mm, 반경 최대 변경 한도 0.3 mm. 기존 중심선의 첫 두 점·마지막 두 점과 끝점 반경을 보존한다. 다른 1,080개 경로와 모든 node가 변하지 않았음을 비교했다.

| 측정 | 이전 | 이후 |
|---|---:|---:|
| 중심선 길이 | 36.397660 mm | 33.776223 mm |
| 연속 chord 사이 굴절각 95백분위 | 60.000° | 24.873° |
| 반경 총변동량 | 6.442738 mm | 1.927536 mm |
| 반경 범위 | 1.358774–1.811698 mm | 1.402641–1.688933 mm |

최대 중심선 이동 0.199589 mm, 최대 반경 변경 0.175631 mm. 길이 감소 2.621437 mm는 실제 변형 결과이며 단순 표시 변경이 아니다. 굴절각은 곡률이 아니고 표본 간격에 영향을 받는다. 반경 총변동량도 임상적 매끄러움 수용 지표가 아니다.

기존 병변 사양과 neck 좌표는 원래 사례 revision에 속한다. 새로운 기준에서는 station·법선·neck attachment와 병변을 다시 생성하고, 치수·접합부·주변 혈관 충돌을 검사해야 한다. 현재 데모 후보는 변경하지 않았다.

- 새 사례: `exports/mca-profile-regularization/case.snapshot.json`
- [측정·출처 기록](evidence/mca-profile-regularization.json)
- 재현: Docker에서 `PYTHONPATH=src python scripts/inspect_mca_profile_regularization.py`
- 기존 평활화 연산자 회귀 검사: **23 passed**.

원본 입력의 바이트 불변은 확인했다. 새 모혈관의 표면 재생성, 병변 재생성, 해부학적 승인 및 충돌 검사는 미완료다.

## 새 기준에서의 병변 표면 생성

후속 실행에서 기존 중심선의 interval index와 보간 비율을 유지한 위치로 병변을 옮겼다. 기존 법선을 참조 방향으로 투영해 새 프레임·neck 중심·접합 곡선을 계산하고, 목 2×1 mm·돔 4×3×5 mm의 설계 입력은 유지했다. 이는 동일한 해부학적 배치의 입증이 아니다.

0.15 mm 격자에서 폐곡면을 생성한 뒤, 최대 변위 0.15 mm·체적 변화 2% 한도의 기존 평활화를 적용했다. 결과는 정점 26,566개·삼각형 53,128개이며 실제 평활화 최대 이동 0.074050 mm였다. 단일 폐곡면 및 표본 내강 연결 검사는 통과했다. 새 사례 바이트 불변을 확인했다.

주변 1,080개 경로 검사 결과는 분리 1,074개, 프로파일 내부 증거 5개, 미확인 1개다. 미확인 `FJ1662:e12`는 거리 하한 -0.024467 mm이며 255개 내부 표본에서 겹침 증거를 찾지 못했으나, 분리로 승인하지 않는다. 이전 후보의 분리 1,075개보다 검토 항목이 늘었으므로 전체 품질 개선이나 충돌 해소로 표시하지 않는다.

`exports/regularized-mca-sac/comparison.png`에 두 실제 삼각형 표면을 같은 평면으로 자른 결과를 저장했다. 일부 모혈관 굴곡이 감소했지만 목의 방향·돔 위치도 달라졌다. 한 단면은 전체 표면 매끄러움이나 neck 치수 승인을 대신하지 않는다. 현재 데모 후보는 유지한다.

## 미확인 경로의 삼각형 세분화 검사

`FJ1662:e12`에 대해 후보의 모든 53,128개 삼각형을 대상으로 거리 하한 검사를 실시했다. 최초 하한으로 분리를 입증하지 못한 부분만 최대 깊이 8·총 검사 cell 100,000개 한도에서 네 부분으로 나눴다. 모든 leaf의 양의 거리 하한이 확보될 때만 `SEPARATED_PROFILE`을 반환하고, 깊이·개수 한도에 걸린 부분은 `UNKNOWN`으로 남긴다.

실제 결과는 **53,140개 cell 검사, 미해결 0개, 최소 거리 하한 0.002353 mm**로 프로파일과의 분리가 입증됐다. 이는 매우 작은 기하학적 하한이며 임상 안전 간격이나 원본 Atlas 표면 사이 간격을 의미하지 않는다. 다른 5개 경로의 겹침 증거는 그대로 남아 전체 후보는 여전히 검토 대상이다.

관련 검사 **14 passed**. 표본에서 교차를 찾지 못한 경우를 통과시키는 대신, 삼각형 전체를 덮는 거리 하한을 사용한다. 검사 cell 한도를 1로 제한하면 `UNKNOWN`을 유지하는 회귀 검사를 포함한다.

## 목 설계 곡선의 실제 표면 대응

재생성 시 저장한 비평면 접합 곡선의 125개 점을 최종 삼각형 표면의 최근접점과 대응했다. 기존 후보 검사와 같은 거리 한도 0.30 mm를 사용했다.

| 측정 | 결과 |
|---|---:|
| 표본 최대 표면 거리 | 0.168440 mm |
| 표본 평균 표면 거리 | 0.099538 mm |
| 설계 곡선의 투영 폭·깊이 | 2.000000 × 1.000000 mm |
| 최근접 표면점 집합의 투영 폭·깊이 | 2.095538 × 1.316652 mm |
| 투영 폭·깊이 변화 | +0.095538 × +0.316652 mm |

표본 거리 조건은 `PASS`지만 깊이 방향 span이 약 31.7% 커졌다. 최근접점 집합이 실제 목 경계라는 보장은 없으므로 이 값을 실제 neck 깊이로 확정하지 않는다. 작은 최근접 거리만으로 요청 목 치수를 보존했다고 판단할 수 없음을 보여준다.

실제 neck 경계 추출, 연속 접합 곡선 대응, 목 치수 승인 및 접합부 매끄러움은 미완료다. 측정 함수의 평면 fixture에서 거리·폭·깊이와 거리 조건 실패, 잘못된 좌표축 거부를 확인했다(**2 passed**).

## 모혈관 프로파일과 생성 표면의 교차선 진단

최종 표면 정점에서 원래 모혈관 field를 계산하고, 삼각형 위 선형 보간의 0 등고선을 공유 mesh edge 주소로 연결했다. 모든 교차 성분을 보관했으며 설계값에 가까운 성분을 골라 목으로 지정하지 않았다.

실제 결과는 **204개 성분, 204개 닫힌 곡선**이다. 목 중심에 가장 가까운 성분은 4,062개 점으로 이루어졌고 투영 span이 **16.468490 × 4.524172 mm**로 모혈관 표면까지 이어졌다. 해당 성분에서 실제 비선형 field 잔차 최댓값은 0.004630 mm였다. 따라서 이것을 설계 목 2×1 mm의 경계로 사용할 수 없다.

이 검사는 vertex field의 선형 등고선이다. 같은 부호인 edge 사이의 비선형 교차를 모두 포착하는 정확한 표면 교차 검사가 아니다. 생성 표면의 모혈관 부분이 원래 프로파일 안팎으로 이동하면서 여러 교차선이 생길 수 있어, 단순 field=0 추출만으로 실제 목 경계를 특정할 수 없다.

**후속 구현 방향:** 표면 생성 과정에서 모혈관·병변의 영역과 접합 경계 정보를 유지해야 한다. 최근접 곡선이나 크기가 맞는 등고선을 사후 선택하는 방식으로 목 치수 승인을 대체하지 않는다. 현재 후보의 목 치수 승인은 `UNKNOWN`을 유지한다.
