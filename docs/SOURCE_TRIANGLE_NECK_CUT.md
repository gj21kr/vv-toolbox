# 원본 면을 보존하는 목 경계 절단

`triangle_neck_cut.partition_triangle`은 볼록한 목 다각형을 투영한 원본 삼각형을 안쪽과 바깥쪽 조각으로 나눈다. 결과는 원본 세 정점에 대한 barycentric 좌표이며, 각 조각의 3D 좌표는 원본 면에서 계산한다. 투영이 퇴화한 면과 오목한 목 경계는 거부한다. 입력 형상은 변경하지 않는다.

[Docker 검사 8개 PASS](evidence/triangle-neck-cut-tests.xml): 경계 방향, 비스듬한 3D 원본 면, 전체 포함·전체 제외, 모서리 접촉, 면적 보존과 오목 경계 거부를 확인했다.

[실제 ACA 면별 검사](evidence/aca-triangle-cuts.json): 기존 목 개구에서 제거 대상으로 선택된 오른쪽 9개, 왼쪽 10개 원본 면 전부에서 조각의 면적 합과 원본 평면 일치를 확인했다. 오차 한계는 면적 1e-9 mm², 평면 거리 1e-9 mm이다. 검사는 동일 원본 좌표를 float64로 변환하여 수행한다. 초기 검사에서 원본 면적을 float32로 계산해 정밀도가 일치하지 않았으며, 좌표 변경이나 허용 오차 완화 없이 계산 정밀도를 통일했다.

## 공유 정점 조립과 좌우 결합 검사

`source_neck_opening.build_source_neck_opening`은 외측 조각과 원본 면 사이의 모서리 분할 위치를 공유하고, 각 조각 내부를 원본 평면에서 삼각분할한다. 기존 고리 재구성 대신 원본 면의 분할 조각을 사용한다. 각 출력 면에는 원본 face ID를 남긴다. 공유 위치 병합 허용 거리는 1e-9 mm이며, 목 경계가 원본 trace에서 벗어나거나 방향·면적 조건이 맞지 않으면 거부한다.

[기본 회귀 9개 PASS](evidence/source-neck-opening-tests.xml). 실제 좌우 ACA에서 각각 76개 목 경계 정점으로 하나의 개구를 확인했다([개구 기록](evidence/aca-source-neck-openings.json)).

`scripts/inspect_aca_union_contacts.py --source-cut`로 동일 dome을 새 개구와 결합했다. [결합 검사](evidence/aca-source-cut-union-contacts.json)에서 좌우 모두 자기 접촉 `NO_CONTACT_DETECTED`, 단일 닫힌 체적 조건을 만족했다. 기존 collar 방식의 오른쪽 3쌍·왼쪽 10쌍 충돌 기록은 별도로 보존한다.

검사는 고정된 두 사례에 한정된다. 원본 분할 면의 체적 보존, 주변 혈관과의 교차·포함, 분지 개구와 접선 연속성, 다른 입력의 안정성은 추가 검증 대상이다. 앱 적용과 생성 수용은 계속 미완료다.

## 생성 함수 연결

`build_source_sac_union`은 원본 면 절단 개구를 사용한다. 절단 면은 원본 face ID를 보존하고, dome에는 -1을 기록한다. 변경 없이 유지된 면의 출력 ID를 별도로 기록해 좌표가 원본과 정확히 같은지 검사한다. 모든 원본 유래 조각의 정점이 선언한 삼각형 평면과 내부에 남는지도 검사한다. 단일 닫힌 체적·자기 접촉 검사는 계속 필수이며 수용 상태는 후보로 유지한다.

[연결 회귀 13개 PASS](evidence/source-cut-union-tests.xml). 실제 생성 함수에서 좌우 두 후보를 생성하고 해시와 출처를 저장했다([실행 기록](evidence/aca-source-cut-sac-unions.json)). 체적은 오른쪽 174.961764 mm³, 왼쪽 174.857221 mm³이다. 원본 보존 실패 또는 자기 접촉 실패가 발생하면 저장하지 않는다. 출력은 `exports/aca-source-cut-sac-unions/`이며 이전 실패 기록을 덮어쓰지 않았다. 주변 간섭·분지 개구 검사와 앱 연결은 남아 있다.

## 전체 주변 동맥 접촉 대조

`scripts/inspect_aca_union_surroundings.py`는 저장 형상 해시와 Atlas archive hash를 확인하고 각 후보를 자신을 제외한 동맥 517개와 대조한다. 경계상자가 분리된 조합을 기록하고, 나머지는 원본과 후보 각각의 삼각형 접촉을 검사한다. 출력 면의 원본 face ID를 이용해 기존 접촉 면 쌍과 새 접촉 면 쌍을 구분한다. 양쪽 모두 전체 검사 범위를 완료했다([실행 기록](evidence/aca-union-surroundings.json)).

- 오른쪽 FJ1654: **NEW_CONTACTS**. FJ1690과 원본은 51쌍, 후보는 196쌍 접촉한다. 이 중 55쌍은 새 dome 면의 접촉이다. 원본 유래 면의 분할로 접촉 쌍 개수도 달라지므로 단순 개수 차이를 새 충돌 수로 해석하지 않는다.
- 왼쪽 FJ1654M: **NO_NEW_FACE_PAIR_CONTACTS**. 원본 face ID와 주변 face ID로 대조했을 때 새 면 쌍 접촉은 없다. 기존 접촉의 공간적 범위가 동일하다는 판정은 아니다.

오른쪽 후보는 주변 간섭 조건을 만족하지 못한다. 자기 교차 통과와 닫힌 체적을 주변 간섭 통과로 확대하지 않는다. 체적 포함, 분지 개구 및 접선 연속성은 미검증이며 두 후보 모두 앱 적용·생성 수용은 허용하지 않는다.

## 오른쪽 돌출 방향의 고정 각도 검사

`scripts/inspect_right_aca_tilts.py`는 목 중심과 모든 치수를 유지하고 목의 width 축을 기준으로 돌출 방향을 -30°, -15°, +15°, +30° 회전한다. 네 시도를 모두 수행하며, 생성에 성공한 각 후보의 dome을 나머지 동맥 517개와 대조했다. [실행 기록](evidence/right-aca-tilts.json)의 상태는 COMPLETED이며 수용 후보는 없다.

| 각도 | 결과 |
|---|---|
| -30° | 원본 목 경계의 완전하고 유일한 추적 실패 |
| -15° | 닫힌 결합 생성, FJ1690과 dome 접촉 유지 |
| +15° | 닫힌 결합 생성, FJ1690과 dome 접촉 유지 |
| +30° | 결합 자기 교차 검출, 저장 거부 |

이 결과는 해당 축·각도·중심·치수의 네 조건에 한정된다. 다른 회전축과 목 위치의 가능성을 배제하지 않으며, 충돌을 없애기 위해 치수나 검사 허용 오차를 축소·완화하지 않았다. 저장된 -15°/+15° 형상은 거부된 진단 후보이며 앱 적용 대상이 아니다.

두 번째 축(depth)에서도 같은 네 각도를 전수 검사했다([기록](evidence/right-aca-tilts-depth.json)). -30°/-15°/+30°는 유일한 원본 목 경계 추적에 실패했고 +15°는 FJ1690 접촉이 남았다. 회전 시 돌출 normal과 width 방향을 함께 바꿔 목 평면의 직교 조건을 유지했다. 수용 후보는 없다.

[기준 후보의 접촉 높이](evidence/right-aca-contact-height.json)를 추가 확인했다. FJ1690에 접촉하는 dome 면 49개의 모든 정점은 설계 목 평면 기준 -0.684664~-0.242766 mm에 있다. 원본에 투영된 목 경계의 높이는 -0.959908~-0.267853 mm이며 요청 dome 높이는 5 mm이다. 따라서 이번 접촉 면은 돌출부 끝이 아니라 원본 목에 맞추기 위해 변형된 기저부에 위치한다. 이는 면 정점의 높이 범위이며 정확한 교선 위치나 해부학적 병변 위치 판정은 아니다. 다음 검토 대상은 목 위치와 기저부 형상이며, 단순 돌출 방향 변경으로 해결됐다고 간주하지 않는다.

## 목 경계 포함과 위치 이동

동일 기록에 FJ1690의 닫힌 방향성 표면을 확인한 뒤 generalized winding 기반 점 포함 검사를 추가했다. 기준 목 경계 76개 중 **24개가 이웃 표면 내부 또는 경계**로 판정됐다(경계 허용 거리 1e-8 mm). 이 결과는 지정된 점들의 포함 검사이며, 전체 체적 겹침량이나 이웃 자기 교차의 검증은 아니다. 목 경계를 유지하면서 dome 상부 방향만 변경하는 방식으로는 원인이 제거되지 않는다.

크기·방향을 유지하고 목 중심을 두 축 각각 -1 / -0.5 / +0.5 / +1 mm 이동한 8개 조건을 모두 실행했다.

- [width 축 이동](evidence/right-aca-tilts-translate.json): 네 조건 모두 완전하고 유일한 원본 목 경계 추적 실패.
- [depth 축 이동](evidence/right-aca-tilts-depth-translate.json): 네 조건 모두 결합을 생성했으나 FJ1690과 dome 접촉 유지.

이 국소 탐색에서도 수용 후보는 없다. 위치 범위를 계속 넓히는 대신 목과 인접 분지의 관계, 원본의 기존 겹침 및 분기부 모델 범위를 재검토해야 한다. 앱에는 적용하지 않았다.
