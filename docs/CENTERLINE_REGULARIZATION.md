# 합성 중심선 평활화와 실제 목 사례 검사

`smooth_synthetic_centerlines`는 원본을 보존한 별도 합성 사례에서 중심선을 물리 호길이 기준으로 평활화한다. 첫 두 점과 마지막 두 점을 정확히 고정하여 접합 위치와 끝 선분 방향을 유지한다. 반경 값은 각 원래 station index에 그대로 남긴다. 원본 사례 직접 입력, 병변이 있는 선택 edge, 닫힌/너무 짧은 경로, 최대 변위 초과는 거부한다.

```text
python -m vv_toolbox.case_cli smooth-centerlines INPUT.snapshot.json PARAMETERS.json OUTPUT.snapshot.json
```

파라미터 JSON에는 `edge_ids`, `sigma_mm`, `sample_spacing_mm`, `max_displacement_mm`, 새 `case_id`를 지정한다. 입력·설정 파일을 덮어쓰지 않는다. 수정 edge는 추정 합성 출처로 표시하며, 이전 품질 결과를 새 형상의 승인으로 유지하지 않는다.

## 실제 목 사례의 고정 조건 비교

`scripts/inspect_centerline_regularized_neck.py`는 원래 목 사례의 CCA/ICA 4개 edge에 sigma 2 mm, 표본 간격 0.25 mm, 최대 이동 1 mm를 고정하여 적용한다. 원래 사례와 이전 실험 파일은 보존한다. 표면 생성 격자는 0.6 mm로 유지한다.

실제 최대 이동량은 0.712–0.822 mm였다. 네 접합 위치·끝 선분·반경은 유지됐고 접합 연속성 검사를 통과했다. 원래 단면 124개의 위치와 방향을 고정한 비교와 새 중심선을 따라 다시 배치한 단면 비교를 구분했다. normal은 양쪽 2 mm chord로 계산했다.

| 구간 | 원래 표면 반경 TV mm | 같은 단면의 수정 표면 TV mm |
|---|---:|---:|
| 왼쪽 CCA | 0.476950 | 0.503703 |
| 왼쪽 ICA | 0.391390 | 0.546079 |
| 오른쪽 CCA | 0.887534 | 1.002710 |
| 오른쪽 ICA | 0.301301 | 0.463814 |

TV는 접합 원본 쪽 -15…0 mm 구간의 station 간 등가 반경 절대차 합이다. 네 구간 모두 증가했다. 이 고정 조건의 중심선 단독 보정을 기본값으로 채택하지 않는다. 이것은 모든 중심선 보정 방식이 효과 없다는 결론이 아니며, 이번 실험에서 반경·표면 격자는 변경하지 않았다.

수정한 4개 혈관과 합성 연결 2개를 전체 사례의 주변 중심선과 대조하며, 동일 범위의 원래 사례도 검사한다. 접촉 후보는 실제 충돌 또는 해부학적 분기 확정과 구분한다. 결과와 원본 해시는 [검사 JSON](evidence/centerline-regularized-neck.json)에 보존한다. 최종 삼각형 충돌·해부학 수용·전반적인 표면 매끄러움은 미확정이다.

전후 모두 동일한 17개 edge 쌍에서 보수적 capsule 접촉 후보가 나왔으며 새로 추가되거나 사라진 후보 쌍은 없었다. 이 결과는 기존 접합의 타당성이나 삼각형 비충돌을 확인한 것이 아니다. 전체 주변 간격 상태는 UNKNOWN을 유지한다.

Docker 연산·CLI·반경·연속성 검사 **31 passed, 1.03 s**. 원본 및 비선택 혈관 불변, 끝 선분·반경 보존, 병변 거부, 최대 변위 초과 거부, 결정적 재생성과 저장을 확인했다.
