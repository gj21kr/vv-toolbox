# 곡면 목을 가진 주머니 표면 후보

`build_curved_sac_patch()`은 원본에 연결된 투영 목 윤곽을 재검사한 뒤 열린 주머니 표면을 생성한다. 64개 경계점은 입력 배열 그대로 보존한다. 타원체 축 프로파일에 따라 지정한 주머니 폭·깊이로 확장하고, 목의 높이 변화는 위로 갈수록 줄여 지정한 꼭짓점 높이에 연결한다. 폭·깊이가 최대가 되는 높이도 링에 포함한다.

각 각도에서 높이 역전·꼭짓점 초과를 거부한다. 모든 면의 양의 면적, 일관된 방향, 원반 위상, 정확히 선언한 목 경계만 존재하는지 검사한다. 주머니 폭·깊이·기준 평면으로부터의 수직 높이를 실제 정점에서 측정한다. 치수 일치 검사 오차 1e-6 mm는 수치 구현 확인용이며 임상 허용오차가 아니다.

출력은 **열린 표면 패치**다. 부모 혈관 면 절단·내강 결합·접선 연속성·주변 충돌 검증을 포함하지 않는다. `closed_lumen=false`, `accepted_for_generation=false`를 유지한다. 목 위치의 연속성은 부모와의 매끄러운 접합을 의미하지 않는다.

## 실제 ACA 입력

[검사 결과](evidence/aca-curved-patches.json): 기존 좌우 곡면 윤곽에서 각각 정점 2,177개·삼각형 4,288개 패치를 생성했다. 목 경계 보존, 원반 위상, 지정한 주머니 4×3×5 mm 치수 검사를 통과했다. 후보 파일은 `exports/aca-curved-patches/patch-0.npz`, `patch-1.npz`이며 기록에 각 SHA-256을 포함했다. 원본 사례 보존, 앱 미적용이다. 파일의 생성은 완성 혈관 데이터 수용을 의미하지 않는다.

[테스트 5개](evidence/curved-sac-patch-tests.xml)는 합성 곡면 목의 경계 보존·치수·열린 표면 조건, 부적합한 목 윤곽의 생성 거부와 기존 윤곽 연속성 검사를 포함한다. 전체 회귀나 실제 원본 Atlas 삼각형 부착 검증은 아니다.

## 자기 접촉 검사

생성기는 기존 `inspect_self_contact()`를 사용해 표면의 자기 접촉을 검사한다. 인접 삼각형의 정상적인 공유 정점·모서리는 허용하되 공유 위상 밖의 겹침을 검사한다. 공간 선별 후 필요한 모든 면 쌍을 검사하며, `NO_CONTACT_DETECTED`일 때만 후보를 반환한다. 접촉 검출이나 계산 예산 소진은 생성 오류다.

[실제 ACA 후보 검사](evidence/aca-patch-self-contact.json)는 위에서 저장한 NPZ의 SHA-256을 확인한 뒤 재생성 없이 같은 정점·면을 검사했다. 우측 28,290쌍, 좌측 28,582쌍을 비교했으며 양측 `NO_CONTACT_DETECTED`, 검출 쌍 0개다. 입력 후보 파일은 변경하지 않았다. 공간 선별로 배제한 면 쌍도 포함한 전체 distinct triangle pair 검사 범위를 사용한다. 부동소수점 교차 검사이며 정확 연산 증명이나 다른 혈관과의 비접촉을 의미하지 않는다.

[관련 검사 10개](evidence/curved-sac-self-contact-tests.xml)가 통과했다. 생성기 통합 테스트는 작은 링 수의 합성 후보를 사용하며, 실제 32링 ACA 후보는 위의 별도 파일 검사 결과로 구분한다. 검사 예산 소진 시 후보 반환을 차단하는 조건도 확인했다. 부모와 합친 폐내강·접선 연속성·주변 혈관 검사는 여전히 미완료다.

## 전체 Atlas 동맥 표면과의 접촉

[실제 검사](evidence/aca-patch-atlas-contact.json)는 동일 NPZ 파일의 해시·사례 revision·좌표계를 확인하고, 사례 출처에 연결된 Atlas archive 해시를 대조했다. 현재 Atlas 로더의 `arterial` 분류 **518개 표면 전체**를 사용했으며 부모 부품도 제외하지 않았다. 앞선 517개 마스크 입력 집합과 동일한 개수의 집합으로 가정하지 않는다.

| 후보 | 접촉한 원본 부품 | 교차 삼각형 쌍 |
|---|---|---:|
| 우 ACA | FJ1690 | 66 |
| 좌 ACA | FJ1654M | 66 |
| 좌 ACA | FJ1690M | 140 |

양측 `CONTACT_DETECTED`이며 검사 범위는 모두 완료했다. 공간 경계로 분리된 부품 ID와 실제 삼각형 검사 결과를 기록했다. 이는 자기 접촉 검사와 다르며 자기 접촉이 없다고 주변 접촉이 없는 것은 아니다.

접촉이 의도한 부모 부착인지 다른 혈관과의 관통인지는 `UNKNOWN`이다. 닫힌 체적의 포함 검사도 `NOT RUN`이다. 열린 주머니 패치는 아직 부모와 결합하지 않았으므로 접촉 0을 요구해 임의로 원본 연결을 제거하지 않는다. 두 후보는 앱에 적용하지 않았다. 접촉 판정 공통 모듈 [회귀 8개](evidence/aca-patch-contact-regression.xml)도 통과했다.

## 접촉 면의 위치 분류

[후속 위치 검사](evidence/aca-patch-contact-regions.json)는 실제 열린 표면의 경계 모서리에서 경계 정점을 구하고, 접촉 면을 경계 정점을 포함하는 면과 포함하지 않는 내부 면으로 나눴다. 저장된 접촉 기록 및 후보의 해시를 대조했다. 위치 분류기의 [테스트 2개](evidence/patch-contact-region-tests.xml)는 경계/내부 구분과 인덱스 오류 거부를 확인한다.

| 후보·상대 부품 | 경계 인접 접촉 면 | 내부 접촉 면 |
|---|---:|---:|
| 우측·FJ1690 | 0 | 59 |
| 좌측·FJ1654M | 52 | 7 |
| 좌측·FJ1690M | 0 | 122 |

Atlas 원본 명칭은 FJ1690/1690M이 각각 `right/left medial frontobasal artery`, FJ1654M이 `left anterior cerebral artery`다. 명칭은 원본에서 복사했으며 별도의 임상 판독이 아니다.

내측전두기저동맥 부품과의 교차는 목 경계 정점을 포함하지 않는 주머니 면에서 발생한다. 이 접촉을 정상 목 부착으로 묶어 제외할 수 없다. 주변 분지를 피하는 주머니 배치·형상 설계가 필요하다. 좌측 부모 접촉도 내부 면 7개가 있어 목 경계만의 일치로 표현하지 않는다. 경계 인접 면의 교차점이 경계 위에 있다는 뜻도 아니다. 원본 및 후보를 변경하거나 앱에 적용하지 않았다.

## 고정 방향 후보 비교

[여섯 방향 실행 기록](evidence/aca-direction-candidates.json). 좌우 각각 후방(+Y), 상방(+Z), 외측(우 −X·좌 +X) 세 방향을 실행 전에 정했다. 기존 목 2×1 mm·주머니 4×3×5 mm·전이 0.5 mm와 윤곽 오차 0.02 mm를 유지하고 첫 성공 뒤에도 나머지를 모두 실행했다. 각 방향의 국소 프레임·곡면 윤곽·표면·자기 접촉을 검사하고 생성된 후보는 전체 Atlas 동맥 518개와 비교했다.

| 측·방향 | 결과 |
|---|---|
| 우·후방 | FJ1655 표면과 접촉 |
| 우·상방 | 목 윤곽 연속 오차 조건 FAIL |
| 우·외측 | 다른 동맥 표면 접촉 검출 없음 |
| 좌·후방 | 목 윤곽 연속 오차 조건 FAIL |
| 좌·상방 | 다른 동맥 표면 접촉 검출 없음 |
| 좌·외측 | FJ1690M 표면과 접촉 |

우 외측·좌 상방 후보의 실제 주머니 치수는 각각 지정한 4×3×5 mm와 수치 오차 내에서 일치한다. 부모를 포함한 동맥 표면 교차가 모두 검출되지 않았으므로, 이를 원본 부모와 잘 붙었다는 뜻으로 해석하지 않는다. 목은 중심선·반경 재구성 외벽에 맞춘 것이며 원본 Atlas와의 간극·체적 포함은 미확인이다. 이 두 후보도 폐내강·해부학적 수용은 아니며 앱 적용하지 않았다.

네 개 생성 파일은 `exports/aca-direction-candidates/`에 저장하고 파일 해시와 전체 접촉 기록을 남겼다. 생성 실패 두 건도 함께 기록했다. 기존 실패와 원본 사례는 보존했다. 사용한 프레임·윤곽·표면·교차 모듈 [회귀 21개](evidence/aca-direction-generator-tests.xml)가 통과했다.

## 원본 부모와의 간극 확인

[저장 후보의 실제 원본 거리 검사](evidence/aca-patch-parent-gap.json)는 우 외측·좌 상방 후보의 목 경계 64점 각각에서 원본 ACA 삼각형까지 최근접 거리를 계산했다. 결과 좌표와 원본 면 ID를 모두 보존한다.

| 후보 | 최소 / 중앙 / 최대 목 표본 거리 (mm) | 원본 안의 후보 정점 |
|---|---|---|
| 우 외측 | 0.203811 / 0.357336 / 0.443708 | 0 / 2,177 |
| 좌 상방 | 0.158711 / 0.272994 / 0.425057 | 0 / 2,177 |

원본 메시의 중복 좌표 정점 인덱스를 정확히 합치고, 변경 전후 모든 삼각형 좌표의 배열 일치를 확인했다. 위치·면 방향·삼각형을 바꾸지 않은 이 정규화 후 양측 원본이 폐체적 조건을 만족해 전체 후보 정점의 포함 검사를 실행했다. 초기 원본 인덱스 상태의 체적 판정은 false였음을 함께 기록했다.

두 후보는 주변 동맥 표면 교차가 없더라도 원본 부모에 접합된 상태가 아니다. 목 표본은 원본에서 떨어져 있고 후보 정점은 모두 원본 밖이다. 정점 포함만으로 삼각형 전체나 체적의 비겹침을 증명하지 않으며, 이 사례에서는 앞선 전체 표면 교차 검사와 함께 해석한다. 다음 연결 형상은 재구성 반경 외벽이 아니라 실제 원본 표면에 맞춰야 한다. 최근접 좌표를 새 경계로 자동 적용하지 않았고 파일·앱은 변경하지 않았다.

## 실제 원본 삼각형에 대한 목 투영

`project_rim_to_mesh()`은 명시된 삼각형 표면과 평면 목 윤곽·단위 법선을 받아 광선 교점을 구한다. 정확히 같은 좌표의 정점 인덱스만 합친 뒤 일관된 폐체적 조건을 요구한다. 지정한 범위 안에서 바깥쪽 출구가 하나이며 접선 교점으로 판정되지 않는 표본만 반환한다. 출구 누락·복수 출구·접선 교점은 UNKNOWN으로 남기고 전체 윤곽을 자동 생성하지 않는다. 정점과 면 배열의 기하 해시 및 원본 면 번호를 저장한다.

[실제 투영 기록](evidence/aca-mesh-rims.json)은 우 외측·좌 상방의 기존 목 방향과 평면 치수를 보존하고 −5~+5 mm 범위를 사용했다. **양측 원본 ACA 삼각형에서 각각 64/64개 단일 출구**를 확인했다. 기존 반경 합집합 투영과 구분되는 별도 결과다. 원본 표면·앞선 패치 파일은 수정하지 않았으며 새 교점에 기존 패치를 자동으로 옮기지 않았다.

아직 표본 사이 곡선의 원본 면 부착·절단, 부모 내벽 제거, 패치 결합, 접선 연속성 및 전체 주변 검사는 필요하다. 유한정밀도 광선 계산의 결과이지 정확 연산 증명은 아니다. [테스트 3개](evidence/mesh-rim-projection-tests.xml)는 알려진 상자 표면의 교점과 면 번호, 출구 누락/복수 출구 미선택, 열린 입력 표면 거부를 확인했다.

## 원본 면을 따르는 전체 경계 경로

`trace_mesh_rim()`은 평면 다각형의 각 변과 투영 방향으로 정의한 평면을 원본 삼각형들과 교차시킨다. 외측을 향한 면에서 나온 교차 선분을 다각형 변의 범위로 자르고 순서대로 연결한다. 각 변 전체의 투영 범위를 빠짐없이 덮는지, 겹치는 층이 없는지, 3D 선분 끝점과 마지막–첫 연결이 지정 오차 안에서 일치하는지 검사한다. 공면 모호성·복수 층·구멍은 UNKNOWN이다.

[실제 ACA 경계 추적](evidence/aca-mesh-rim-traces.json)은 양측 모두 **76개 원본 면 위 선분으로 닫힌 경로**를 얻었고 64개 투영 변 중 미해결 변은 없었다. 연결 오차는 1e-7 mm로 고정했다. 원래 표본 사이에서 다른 삼각형으로 넘어가는 위치를 추가했으므로 64개 점을 직선으로 단순 연결한 것과 다르다. 각 선분의 원본 면 ID·끝점·투영 구간을 기록했다.

이 결과는 원본 면 절단에 사용할 경로 후보다. 원본 면을 실제로 삭제하거나 패치와 결합한 결과는 아니다. [경계 추적·투영 검사 5개](evidence/mesh-rim-trace-tests.xml)는 원본 삼각형 경계를 넘는 전체 경로와 복수 층 미선택 등을 확인했다.

## 별도 목 개구부 후보

`build_neck_opening()`은 원본과 별도로 목 개구부 후보를 만든다. 경계가 지나는 면과 앞쪽 내부 면을 선택하고, 그 영역의 원본 바깥 고리와 원본 면 위의 목 경계 사이를 다시 삼각형으로 구성한다. 선택 영역 밖의 삼각형은 좌표를 그대로 보존한다. 정확한 동일 좌표 중복 정점만 인덱스를 합친다.

이는 원본의 모든 삼각형을 경계에서 정밀 분할하는 방식이 아니다. 교체한 목 주변 삼각형의 내부는 원래 면과 다를 수 있어 `source_face_ids=-1`로 기록하고, 원본 편차 및 자기 접촉 검사를 별도로 요구한다. 바깥 고리 하나, 선언한 목 경계 하나, 일관된 면 방향을 확인해야 후보를 반환한다.

[실제 ACA 결과](evidence/aca-neck-openings.json): 우측 원본 면 9개를 목 주변 면 85개로, 좌측 10개를 86개로 구성한 별도 파일을 생성했다. 양측 모두 76점 목 경계 하나를 가지며 교체 영역 밖의 삼각형 좌표 동일성 PASS다. 원본 Atlas 파일·앱은 수정하지 않았다. 후보는 `exports/aca-neck-openings/`에 저장했고 해시와 제거·보존 원본 면 ID를 기록했다.

[개구부·경계 검사 3개](evidence/mesh-neck-opening-tests.xml)는 합성 상자에서 원본 입력 보존, 바깥 삼각형 동일성, 단일 열린 경계 및 기존 경계 추적을 확인했다. 주머니 결합·폐내강·매끄러운 접합·주변 충돌은 아직 검증하지 않았다.

## 원본 개구부와 주머니의 공유 경계 결합

`build_source_sac_union()`은 추적된 목 정점 인덱스를 부모와 주머니가 공유하도록 결합한다. 목의 내부 뚜껑을 추가하지 않는다. 불규칙한 목 표본의 실제 각도를 사용해 주머니 링을 만들고 단일 폐체적·면 방향·자기 접촉·보존 원본 삼각형 동일성을 검사한다. 입력 원본과 사례는 바꾸지 않는다. 호출자가 원본 부품과 사례 출처를 연결해야 하며 실제 검사 스크립트는 Atlas archive 및 사례 revision을 대조한다.

경계의 일직선 중간점 때문에 earcut이 퇴화 삼각형을 만들 수 있어 해당 삼각형과 인접 면의 대각선을 바꾸어 점과 바깥 경계를 유지한다. 면을 단순 삭제해 틈을 남기지 않는다. 합성 상자+주머니에서 목·부모·주머니 내부 점의 포함, 모든 모서리의 두 면 연결, 원본 보존을 확인했으며 [관련 검사 5개](evidence/source-sac-union-tests.xml)가 통과했다.

[실제 ACA 결합 실행](evidence/aca-source-sac-unions.json)은 양측 모두 단일 폐체적 조건 이후 자기 접촉 단계에서 FAIL이다. 우측 43,142쌍 검사 중 3쌍, 좌측 41,319쌍 중 10쌍의 접촉이 검출됐다. 전체 검사 범위는 완료했으며 후보 파일 게시와 앱 적용을 차단했다. 기존 열린 패치의 자기 접촉 없음 결과는 이 새 결합 표면의 수용 근거가 아니다. 결합부 보정과 재검사가 필요하다.
# 원본 결합의 충돌 위치 진단

`scripts/inspect_aca_union_contacts.py`는 기존 사례 revision과 Atlas archive hash를 확인한 뒤 거부된 좌우 결합을 재구성한다. 각 충돌 면을 원본 유지 면·재구성 collar·dome으로 구분하고 면 ID, 공유 정점, 삼각형 좌표를 기록한다. 진단 형상을 앱에 적용하거나 생성 후보로 게시하지 않는다.

[진단 기록](evidence/aca-union-contact-diagnosis.json)에서 오른쪽 FJ1654의 3쌍과 왼쪽 FJ1654M의 10쌍은 모두 **collar–dome** 접촉이다. 이 실행에서 검출된 접촉에는 원본 유지 면이 포함되지 않는다. 이는 전체 해부학적 수용이나 접선 연속성 통과를 의미하지 않는다.

현재 collar는 외곽과 목 경계를 투영 평면에서 삼각분할한 뒤 3D 정점을 연결한다. 원본 삼각형 내부를 따르도록 강제하지 않으므로 목 경계가 맞아도 연결부 내부에서 dome을 침범할 수 있다. 다음 수정은 원본 면별 절단과 외측 조각 보존을 대상으로 하며, 기존 자기 접촉 거부 조건은 유지한다.
