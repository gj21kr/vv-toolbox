# 닫힌 내강 후보의 제한된 표면 평활화

고정 계수 0.5/−0.53의 인접 정점 기반 두 단계 평활화를 10회 적용한다. 삼각형 연결은 유지하며 정점 이동 최대 **0.15 mm**, 부피 변화 최대 **2%**를 실행 전에 정했다. 한도를 초과하거나 닫힌 양의 표면 조건을 잃으면 결과를 거부한다. 부모를 포함한 선택 표면 전체를 수정한 별도 후보이며 원본 모델을 덮어쓰지 않는다.

같은 삼각형의 대응 정점 이동 상한은 같은 barycentric 좌표에서의 표면점 이동도 제한한다. 그러나 자기 교차·다른 혈관과의 간격이나 해부학적 정확도를 보증하지 않는다.

## 실제 우측 MCA 결과

| 항목 | 결과 |
|---|---|
| 최대 정점 이동 | 0.074304 mm / 한도 0.15 mm |
| 부피 변화 절댓값 | 0.111110% / 한도 2% |
| 인접 면 각도 95백분위 | 54.735° → 15.377° |
| 인접 면 각도 중앙값 | 0.000172° → 4.409° |
| 목 윤곽→출력 삼각형 최대 거리 | 0.171447 → 0.194685 mm / 한도 0.30 mm |
| 목 윤곽→출력 삼각형 평균 거리 | 0.090770 → 0.112192 mm |

면 각도 중앙값 증가는 기존 격자의 평평한 면이 곡면으로 바뀌는 효과를 포함한다. 95백분위 감소만으로 접합부 매끄러움의 수용 기준을 충족했다고 주장하지 않는다. 목 표본의 최근접 삼각형 거리는 방향성 거리이며 실제 목 폭·깊이의 측정이 아니다.

동일 좌표의 전후 삼각형 단면 `exports/union-regularization/comparison.png`를 열람했다. 작은 계단이 줄었지만 큰 굴곡과 목의 접합 각도는 남는다. 후보는 CANDIDATE이며 앱에는 적용하지 않았다.

[실행 JSON](evidence/union-regularization.json)은 원래 표면 hash·출력 hash·원본 revision·평활화 설정·전후 수치를 기록한다. 실제 삼각형 최근접 거리를 계산했으며 source 표면은 불변이다.
