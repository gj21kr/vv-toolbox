# 원본 분지 접촉 대조

검사일: 2026-10-21. 대상은 전방순환 결합 후보에서 이름과 접촉 위치가
단순하게 대응하지 않았던 원본 부분이다. 원본 표면과 데모는 변경하지 않았다.

## 원본 형상 검사

[실행 결과](evidence/ambiguous-original-source-contacts.json)는 고정된 사례 revision,
각 원본 표면의 좌표·면 해시, 접촉 삼각형 쌍을 기록한다.
결합 후보와 같은 1e-6 mm 허용오차로 원본 13개 조합을 검사했다.
모든 조합의 표면 쌍 검사는 complete이다. 부피 포함 여부는 이 검사 범위에 없다.

| 조합 | 우측 접촉 쌍 | 좌측 접촉 쌍 |
|---|---:|---:|
| FJ1662 ↔ ICA | 59 | 59 |
| FJ1662 ↔ MCA 근위부 | 27 | 27 |
| FJ1663 ↔ ICA | 30 | 30 |
| FJ1663 ↔ MCA 근위부 | 0 | 0 |
| ICA ↔ MCA 근위부 | 98 | 98 |

좌측 ID에는 `M` 접미사가 붙는다. ICA는 FJ1682/M, MCA 근위부는 FJ1692/M이다.
FJ1662/M과 FJ1663/M의 Atlas 이름은 모두 MCA 전외측중심가지다.
0은 표면 교차 미검출이며 부피 분리 또는 해부학적 비연결을 의미하지 않는다.

우측 총경동맥(FJ3564)–팔머리동맥(FJ3417)은 81쌍,
총경동맥–쇄골하동맥(FJ3579)은 73쌍,
팔머리동맥–쇄골하동맥은 57쌍이 검출됐다.
세 원본 표면이 서로 접촉한다는 사실을 세 개의 독립적인 해부학적 연결 edge로
변환하지 않는다.

## 문헌 대조와 접근 범위

- [Rosner 등, 1984, PMID 6747683](https://pubmed.ncbi.nlm.nih.gov/6747683/):
  검색으로 반환된 초록을 확인했다. 성인 사체 25구의 50개 반구에서
  전천공질로 들어가는 동맥들을 조사했으며 ICA, MCA, ACA, 전맥락동맥 기시를
  구분한다. MCA 유래 렌즈핵선조체동맥은 M1·M2에서 기시한다고 기술한다.
  이 구분은 ICA 근처에 있다는 이유로 MCA 가지를 ICA 가지로 바꾸는 근거가 아니다.
  직접 페이지 열기는 본문을 반환하지 않았고 전체 논문 도판은 확인하지 못했다.
- [Kang 등, 2005, PMID 15709128](https://pubmed.ncbi.nlm.nih.gov/15709128/):
  검색 초록에서 159례, 200측의 회전혈관조영 분석임을 확인했다.
  PMC 직접 접근은 확인 화면, AJNR PDF 직접 접근은 403을 반환했다.
  이 자료의 상세 도판을 Atlas 좌표와 대조했다고 기록하지 않는다.
- [Panagouli 등, 2020, DOI 10.7759/cureus.9897](https://www.cureus.com/articles/38528-morphometry-of-the-brachiocephalic-artery-a-cadaveric-anatomical-study.pdf):
  출판사 PDF 본문을 확인했다. 연구는 76구를 해부하고 74개 팔머리동맥을
  측정했다. 본문의 해부 설명과 측정 방법은 팔머리동맥에서 우측 총경동맥과
  쇄골하동맥으로 나뉘는 분기를 명시한다. 따라서 세 부분은 공통 분기점의
  parent–daughter 관계로 검토해야 하며, 두 daughter의 접촉을 별도 문합으로
  선언할 근거는 없다. 이 연구는 해당 Atlas 표본의 분기 좌표를 제공하지 않는다.

## 구현 판단

1. FJ1662/M은 원본 MCA에도 접촉한다. 결합 후 표면에서 ICA 면만 접촉한다고
   원본 MCA 기시가 없다고 결론 내리지 않는다. 결합은 내부 경계 면을 제거하므로
   출력 표면의 면 소유자만으로 연결 그래프를 추론하지 않는다.
2. FJ1663/M은 원본 MCA 표면 접촉이 검출되지 않았다. 이름 기반 기시와 형상
   부착의 차이를 미확정으로 유지한다. 원본을 이동하거나 이름을 변경하지 않는다.
3. 우측 팔머리 분기는 공통 접합부 후보로 다룬다. 실제 내강·분기 좌표·접합 범위
   검사 없이 총경동맥–쇄골하동맥 직접 edge를 추가하지 않는다.
4. 표면 접촉, 문헌 관계, 표본 연결 승인, 합성 연결 선언은 각각 별도 정보로 보존한다.
   이번 결과로 승인한 해부학적 구간 경계는 0개다.
