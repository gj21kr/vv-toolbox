# 대퇴–대동맥–경동맥 원본 연결 입력

고정 사례의 원본 13개 부분에 대해 78개 비순서 조합의 표면 접촉 검사를 완료했다.
[검사 기록](evidence/access-trunk-inputs.json)은 모든 원본 좌표·면 해시,
정점의 정확한 중복 제거 기록 및 접촉 면 번호를 포함한다.
허용오차는 1e-6 mm이며 원본 좌표·면을 변경하지 않았다.

모든 부분이 정확한 정점 인덱스 정리 후 양의 폐곡면 체적 조건을 충족했다.
78개 조합 검사는 모두 complete이고 16개 조합에 표면 접촉이 검출됐다.
기록의 PASS는 검사 완전성만 뜻한다. 자기 접촉·부피 포함·내강 연결·해부학적
연결 승인은 포함하지 않는다.

## 다음 연결 후보 순서

검출된 접촉을 따라 다음 원본 순서를 검사할 수 있다.

| 구간 | 원본 ID 순서 |
|---|---|
| 좌측 대퇴–장골 | FJ2074 → FJ3466 → FJ3464 |
| 우측 대퇴–장골 | FJ2143 → FJ3567 → FJ3565 |
| 장골 이후 공통 몸통 | 좌/우 총장골 → FJ1932(복부 대동맥) → FJ1931(흉부 하행 대동맥) → FJ3411(궁) |
| 좌측 경동맥 진입 | FJ3411 → FJ3483 |
| 우측 경동맥 진입 | FJ3411 → FJ3417 → FJ3564 |

각 연속 쌍에 표면 접촉이 있다는 계산 결과이며, 네 조합의 실제 내강 경로 통과
판정은 아니다. 접촉이 단순 접선 접촉인지 겹친 체적인지와 접합 후 중심선 포함,
최종 자기 접촉·주변 간격을 검사해야 한다.

## 중복 범위와 공통 접합부

- 별도의 하행 대동맥 FJ3427은 FJ1931·FJ1932 및 양측 총장골과 접촉한다.
  세 대동맥 부분의 표본 역할·겹친 범위를 확인하기 전 직렬 구간으로 모두 삽입하지 않는다.
- 양측 총장골끼리도 접촉한다. 공통 대동맥 분기부의 표면 겹침과 독립 문합을
  구분해야 하므로 직접 연결 edge를 추가하지 않는다.
- 현재 표는 추가 경로를 구성할 입력 목록이다. 기존 그래프, 데모, 원본 사례는
  변경하지 않았다.

## 전체 접근 표면 합성

팔머리 분기를 포함한 전방순환 후보를 부모로 하고, 대동맥궁·흉부 하행 대동맥·
복부 대동맥·양측 총장골·외장골·대퇴동맥의 원본 9개 부분을 추가하는 생성
경로를 구현했다. 총 22개 원본 출처를 포함하는 구성이다.

`build_anterior_brachiocephalic_union.py --access-trunks`는 부모 후보와 입력
사례 revision·원본 해시를 확인하고, 단일 폐곡면·자기 접촉·원본 면 출처를
검사한다. 원본 표면과 기존 후보를 덮어쓰지 않고 별도 출력 경로를 사용한다.
FJ3427은 흉부·복부 구간의 대안 원본으로 제외 목록에 명시한다.
이는 원본 역할의 해부학적 확정이 아니라 이 합성 구성의 명시적인 입력 선택이다.

[통합 표면 생성](evidence/femoral-anterior-union.json)을 완료했다.
22개 원본 출처, 67,128개 면의 단일 폐곡면 후보이며 자기 접촉 검출 없음,
모든 출력 면의 원본 출처 대조 PASS다. 출력 파일 SHA-256은
`bad61c62ca40b1aade54c6e52e3ded05829240b23f6dbd915991d8688ae313d9`이다.

같은 후보 해시를 대상으로 모든 등록 중심선과 주변 혈관 788개 검사를
시작했다. 흉부 대동맥의 5개 경로와 우측 총장골의 3개 경로를 모두 포함하며,
가장 긴 경로만 골라 검사하지 않는다. 이 후보는 개별 중심선과 접합 표면을
대조하는 단계이며 네 조합의 연결 그래프·해부 구간 라벨 승인은 아직 없다.
원본 및 데모는 변경하지 않았다.

## 중심선 검사 메모리 처리

첫 전체 중심선 검사 프로세스는 7개 경로 완료 후 traceback 없이 exit 1로
종료됐다. 같은 관찰 구간에 컨테이너 OOM 이벤트와 cgroup `oom_kill=1`을
확인했다. 메모리 관련 종료가 의심되지만 프로세스별 커널 추적은 확보하지 않았다.
[중단 기록](evidence/femoral-anterior-paths-interrupted.json)은 완료된 결과와
검사 checkpoint 해시를 보존하며 전체 상태는 UNKNOWN이다.

중심선 및 반경 envelope 검사에서 동시에 처리하는 nearest-triangle/ray 질의를
2,048개에서 128개로 줄였다. 경로·선분·허용오차·최대 세분 깊이·총 cell 예산은
변경하지 않았다. 내부 경로 및 중간에 표면 밖으로 나가는 600개 선분 예제에서
기존 batch 크기와 상태·처리 구간 수·외부 증거점·미확정 구간의 동일성을 확인했다.
관련 [24개 검사](evidence/containment-bounded-query-tests.xml)가 통과했으며
전체 실제 경로 검사를 다시 실행했다. 이 변경은 메모리 상한의 엄밀한 보장은 아니다.

[재실행 결과](evidence/femoral-anterior-paths.json)는 28개 등록 경로,
9,456개 선분 모두 PASS다. 외부 증거점과 미확정 구간은 없다.
흉부 대동맥 5개 및 우측 총장골 3개 경로를 포함한다. 중심선 사이의 접합 edge를
만들거나 네 접근 조합의 그래프 통과를 검증한 결과는 아니다.

## 후보 불러오기 준비

`access_union_preview.py`는 별도 후보를 형상 해시·검사 revision·면 출처와
대조하여 읽는다. 미완료 경로 기록은 RUNNING, 검사 파일이 없으면 NOT RUN,
미확정 접촉은 UNKNOWN으로 유지한다. 반경 편집용 중심선은 제공하지 않는다.
[5개 단위 검사](evidence/access-union-preview-tests.xml)와
[실제 후보 불러오기](evidence/access-union-preview-load.json)는 통과했다.
이 기록은 백엔드 읽기 기능만 다룬다.

앱 메뉴에 `대퇴–전방순환 통합 · 검토 후보`를 등록했다.
[앱 연결 관련 12개 검사](evidence/access-union-app-tests.xml)와
[실제 브라우저 검사](evidence/access-union-ui.json)가 통과했다.
후보 선택 → 대동맥궁 FJ3411 부분 선택(857개 면) → 전체 표면 → Atlas 복귀를
검사했으며, 빨간 통합 표면과 미확정 범위를 표시한 화면을 직접 확인했다.
해당 후보에서는 반경 편집을 숨긴다. 검사 상태는 후보를 불러온 시점의 기록이며
변경된 검사 결과를 보려면 다시 불러와야 한다.

첫 기존 CDP 브라우저 검증은 초기 로딩 중 지연되어 완료되지 않았다.
별도 headless 브라우저에서 원본 Atlas 뷰어 로딩을 막고, 후보 선택 후 실제 Viser를
연결하여 완료했다. 합성 API 응답은 사용하지 않았다. 캡처는 software WebGL이며
GPU 성능 또는 해부학적 정확도 검증으로 표시하지 않는다. 검사 후 Atlas로 복귀했다.

## 중심선 접합 후보

명시한 인접 원본 22개 조합에서 각 등록 경로 쌍의 최근접 샘플을 연결하는
후보를 만들었다. 가장 긴 경로 선택이나 전체 후보 수 제한 없이 34개 경로 쌍을
보존했다. 연속 곡선 사이의 정확한 최단거리 계산은 아니며 샘플 기반 제안이다.
[5개 회귀 검사](evidence/path-link-candidate-tests.xml)는 분기 보존,
원본 불변성, 동률 처리, 유효하지 않은 입력 거부를 확인한다.

[실제 후보 검사](evidence/access-path-link-candidates.json)에서 31개 직선 연결은
통합 표면 내부 포함 PASS, 2개는 FAIL, 1개는 동일 좌표의 영길이 후보로 UNKNOWN이다.
22개 인접 조합 중 21개에는 적어도 하나의 포함 PASS 후보가 있다.
실패 후보를 삭제하거나 임계값을 변경하지 않았다.

남은 좌측 외장골–총장골은 `FJ3466:n0`와 `FJ3464:n1`의 끝점 좌표가 정확히 같지만
원본 노드 ID가 다르다. [별도 점 검사](evidence/access-coincident-link.json)는
이 좌표가 표면 내부이며 표면까지 거리가 약 4.3479 mm임을 확인했다.
점 내부 판정은 PASS이고 원본 그래프의 접합 승인과 노드 병합은 수행하지 않았다.
향후 연결 시 새 합성 접합 선언과 두 원본 노드의 대응을 함께 기록해야 한다.

이번 단계에서 그래프에 추가한 edge는 0개다. 네 접근 조합을 통과하는 경로,
접합 접선 연속성 및 해부학적 기시의 정확성이 검증됐다는 의미는 아니다.

## 명시적 합성 그래프 구성

위 후보 기록으로부터 별도 graph-only 사례를 생성했다
([검사 및 경로 기록](evidence/access-sample-graph.json)).
각 명시적 인접 조합의 포함 PASS 후보 중 샘플 연결 거리가 가장 짧은 항목을
선택하며 동률은 edge ID·샘플 순서로 정한다. 이는 합성 구성 규칙이며
Atlas의 실제 접합 위치를 승인하는 규칙이 아니다. 좌측 장골은 별도 점 검사에
근거한 합성 노드 alias로 처리했다.

28개 원본 중심선을 접합 샘플에서 분할하고 21개 직선 연결과 1개 노드 alias를
선언하여 65개 edge·65개 node의 그래프를 만들었다. 분할된 각 원본을 다시
이어 붙였을 때 모든 좌표와 반경 샘플이 원본과 정확히 같음을 확인했다.
원본의 미확정 evidence 상태를 통과 상태로 변경하지 않았다.
원본 snapshot은 보존하며 파생 snapshot의 저장/재로드 동일성도 확인했다.

좌우 대퇴 × 좌우 경동맥 네 조합에 대해 등록된 ACA와 MCA 근위부 경로로 향하는
8개 비재방문 경로가 존재한다. 경로는 선택한 경동맥을 지나는 순서 지정 연결을
반드시 통과한다. 판정은 모두 UNKNOWN이다. 경로가 없어서가 아니라 원본 edge와
node에 미확정 연결 근거가 남아 있기 때문이다. A3/M3까지의 전체 분지·구간
도달을 검사한 것으로 표시하지 않는다.

관련 [18개 회귀 검사](evidence/declared-sample-graph-tests.xml)는 내부 부착점 분할,
양쪽 꼬리와 원본 샘플 보존, degree-3 분기, 영길이 edge 없는 노드 alias,
잘못된 입력 거부 및 기존 순서 지정 경로 검사를 포함한다.
직선 연결의 반경 envelope와 접선 연속성은 NOT RUN이다.
이 snapshot은 그래프 전용이며 참조 표면 해시를 기록한다. 원본 표면 목록을
새 분할 edge에 대응시킨 전체 사례 출력은 아직 수행하지 않았다.

## 앱 중심선 그래프와 접근 경로 표

통합 후보에서 `중심선 보기`로 65개 구간을 표시하고 `표면 보기`로 복귀할 수 있다.
원본 경로는 진한 빨강, 추정 목 연결과 합성 접합은 연한 빨강으로 구분한다.
중심선 모드에서는 전체 그래프를 표시하며 원본 부분 선택은 표면 모드에서 사용한다.
접근 경로 펼침 표는 좌우 대퇴·경동맥 조합별 ACA/MCA 근위부의 8개 판정을 표시한다.

불러오기 시 표면 해시, 그래프 snapshot revision, 원본 revision을 대조하고,
저장된 각 경로를 실제 그래프에서 다시 탐색하여 상태와 edge 순서가 일치하는지 확인한다.
미확정 경로를 통과로 바꾼 기록이나 작업공간 밖 경로는 거부한다.
[관련 27개 검사](evidence/access-graph-preview-tests.xml)가 통과했다.

[실제 브라우저 검사](evidence/access-graph-ui.json)는 후보·부분 선택, 8행의
UNKNOWN 경로 표, 표면↔중심선 전환 및 Atlas 복귀를 확인했다.
화면 캡처를 직접 확인했으며 software WebGL의 표시 검증으로 한정한다.
해부학적 경계·기시·접합 곡률이나 GPU 성능을 승인하지 않는다.

## 합성 접합의 방향·반경 검사

[접합 검사](evidence/access-graph-junctions.json)는 8개 접근 경로를 따라
새 연결과 노드 alias가 포함된 고유 전이 37개를 측정했다.
각 edge의 실제 탐색 방향으로 좌표를 정렬해 접합 전후 마지막/첫 선분의 각도와
반경 차이를 계산했다. 원본·그래프를 바꾸지 않았다.
관련 [12개 검사](evidence/access-junction-measurement-tests.xml)는 역방향 탐색,
반경 차이, 잘못된 경로 순서 거부 및 기존 반경 envelope 검사를 포함한다.

가장 큰 방향 전환은 팔머리동맥에서 우측 총경동맥으로 가는
`declared-link:10`의 팔머리 쪽 약 159.6402°이며 총경동맥 쪽은 약 141.1531°다.
좌측 장골 노드 alias에서는 반경 차이 약 0.335881 mm가 있다.
최근접 샘플 연결은 위치 연결 후보이지 매끄러운 경로 생성법이 아님이 드러났다.
원본 폴리라인의 국소 선분 각도이며 실제 표면 곡률이나 연속 곡선 접선의
해부학적 수용 판정으로 확대하지 않는다.

21개 직선 연결 모두의 반경-ball envelope 검사는 FAIL이다.
이는 중심선 위치·선형 반경으로 만든 구들의 합집합에 대한 보수적 검사다.
끝단 방향으로 확장된 구나 비원형 원본 단면 때문에 실패할 수 있으므로
이 결과만으로 실제 재구성 튜브 벽이 밖으로 나갔다고 결론 내리지 않는다.
중심선 포함 PASS와 반경 표현의 적합성을 구분하며 원본 반경을 자동 축소하지 않았다.

우선 팔머리–총경동맥 연결의 원본 중첩 구간과 진행 방향을 고려한
합성 부착 위치·곡선 후보를 구성해야 한다. 검사 허용오차를 완화하거나
실패 후보를 삭제해 기존 직선 그래프를 승인하지 않는다.

### 팔머리–우측 총경동맥 접선 연결 후보

[고정 collar 검사](evidence/access-collar-candidates.json)는 기존 그래프의
`declared-link:10` 양쪽 경로에서 각각 5·10·20 mm 이동한 부착점을 사용한다.
이동 거리는 원본 폴리라인의 호 길이이며, 양 끝 접선에 맞춘 cubic Hermite
곡선을 129개 점으로 샘플링했다. 도함수 길이는 부착점 사이 직선 거리다.
검사 전에 세 거리와 샘플 수를 고정했고 원본 및 데모 그래프는 변경하지 않았다.

| Collar | 샘플 폴리라인 표면 내 포함 | 시작 방향 차이 | 끝 방향 차이 |
|---|---|---|---|
| 5 mm | PASS | 0.35246° | 0.06958° |
| 10 mm | PASS | 0.40453° | 0.22725° |
| 20 mm | PASS | 0.26705° | 0.27257° |

연속 cubic의 끝 접선은 구성상 일치한다. 표의 각도는 첫/마지막 샘플
선분과 유지될 원본 선분 사이 각도이며 연속 cubic 전체의 포함 검사가 아니다.
원본 배열 보존·역방향·유효하지 않은 거리 거부에 대한
[단위 검사 6개](evidence/collar-link-tests.xml)가 통과했다.
각 후보 파일 해시, 원본 경로 방향 및 그래프/표면 해시는 검사 기록에 있다.
이동한 부착점에 따른 분지 재연결, 반경 변화, 자체 접촉 검사는 남아 있다.
따라서 후보의 전체 수용 상태는 UNKNOWN이며 기존 직선 연결을 교체하지 않았다.

### Collar 반경 및 유지 구간

[반경 검사](evidence/access-collar-radii.json)는 같은 세 후보의 부착점 반경을
원본 두 샘플 사이에서 선형 보간했다. 연결부 반경은 샘플 중심선의 호 길이에
따라 양 끝 반경을 선형 보간하며, 유지 구간의 기존 샘플과 반경은 그대로 둔다.
원본 구간 경계에 부착점이 정확히 놓일 때도 중복 점을 추가하지 않는다.
[11개 단위 검사](evidence/collar-radius-tests.xml)가 통과했다.

5·10·20 mm 후보 모두 radius-ball envelope 포함 검사는 FAIL이다.
원본 반경을 축소하지 않았고, 이 결과를 실제 튜브 벽의 관통으로 확정하지 않는다.
각 후보와 유지 구간의 좌표·반경을 별도 파일로 저장하고 해시를 기록했다.
반경 값의 연속성과 반경 기울기의 연속성은 다르며 후자는 강제하지 않았다.
실제 단면/표면, 자체 접촉, 분지 재연결 검사가 남아 있으므로 전체 수용은 UNKNOWN이다.

### 실제 샘플 튜브 벽 진단

`inspect_collar_walls.py`는 각 중심선의 국소 수직 평면에 32각형 단면을
배치하고 인접 단면을 삼각형으로 연결한다. float64 좌표와 보간 반경을 사용하며
열린 양 끝을 가진 별도 진단용 벽이다. 융합 접합부로 승인하지 않는다.
[단위 검사 15개](evidence/collar-wall-tests.xml)는 반경 보존, 입력 보존,
실제 외부 꼭짓점의 실패 판정 및 내부 꼭짓점만으로 전체 표면을 승인하지 않는
동작을 확인했다.

[벽 검사 기록](evidence/access-collar-walls.json)에 후보 파일 해시와 외부 점의
좌표·표면까지 거리를 저장한다. 5 mm 후보의 4,128개 꼭짓점 중 690개가
허용오차 1e-6 mm보다 멀리 바깥에 있어, 이 원형 단면 벽은 포함 검사 FAIL이다.
이는 구 envelope만의 실패보다 강한 반례다. 원본 Atlas 표면의 실패나
실제 환자 해부의 오류를 의미하지 않는다. 10 mm 후보는 외부 꼭짓점 1,768개,
20 mm 후보는 2,053개로 모두 FAIL이며 세 후보 검사가 완료됐다.
모든 꼭짓점이 내부여도 삼각형 내부 및 자체 접촉 검사를 대신할 수 없다.

### 원본 비원형 단면 측정

통합 표면을 절단했다. 총 381개 지점 모두 중심선 점을 포함하는 유일한
닫힌 윤곽을 측정했다. 원본 표면 및 중심선을 이동하지 않았으며 윤곽의
좌표, 면적, 도심과 중심선에서 경계까지의 최소 거리를 별도로 저장했다.
관련 [기존 단면 검사 16개](evidence/collar-source-section-tests.xml)가 통과했다.

| Collar | 측정 단면 | 저장 반경이 최소 경계 거리를 초과한 단면 | 최대 도심 편차 |
|---|---|---|---|
| 5 mm | 127 | 95 | 5.72861 mm |
| 10 mm | 127 | 127 | 5.16322 mm |

도심은 분지부의 넓어진 단면에도 영향을 받으므로 중심선을 도심으로 자동 이동하지 않는다.
닫힌 단면 하나라는 조건만으로 단면 간 대응이나 분지 보존을 승인하지 않는다.
양 끝 부착 윤곽, 비원형 단면 간 연결 및 분지 대응이 다음 구현 대상이다.

전체 수용은 UNKNOWN이며 원본 표면 대조 및 잔여 경로 보존이 남아 있다.

### 대퇴–전방순환 주변 형상 전체 검사 완료

### 최대 편차 구간의 다중 윤곽

단면 추출에 `include_all_contours` 옵션을 추가했다. 중심선을 포함하지 않는
윤곽도 좌표·닫힘 여부·면적과 함께 남기며, 해부학적 분지 ID는 UNKNOWN으로
유지한다. 옵션을 사용하지 않을 때의 기존 선택 윤곽은 그대로다.
[검사 11개](evidence/collar-branch-contour-tests.xml)가 통과했다.

[최대 편차 대조](evidence/access-collar-branch-contours.json)에서 두 후보의
최근접 원본 face 소유자는 모두 `FJ3579`였다. 10 mm 후보의 101→102번
단면은 선택 면적이 112.379→50.807 mm²로 바뀌고 전체 윤곽 수는 2→3이다.
20 mm 후보의 83→84번 단면은 108.374→52.365 mm²이며 전체 윤곽 수는
3→3이다. 두 번째 사례처럼 윤곽 개수만 같아도 선택 윤곽 간 대응이 보장되지 않는다.
해당 네 평면의 모든 윤곽을 별도 파일로 보존했다.

선택된 윤곽 하나씩을 그대로 이어 붙이는 방법은 이 구간의 원본 분지 표면을
보존했다고 볼 수 없다. 임의 반경 축소나 점 수 증대로 승인하지 않으며,
원본 분지 표면을 유지하는 국소 패치와 다중 윤곽 대응을 다음 단계에서 검토한다.

### 원본 분지 표면 보호 패치

[분지 보호 패치](evidence/brachiocephalic-source-patch.json)는 기존 통합 표면의
소유 ID `FJ3417`, `FJ3564`, `FJ3579`에 해당하는 모든 삼각형을 그대로 추출한다.
각각 314·615·404개, 총 1,333개 삼각형과 꼭짓점 767개로 구성되며 연결 성분은
하나다. 원본 삼각형 좌표의 바이트 일치를 검사하고 source face/vertex ID를
저장했다. 원본 표면을 새로 삼각분할하거나 단면 사이를 덮어 만들지 않았다.

원본 인덱스 기준 경계는 156개·45개 꼭짓점의 단순 루프 2개다.
루프 개수는 해부학적 출구 개수가 아니며, 기존 표면에 포함된 끝막음과 다른
소유 표면과의 경계를 구분하는 작업이 남아 있다. [검사 8개](evidence/source-patch-tests.xml)가
원본 좌표/ID 대응, 경계 순서 및 잘못된 선택 거부를 확인했다.
이 패치는 분지 보호 및 주변 편집을 위한 기준이며 새 연결 형상의 승인이나
매끄러움 개선 결과가 아니다. 데모 및 원본 그래프는 변경하지 않았다.

### 보호 패치의 원본 연결 경계

[경계 대응 검사](evidence/brachiocephalic-patch-interfaces.json)는 원본 mesh의
공유 edge를 기준으로 패치 내부 및 외부 삼각형을 대응시켰다. 총 201개 경계
edge 모두 내부 1개·외부 1개의 삼각형을 가지며 edge 방향이 반대임을 확인했다.
156개 edge의 외부 소유자는 `estimated_right_carotid_neck`, 나머지 45개의
외부 소유자는 대동맥궁 `FJ3411`이다. 원본 vertex/face ID와 외부 소유자를
각 edge마다 저장했다.

[단위 검사 9개](evidence/patch-interface-tests.xml)는 닫힌 표면의 대응,
열린 경계 및 같은 방향 거부, 원본 패치 좌표 보존을 확인했다.
이 PASS는 원본 인덱스와 방향의 대응에 한정한다. 편집 후 경계 좌표 일치,
접선 연속성 및 주변 혈관 무충돌은 별도 검사 대상이다.

### 분지 보호 상태의 목 구간 편집 후보

`check_protected_patch`는 원본 패치 삼각형과의 일치, 좌표가 중복된 보호
꼭짓점까지 포함한 보호 영역, 명시적 편집 영역 밖의 좌표 바이트 일치,
최대 이동량 및 삼각형의 퇴화/반전을 확인한다.
[단위 검사 9개](evidence/protected-patch-edit-tests.xml)가 통과했다.

[목 구간 편집 후보](evidence/protected-neck-fairing.json)는 추정 우측 경동맥
목 구간에만 속하는 내부 꼭짓점 14,664개를 대상으로 했다. 다른 소유자와
공유하는 경계 및 분지 보호 패치는 고정했다. 검사 전에 고정한 설정은
Laplacian 강도 0.1, 최대 이동 0.5 mm, 전체 체적 변화 비율 0.01이다.
측정 최대 이동은 약 0.040945 mm이며 보호 패치 삼각형 및 고정 좌표 일치,
폐쇄 양의 체적 검사는 PASS다. 전체 체적 변화가 작다는 사실은 국소 단면
보존을 증명하지 않는다. 자체 교차, 주변 충돌, 중심선 포함 및 매끄러움
수용 검사는 NOT RUN이며 원본과 데모에는 적용하지 않았다.

### 보호 편집 후보의 후속 검사

[자체 교차 및 굴곡 검사](evidence/protected-neck-fairing-self.json)와
[중심선 포함 검사](evidence/protected-neck-fairing-paths.json)를 실행한다.
두 검사는 동일 후보 해시를 사용하며 각각 진행 상태를 저장한다.
중심선은 기존 접근 그래프의 65개 edge 전체를 대상으로 하고 일부 완료를
전체 PASS로 표시하지 않는다. 자체 교차도 전체 표면의 삼각형 쌍을 검사한다.

편집 영역과 맞닿은 인접 face 쌍 44,616개의 각도를 측정했을 때 평균은
1.02321°→1.04443°, 95백분위는 6.59024°→5.99309°, 최대값은
22.14834°→22.71267°였다. 지표가 서로 다른 방향으로 바뀌었으므로 전체적으로
더 매끄러운 표면이라고 승인하지 않는다. 이 측정은 해부학적 매끄러움의
검증 기준이 아니며, 진행 중 검사의 최종 상태는 각 JSON에서 확인한다.

후속 실행이 완료됐다. 기존 접근 그래프 65개 edge 전체의 중심선 포함은
PASS이고, 전체 표면 자체 교차 검사는 NO_CONTACT_DETECTED다.
주변 혈관 충돌과 국소 단면 보존은 아직 NOT RUN이다.

[굴곡 악화 위치](evidence/protected-neck-fairing-creases.json)를 원본 face ID에
연결했다. 최대 편집 후 각도는 추정 우측 목 구간의 face 27406/27407에서
14.87959°→22.71267°이며, 이 쌍의 면적은 약 0.002164/0.006963 mm²다.
가장 큰 증가량은 face 23448/23451의 3.58479°→22.30910°로, 고정점과
이동점이 만나는 edge에 해당한다. 이 쌍 중 작은 삼각형 면적은 약
0.00010438 mm²다. 경계뿐 아니라 내부에서도 악화가 발생했다.
따라서 강도 변경만으로 해결됐다고 표시하지 않고, 보호 경계를 보존하면서
추정 구간의 가늘고 작은 삼각형 구성을 개선하는 작업을 진행한다.

### 좌표 고정 상태의 대각선 개선

`improve_planar_patch`는 명시적으로 선택된 face 쌍에서만 대각선을 바꾼다.
기존 평면에서 벗어나는 거리가 1e-8 mm 이내이며 볼록하고, 두 삼각형 중
낮은 품질이 개선될 때만 변경한다. 꼭짓점과 선택 영역 밖 face는 유지한다.
[검사 2개](evidence/planar-patch-flip-tests.xml)가 볼록 평면의 개선 및
선택 경계/비평면 보존을 확인했다.

[실제 목 구간 결과](evidence/neck-planar-flips.json)는 고정된 3회 sweep에서
대각선 9개를 변경했다. 폐쇄 양의 체적과 선택 외부 face는 보존됐으나,
최소 삼각형 품질은 0.00034853으로 전후 동일하다. 따라서 핵심적인 가는
삼각형 문제를 해결한 것으로 판정하지 않는다. 변경 face 쌍의 이력을 저장했으며
이전 단일 face 출처를 새 삼각형의 출처로 그대로 복사하지 않는다.
자체 접촉 검사는 NOT RUN이고 원본/데모는 변경하지 않았다.

### 내부 단면 재배치 후보

`resample_bridge_interior`는 양 끝의 두 단면씩을 좌표 그대로 유지하고,
나머지 단면을 둘레 길이 기준 64개 점으로 재샘플링한다. 점 개수가 달라지는
두 전이 구간은 품질 기반 연결을 사용한다. [검사 5개](evidence/bridge-resampling-tests.xml)가
입력 보존, 끝 단면 보존 및 전이 연결을 확인했다.

[우측 목 후보](evidence/resampled-right-neck.json)는 원래 96×156점의 추정
연결을 대상으로 만들었다. 삼각형은 29,640→12,712개, 품질 하위 1백분위는
0.0021605→0.0488284, 품질 0.01 미만 삼각형 수는 1,125→36개다.
0.01은 비교용 집계값이며 수용 기준이 아니다. 최소 품질은 0.00034853으로
동일하며 새 face 12577의 세 꼭짓점은 모두 보존한 끝부분 단면에 있다.
자체 교차는 NO_CONTACT_DETECTED다.

이 후보는 열린 추정 연결이며 기존 통합 표면에 아직 결합하지 않았다.
내부 재샘플링은 원래 단면의 모든 모서리를 보존하지 않으므로 표면 편차,
끝막음·통합, 중심선 및 주변 충돌 검사가 남아 있다. 원본과 데모는 유지했다.

### 재구성 목 구간의 편차 및 폐쇄 체적

[편차·체적 검사](evidence/resampled-right-neck-volume.json)는 원본→후보 방향
44,616개 점, 후보→원본 방향 19,224개 점에서 최근접 거리를 측정했다.
샘플은 꼭짓점 및 삼각형 중심점이며 연속 Hausdorff 상한은 아니다.
최대 거리는 각각 0.022384 mm, 0.022120 mm이고 95백분위는
0.008862 mm, 0.008044 mm다. 별도 허용오차 승인은 아직 없다.

동일한 0.001 mm 평면성 제한과 planar-earcut 방식으로 양 끝을 닫았다.
양의 폐쇄 체적 및 자체 교차 NO_CONTACT_DETECTED를 확인했고, 닫힌 후보를
별도 파일과 해시로 저장했다. [새 통합 실행](evidence/resampled-access-union.json)은
같은 22개 입력 중 추정 우측 목 구간만 이 후보로 바꾸어 진행한다.
원본 동맥은 고정된 사례 snapshot에서 읽으며 새 union 결과의 출처는
이번 입력 삼각형을 기준으로 검증한다. 최종 통합·중심선·주변 검사는
실행 결과를 확인하기 전까지 완료로 표시하지 않는다.

### 주변 검사 미확인 11개 입력의 원인

[입력 진단](evidence/context-unknown-surface-diagnostics.json)은 주변 형상
788개 전체의 해시가 기존 검사와 동일함을 먼저 확인한 뒤 미확인 11개를 검사했다.
9개(`FJ1683`, `FJ1683M`, `FJ1688`, `FJ1688M`, `FJ2404`, `FJ2405`,
`FJ3467`, `FJ3473`, `FJ3639`)는 자체 삼각형 접촉이 검출됐다.
`FJ3553`과 `estimated_left_vertebral_neck`는 열린 표면이다.
두 열린 표면은 방향이 일관되고 퇴화 face는 없으나, 폐쇄 체적 전제는 만족하지 않는다.
이 결과는 11개 모두가 검사 시간 부족으로 미확인된 것이 아님을 보여준다.

포함 검사 실패 정보에 실패한 입력 번호, 형상 해시, 인덱스 정규화/폐쇄 상태,
자체 접촉 상태와 예시 face 쌍을 추가했다. [회귀 검사 14개](evidence/context-validation-diagnostic-tests.xml)가
통과했으며 기존 PASS/UNKNOWN 판정은 바꾸지 않았다. 이번 작업은 원인 확인이고
원본 형상 복구나 주변 무충돌 승인이 아니다.

재구성 우측 목 구간을 사용한 22개 입력 통합 실행도 완료됐다.
새 후보는 연결된 경계 성분 하나이며 양의 폐쇄 체적, 자체 교차 미검출 및
이번 입력 삼각형에 대한 출처 검증 PASS를 만족했다. 중심선 포함·주변 검사와
기존 보호 패치의 표면 대응은 아직 완료하지 않았다.

### 보호 패치 좌표 복원과 재검사

새 union의 보호 영역은 기존과 같은 767개 꼭짓점과 1,333개 삼각형을
가졌으나, 통합 연산의 수치 차이로 최대 4.38904e-13 mm 차이가 있었다.
`restore_patch_coordinates`는 1e-8 mm 이내의 일대일 꼭짓점 대응과 방향을
포함한 삼각형 대응을 확인한 경우에만 원본 좌표를 복원한다.
대응 모호성·범위 초과·방향 변경은 거부한다.
[회귀 검사 8개](evidence/patch-roundoff-tests.xml)가 통과했다.

[별도 보호 후보](evidence/resampled-access-protected.json)는 원본 보호 좌표가
정확히 일치하고 face 인덱스는 변경하지 않았다. 폐쇄 양의 체적을 확인했다.
복원 후 전체 자체 교차와 [기존 중심선 65개](evidence/resampled-access-paths.json)를
재검사하며 각각의 실행 결과를 별도로 기록한다. 샘플 중심선 포함만으로
반경, 새 collar 경로, 주변 무충돌을 승인하지 않는다.

주변 검사의 요청 내 캐시는 최근 사용된 항목을 유지하도록 바꿨다.
32개 제한을 유지하며 반복 사용되는 큰 union이 이웃 입력 교체 때문에
불필요하게 재검증되는 것을 줄인다. [회귀 검사 15개](evidence/context-lru-tests.xml)가
통과했으며 검사 허용오차·범위·판정은 바꾸지 않았다. 실행 시간 개선은 아직 측정하지 않았다.

복원된 후보의 전체 자체 교차 검사 결과는 NO_CONTACT_DETECTED이고, 기존
그래프의 65개 edge 모두 중심선 포함 PASS다. 새 collar 그래프와 반경 포함
검사는 이 결과에 포함되지 않는다.

[주변 형상 재검사](evidence/resampled-access-context.json)는 baseline과 전체
context 해시가 동일한 788개 이웃을 사용한다. 새로운 검사 진행 콜백은
각 항목의 결과 사본을 전달하며, 호출자가 수정해도 실제 판정을 변경하지 않는다.
진행 기록은 10개 항목마다 저장하고 마지막 전체 결과를 별도로 기록한다.
[회귀 검사 16개](evidence/context-progress-tests.xml)가 통과했다.
완료 후 접촉 이웃 ID의 추가/제거를 비교하되, 같은 이웃과의 접촉 위치나
면적이 동일하다는 주장으로 확대하지 않는다. 진행 중 결과는 RUNNING이다.

전체 788개 재검사는 738.27초에 완료됐다. 접촉/포함 이웃 80개와 미확정
11개가 남아 최종 상태는 UNKNOWN이다. 기존 전체 모델 대비 새 접촉 이웃과
제거된 접촉 이웃은 모두 0개다. 이는 이웃 ID 집합 비교이며 접촉 위치·면적
동등성은 NOT RUN이다. 이 결과로 충돌 없음이나 해부학적 수용을 선언하지 않는다.

다음 편집 검사는 [좌측 대퇴동맥 반경 편집](ACCESS_RADIUS_EDIT.md)이다.
1.05배·전이 10 mm·최대 이동 1 mm를 고정하고 별도 표면에서 검사한다.
