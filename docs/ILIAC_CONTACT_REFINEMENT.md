# 장골 분기부 접촉 후보 상세 검사

입력은 [국소 표면 검사](INTERNAL_ILIAC_SURFACE.md)의 동일 snapshot과 15개
capsule 접촉 후보다. 최초 검사는 첫 번째 경고 선분만 저장하므로, 이번에는 각
혈관 쌍의 모든 선분 조합을 검사해 최소 capsule 하한과 실제 구형 포락체 겹침
witness를 저장했다. 원본과 합성 사례를 변경하지 않았다.

양수인 한 쌍은 설정된 1.2 mm 여유 간격보다 가깝지만 보수적 capsule 자체는
분리되어 있다. 음수 6쌍은 최소 중심선 거리를 이루는 두 위치에서 선형 보간한
반경의 구가 겹치는 실제 witness다. **변동 반경의 전역 최소 간격, 침투 깊이,
원본 mesh 관통 또는 해부학적 연결을 측정한 값이 아니다.**

나머지 8쌍은 선택한 6개 edge 내부 조합이다. 기존 접합 영역 밖 검사는 PASS였고,
이번 전체 구간 검사는 접합 영역 내부도 포함한다. 내부 조합의 경고를 주변
혈관 충돌로 중복 계산하지 않는다. 접합 내부 형상 수용은 미완료다.

## 다음 판독 위치

JSON에 모든 witness의 두 edge ID, interval/fraction, XYZ와 반경을 기록했다.
대동맥/좌측 총장골 인접부는 대동맥 분기 접합의 원본 형상·연결 이력과 함께
검사한다. 고환동맥 및 두 요동맥과의 쌍은 같은 위치의 원본 표면 대조가 필요하다.
이름이나 음수 간격만으로 연결을 추가하거나 주변 혈관을 이동하지 않는다.
