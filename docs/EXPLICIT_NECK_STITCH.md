# 명시적 접합 경계 연결

병변 합집합을 격자로 만든 뒤 목 경계를 사후 추정하는 과정에서 설계 곡선의 치수와 생성 경계의 차이가 확인됐다. 접합 곡선을 실제 mesh vertex로 보존하고 양쪽 surface patch가 동일한 경계를 공유하도록 연결하는 방식을 구현한다.

`stitch_rings`는 점 수가 다른 두 폐곡선의 원래 vertex ID와 명시적 순서 파라미터를 받아 삼각형 띠를 만든다. 두 고리의 ID는 겹치지 않아야 하며, 파라미터는 공통 seam에서 0으로 시작해 2π 미만으로 증가해야 한다. 각 고리를 한 바퀴 순회하며 다음 파라미터가 먼저 오는 쪽을 전진시킨다.

함수는 vertex 좌표를 수정하거나 복제하지 않는다. 반환 면 수는 두 고리의 점 수 합계이며, 두 고리의 모든 boundary edge를 유지한다. 중간 설계 고리를 양쪽 띠가 같은 ID로 공유하도록 구성할 수 있다.

## 검증

8↔13, 8↔8, 38↔125개 점의 원형 고리에서 면 수, Euler 수 0, 면 방향 일관성, 양의 삼각형 면적, 원래 두 경계 ID 보존을 확인했다. 양 끝을 cap으로 막으면 한 개의 방향 일관된 폐곡면이 됐다. 잘못된 순서와 중복 고리 ID는 거부한다. 관련 Docker 검사 **9 passed**.

이는 연결 위상 연산자 검사다. 임의 공간 고리에서 교차 없는 표면이나 접선 연속성을 보장하지 않는다. 실제 MCA에 적용하려면 두 출처 경계와 설계 고리의 순서·seam 대응을 정하고, 기존 혼합 면을 교체한 후 폐곡면·국소 교차·치수·접합부 매끄러움을 검사해야 한다. 현 단계에서 실제 MCA 형상과 데모는 변경하지 않았다.

## 설계 곡선 고정 국소 평활화

실행 전에 설계 고리로부터 2 mm 미만의 주변 정점만 자유 변수로 정하고, 설계 고리와 바깥 영역은 정확히 고정했다. 균일 Laplacian 제곱 에너지와 원래 정점 위치 보존항을 함께 최소화한다. 강도 10, 최대 이동 0.3 mm, 체적 변화 한도 2%를 고정했다.

실제 MCA에서 2,533개 정점이 자유 변수였고 최대 이동은 **0.162580 mm**, 체적 변화율은 **0.020222%**였다. 설계 고리 좌표는 그대로이며 단일 폐곡면 조건을 유지했다. 접합각 95백분위는 160.495°에서 **104.041°**, 최댓값은 161.204°에서 **119.431°**로 줄었다.

각도가 줄었지만 여전히 큰 접힘이 있어 매끄러운 접합으로 승인하지 않는다. 이 연산자는 접선 연속성을 직접 구속하지 않으며, 자기 교차와 주변 충돌도 미검사다. 현재 데모는 유지한다.

고정 정점의 정확한 보존, 큰 좌표 이동에 대한 결과 일관성, 사전 변위 한도 초과 시 거부를 Docker에서 검사했다(**2 passed**).

- [국소 평활화 결과](evidence/mca-neck-fairing.json)
- 별도 후보: `exports/mca-neck-fairing/surface.npz`
- 재현: `PYTHONPATH=src python scripts/inspect_mca_neck_fairing.py`.

## 접선 조건과 전환 영역 품질

독립 코드 검토와 저장 mesh 재측정에서 위치 고정 Laplacian 목적함수는 양쪽 접평면을 구속하지 않는 것으로 확인했다. 원래 고리의 125개 edge 모두에서 법선 각도가 90°를 넘었고, 평활화 뒤에도 32개가 남았다. 독립 누적 길이 대응과 125↔38/46점 밀도 차이도 가늘고 긴 삼각형을 만들었다.

`scripts/inspect_neck_transition_quality.py`는 목 고리뿐 아니라 전환 띠 내부와 바깥 접합을 별도로 측정한다. [검사 기록](evidence/neck-transition-quality.json)의 평활화 후보는 목 최대각 119.431°, 바깥 접합 최대각 66.147°, 띠 내부 최대각 50.287°이다. 띠의 최소 정규화 삼각형 품질은 0.001516으로, 폐곡면 여부만으로 이 후보를 승인할 수 없다.

`tangent_patch.hermite_rings`는 대응이 주어진 두 고리 사이에서 양 끝 위치와 도함수를 명시하는 cubic Hermite 전환 연산자다. 목 양쪽 패치에 같은 도함수를 지정할 수 있고, 목 및 바깥 경계 좌표를 정확히 보존한다. 단위 방향뿐 아니라 도함수 크기도 입력하므로 전환 폭을 명시적으로 관리한다. Docker의 6개 검사는 직선 원통 재현, 평행 이동 일관성, 공유 목 좌표와 도함수 일치, 잘못된 입력 거부를 확인했다.

이 연산자는 아직 실제 MCA mesh의 대체 패치에 통합하지 않았다. 대응점 계산, 표면 연결성을 따른 annulus 선택, 외곽 접평면 추정 및 재삼각분할이 남아 있다. 해석적 도함수 일치는 이산 mesh의 매끄러움이나 자기교차 부재를 보증하지 않는다. 실제 후보는 목·띠 내부·외곽 접합의 각도와 해상도 수렴, 삼각형 품질, 자기교차, 주변 충돌, 변위·체적 한도를 모두 검사한 뒤 적용한다.

## 표면 연결성을 따른 전환 영역 선택

`inspect_mca_transition_annulus.py`는 원본 출처 분리 표면의 혼합 면에 인접한 모혈관·병변 면에서 시작한다. 같은 출처의 edge-adjacent face 사이 중심점 거리로 최단 경로를 계산하고, 사전에 정한 1.0 mm 이내의 띠를 선택한다. 이는 이산 표면 경로이며 정확한 연속 geodesic 거리는 아니다.

실제 MCA 결과에서 모혈관 778면, 병변 821면이 선택됐다. 양쪽 모두 연결 성분 1개, Euler characteristic 0, 닫힌 경계 2개이며 기존 안쪽 경계가 보존됐다. 띠를 제외한 각 출처 영역에는 닫힌 외곽 경계가 하나씩 남았다. 외곽 정점 ID와 선택된 면 ID를 [검사 기록](evidence/mca-transition-annulus.json)에 저장했다. 입력 형상은 변경하지 않았다.

전환 영역의 조합적 조건은 충족하지만 외곽 접선 호환성, 대응점, 실제 대체 면 생성과 교차 검사는 아직 미완료다. 재현: Docker에서 `PYTHONPATH=src python scripts/inspect_mca_transition_annulus.py`.

## 실제 MCA Hermite 전환 후보

`inspect_mca_tangent_transition.py`는 선택한 양측 띠를 제거하고 설계 목을 공유하는 Hermite 패치를 생성한다. 목 곡선 접선에 수직인 공통 횡방향을 양쪽에 적용하고, 외곽에서는 보존 면에서 추정한 법선에 수직인 도함수를 사용한다. 8개 매개변수 구간으로 샘플링하며 마지막 고리는 원래 외곽 정점에 연결한다. 대응은 아직 임시 누적 길이 방식이다. 이 후보는 대응 방식의 한계를 포함해 기록하며 최종 생성 규칙으로 채택하지 않는다.

| 검사 영역 | 최대 면 법선 각도 | 90° 초과 edge |
|---|---:|---:|
| 설계 목 | 29.187° | 0 / 125 |
| 바깥 경계 | 168.618° | 6 / 185 |
| 전환 내부 | 179.626° | 114 / 5,685 |

설계 곡선과 원래 정점 좌표는 보존됐고 단일 폐곡면이지만 **전체 전환의 접힘 검사는 FAIL**이다. 목의 최대각 감소를 전체 접합부 개선으로 해석하지 않는다. 최소 삼각형 품질은 0.000451이며 자기교차·주변 충돌은 NOT RUN이다. 바깥 경계의 도함수는 보간 표본에 대한 조건이므로 원래 경계까지의 최종 삼각분할에서 접평면 일치를 보장하지 않는다.

다음 구현은 공통 기하학적 대응과 외곽 접선 조건을 직접 유지하는 재삼각분할을 해결해야 한다. 단순 표본 수 증가나 평활화 강도 변경으로 통과시키지 않는다.

- [검사 결과](evidence/mca-tangent-transition.json)
- 후보: `exports/mca-tangent-transition/surface.npz` (앱 미적용)
- 재현: `PYTHONPATH=src python scripts/inspect_mca_tangent_transition.py`.

## 공통 투영각 대응의 적용 조건

`angular_ring`은 실제 투영각을 보존하고 원래 mesh 경계의 순서를 검사한다. 각도가 역행하는 경계를 임의 정렬하지 않는다. `stitch_polar_rings`는 시작 위상이 다른 두 고리도 기존 경계 edge를 유지하며 연결한다. 서로 다른 위상·점 개수의 경계 보존, 시계 방향 처리, 각도 역행 거부 및 Hermite 연산자를 Docker에서 검사했다(9 passed).

실제 MCA의 모혈관 외곽 경계는 목 평면에서 투영각이 단조 증가하지 않아 적용 조건을 충족하지 않았다. `--angular` 실행은 **REJECTED**, 새 형상은 생성하지 않았다. [거부 기록](evidence/mca-angular-transition.json)은 원본 hash와 거부된 쪽을 포함한다. 따라서 이 형상에는 단순 방사형 대응을 적용할 수 없으며, 표면 위 일대일 대응 또는 외곽 경계 자체의 재메싱이 필요하다. 기존 Hermite 후보의 실패 기록은 유지한다.

## 접선 방향 가설 검사

`--normal-tangent` 후보는 외곽점 차이 대신 설계 목의 법선을 곡선 접선에 수직으로 투영해 공통 횡접선을 만든다. 원래 횡접선과 목 법선의 내적은 0.825–0.997로 모두 양수였다. 접선의 방향 뒤집힘은 관측되지 않았다.

기준 법선 후보도 내부 114개·외곽 6개 edge에서 90° 초과가 남았다. 목 최대각은 28.090°이지만 전체 접힘 검사는 FAIL이다. 접힘은 병변 쪽 여러 전환 띠에서 같은 경도를 따라 반복된다. 접선을 바꾼 것만으로 해결되지 않으므로 외곽 대응 및 각 strip의 실제 삼각형을 확인한다.

### 독립 검토에 따른 투영 연산 수정

양의 법선 내적은 접선장 변화가 안정적임을 뜻하지 않는다. 독립 좌표 검사에서 매우 짧은 적응 표본 사이의 곡선 접선 변화가 법선 투영에 전파되어 병변 쪽 고리의 투영각 순서가 뒤집히는 것으로 확인됐다. 따라서 위 검사는 접선 **부호** 뒤집힘만 배제하며, 접선 **변화량** 문제를 배제하지 못한다.

`--constant-normal` 후보는 투영 없이 일정한 설계 법선을 사용한다. 곡선 접선과 이 횡방향이 함께 접평면을 정의하므로 두 벡터를 반드시 직교시킬 필요는 없다. 실제 재생성 결과 내부 90° 초과 edge는 **114→14개**로 줄었고, 남은 14개는 마지막 외곽 연결 띠 또는 그 접합에만 위치했다. 중간 Hermite 띠에서 반복되던 접힘은 사라졌다. 외곽 접합에는 7개가 남아 전체 판정은 여전히 FAIL이다.

- [일정 법선 후보](evidence/mca-tangent-transition-constant.json)
- 원본 정점 및 설계 목 보존, 단일 폐곡면: PASS.
- 다음 수정 대상: 원래 외곽 고리에 연결되는 마지막 삼각형 띠의 재메싱. 자기교차와 주변 충돌은 NOT RUN, 앱 미적용.

## 외곽 연결의 품질 목적함수와 방향 제약

`quality_stitch`는 두 고리의 순서·정점 좌표를 보존하고 동적 계획법으로 삼각형 품질 역수 합을 최소화한다. 한 고리를 먼저 한 바퀴 도는 경로를 막기 위해 정규화 index 차이 0.25 이내의 경로만 탐색한다. 이는 제한된 경로군의 최적화이며 모든 가능한 재메싱을 탐색하는 것은 아니다.

실제 후보에서 품질 목적함수만 적용하면 최소 삼각형 품질은 0.001081→0.001389로 증가했지만, 내부 90° 초과 edge는 14→28개, 외곽은 7→8개로 늘었다. **품질 목적함수 단독 후보는 FAIL**이다. [결과](evidence/mca-tangent-transition-constant-quality.json)를 보존했다.

추가 방향 제약은 보존된 표면 법선을 외곽에 사용하고 대응 위치의 보간 법선을 내부 고리에 사용한다. 이 기준 법선 평균과 반대로 향하는 삼각형을 제외하면 병변 쪽에서 허용된 탐색 범위 안의 연결 경로를 찾지 못했다. [거부 기록](evidence/mca-oriented-transition.json)의 REJECTED는 고정 경계·고정 내부 고리·해당 법선 근사·index 탐색 범위에 한정된다. 기하학적으로 모든 가능한 연결이 불가능하다는 증거는 아니다.

고정 고리 사이의 연결 순서 변경만으로는 현재 문제를 해결하지 못했다. 다음에는 외곽 주변 면을 포함한 위치·삼각분할의 공동 수정이 필요하다. 경계 보존, 품질 목적함수, 퇴화 형상 거부, 기준 법선 방향 강제와 기존 연결 연산자를 Docker에서 검사했다(**18 passed**). 임상 검증·교차 검증·매끄러움 승인은 별도이며 앱은 변경하지 않았다.

## 외곽 정점 이동과 투영 재삼각분할 검사

`inspect_mca_outer_fairing.py`는 외곽 경계에서 mesh edge 경로 거리 0.6 mm 이내만 선택하고, 설계 목과 양쪽 안쪽 5개 고리의 1,375개 정점을 고정한다. 자유 정점 1,412개의 최대 이동은 0.093813 mm, 체적 변화율은 0.0031278%였지만 전체 전환과 이동 영역에서 90° 초과 edge가 **71개** 검출됐다. 이동량·체적 조건을 만족해도 접힘은 악화되므로 [후보](evidence/mca-outer-fairing.json)는 FAIL이다.

`projected_annulus`는 투영 Delaunay 삼각분할 후보를 만들고 두 원래 경계의 모든 edge와 투영 면적을 검사한다. 이는 constrained Delaunay 구현이 아니며 경계 보존을 보장하지 않는다. 마지막 좁은 띠에서는 닫힌 경계 조건을 충족하지 못했다. 안쪽 5개 고리를 남기고 바깥 3개 매개변수 구간으로 넓힌 경우에도 모혈관의 원래 경계 edge를 보존하지 못해 [REJECTED](evidence/mca-delaunay-transition.json)로 기록했다. 어떤 경계도 무시하거나 임의 정렬하지 않았다.

합성 고리의 정확한 두 경계 보존, 교차 고리 거부와 고정 정점 평활화 검사는 Docker에서 **4 passed**였다. 실제 형상에는 경계 edge를 강제하는 재삼각분할이 필요하다. 이 후보들은 앱에 적용하지 않았다.

## 경계 다각형 삼각분할과 내부 edge 교체

선택 의존성 `remesh`에 `mapbox-earcut==1.0.3`을 고정했다. [공식 사용법](https://github.com/skogler/mapbox_earcut_python)은 첫 고리를 외곽, 이후 고리를 구멍으로 지정한다. 라이브러리 자체가 모든 입력의 정확성을 보장하는 것은 아니므로 결과의 두 경계 edge 집합과 투영 면적을 계속 검증한다.

`--constant-normal --earcut-outer` 후보는 실제 MCA의 경계 보존에 성공했지만 외곽 16개·내부 41개 edge에 90° 초과 각도가 남았다. 이어 `--improve-edges`는 경계 edge를 고정하고, 투영에서 볼록한 인접 삼각형 쌍의 내부 대각선만 교체한다. 3D 삼각형 품질 역수 합이 감소할 때만 교체하며 최대 20회 순회한다. 기존 정점 좌표는 이동하지 않는다.

| 검사 | 내부 대각선 교체 후보 |
|---|---:|
| 설계 목 최대각 | 28.089° |
| 외곽 접합 최대각 / 90° 초과 | 34.130° / 0개 |
| 전환 내부 최대각 / 90° 초과 | 92.804° / 1개 |
| 최소 삼각형 면적 | 1.3311e−10 mm² |
| 최소 정규화 삼각형 품질 | 0.000667 |
| 원본 정점·설계 목 보존 / 단일 폐곡면 | PASS |
| 전체 접힘 검사 | FAIL |

남은 최대각은 edge `[27308,27309]`, faces `[52680,52718]`의 안쪽 고리와 재삼각분할 영역 접합이다. 매우 작은 삼각형도 남아 있어 전체 매끄러움 승인은 하지 않는다. 자기교차·주변 충돌은 NOT RUN이며 앱 미적용이다.

## 중간 고리 재표본화와 비인접 면 접촉 검사

`--uniform-interior`는 설계 목 125점을 그대로 보존하고 생성된 중간 고리만 공통 길이 매개변수의 64점으로 보간한다. 원본 혈관 정점은 이동하지 않는다. 적응적으로 매우 가까운 목 표본을 모든 중간 고리에 복제하지 않으므로 작은 삼각형이 반복되는 것을 줄인다.

실제 후보의 최대각은 목 **29.067°**, 외곽 **33.665°**, 내부 **51.048°**이며 세 영역 모두 90° 초과가 **0개**다. 최소 삼각형 면적은 **4.9565e−6 mm²**, 최소 품질은 **0.001420**이다. 설계 목 보존·원본 정점 보존·단일 폐곡면은 PASS, 큰 접힘 선별 검사도 PASS다. 품질 최솟값은 여전히 낮고 해상도 수렴 검사가 없어 전체 매끄러움 승인은 UNKNOWN이다.

`triangle_contact`는 삼각형 쌍에 대해 두 면 법선, edge 간 외적과 공면 분리에 필요한 축을 검사한다. 접촉 허용오차는 1e−8 mm다. 합성 교차·공면 포함·분리·접촉·강체변환·퇴화 거부 검사는 Docker에서 **6 passed**였다.

## 균일 고리 후보의 주변 혈관 검사

`inspect_uniform_transition_context.py`로 정확한 후보 bytes와 현재 case revision을 검증한 뒤 나머지 1,080개 혈관의 중심선·반지름 모델과 비교했다. 전체 후보에서는 1,064개를 AABB로, 10개를 삼각형 거리 하한으로 분리했다. 미확정 FJ1662:e12는 53,172개 세부 cell을 검사하여 미해결 0개, 양의 하한 0.002353 mm로 분리됐다.

## 둘레 표본 수 변화 검사

`--interior-samples 32|64|128`은 중간 고리 표본 수만 바꾼다. 설계 목, 외곽 경계, Hermite 조건, 고리 사이 방향 분할은 동일하게 유지했다. 모든 후보의 큰 접힘 선별 검사는 PASS이며 원본 정점과 설계 목을 보존했다.

| 중간 고리 표본 | 전체 체적 mm³ | 전환 면적 mm² | 절대 접합각×edge 길이 / 면적 (1/mm) |
|---|---:|---:|---:|
| 32 | 308.432740 | 13.089095 | 2.540827 |
| 64 | 308.439352 | 13.108833 | 2.998035 |
| 128 | 308.438469 | 13.134285 | 3.994654 |

전환 정점과 삼각형 중심에서 반대 후보의 실제 삼각형까지 거리를 양방향으로 측정했다. 표본 최대 거리는 32↔64에서 **0.029435 mm**, 64↔128에서 **0.021554 mm**였다. 이는 연속 표면 전체의 Hausdorff 상한이 아니다.

체적·위치 변화는 작아졌지만 절대 접합각 밀도는 증가하고 내부 최대각도 32/64/128점에서 각각 49.716°/51.048°/80.923°다. 따라서 해상도를 높였을 때 매끄러움이 수렴했다고 승인하지 않는다. 고리 사이 방향 분할은 고정되어 있어 이 축의 수렴도 아직 검사하지 않았다. 결과를 본 뒤 허용오차를 맞춰 통과시키지 않는다.

## 공유 경계 밖의 겹침과 후보 전체 자기접촉 검사

`adjacent_contact`는 공유 정점 1개 또는 edge 1개를 입력받아 그 범위를 넘어선 교차를 검사한다. 서로 다른 평면은 교차선 위 삼각형 구간을 비교하고, 공면은 안정적인 2D 투영에서 교집합 다각형을 계산해 허용된 공유 점·선분 밖의 점이 있는지 확인한다. 허용오차는 1e−8 mm다. 합성 정상 인접·공면 겹침·공유 정점을 지난 교차·분리·강체변환 및 비인접 면 검사는 Docker에서 **13 passed**였다.

### 독립 검사 코드 검토 및 수정

독립 검토에서 공면 다각형을 축 하나를 버린 2D 좌표로 투영하면 거리도 줄어드는 문제가 확인됐다. 공유 edge `[0,0,0]–[1,0,0]`, 삼각형 apex `[0,0.8e−8,0.8e−8]`와 `[0,1.6e−8,1.6e−8]`의 교집합은 실제 edge 거리 1.13137e−8 mm인데, 이전 구현은 2D 거리 0.8e−8 mm를 사용해 1e−8 mm 기준에서 놓쳤다.

Clipping 결과를 원래 평면 방정식으로 3D에 복원한 뒤 실제 점·선분 거리를 비교하도록 수정했다. 이 반례와 거의 평행한 공유 edge 사례를 회귀 테스트에 추가했다. 인접 검사의 tolerance는 공유 위상 밖 기하학적 겹침을 판정하는 수치 허용오차이며 최소 이격거리 검사가 아님을 명시했다. 반면 비인접 SAT는 tolerance 내 근접도 보수적으로 접촉 후보에 포함한다.

수정 후 **15 passed**, 같은 64×8 artifact 전체를 다시 검사해 비인접 4,624쌍·인접 328,832쌍에서 여전히 `NO_CONTACT_DETECTED`였다. 전체 자기접촉 기록에는 두 검사 모듈의 SHA256도 포함했다. 과거 부분 검사 기록은 당시 구현의 결과이며 현재 전체 재검사 기록을 우선한다.

### 주변 접촉의 형상 출처 구분

모혈관 유지 면(label 0), 병변 주머니 유지 면(label 1), 새 전환 면(label 4)을 각각 주변 전체 네트워크와 검사했다. 기존 5개 접촉 증거는 모두 **모혈관 유지 면**에서 검출됐다. 병변 주머니와 새 전환 면은 각각 1,078개 AABB 분리 + 2개 양의 삼각형 거리 하한으로 `SEPARATED_PROFILES`였다.

따라서 이번 후보의 병변 주머니·접합부에서 주변 혈관 모델을 관통한다는 증거는 없다. 보존된 모혈관의 5개 접촉을 정상 분기라고 승인한 것은 아니며, 그 관계는 별도 해부학적 연결 판독 대상으로 남는다. [출처별 결과](evidence/mca-uniform-transition-context.json)에 각 영역의 전체 검사 결과를 보존했다.
