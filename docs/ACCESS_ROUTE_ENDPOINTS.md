# 실제 원자료 접근 경로 끝점 검사

검사일: 2026-10-20. 재현은 Docker에서 `PYTHONPATH=src python scripts/inspect_access_route_endpoints.py`로 수행한다. [전체 검사 JSON](evidence/access-route-endpoints.json)은 Git 추적 대상이다.

## 범위와 결과

기존 동맥 대응 검사의 18개 역할에 해당하는 실제 원본 사례를 읽었다. 원본 사례 파일 hash·추출 preview hash·원본 source ID/hash를 기존 검사와 대조한 뒤 실행하며, 입력 파일은 변경하지 않는다.

| 항목 | 결과 |
|---|---:|
| 원자료 역할 | 18 |
| 고유 추출 edge | 24 |
| edge 끝점 기록 | 48 |
| 역할 쌍 | 153 |
| 모든 역할 간 끝점 쌍 | 1,052 |
| 자동 선택한 연결 | 0 |

각 끝점은 원본 part/OBJ hash, edge ID, start/end, node ID, LPS/mm 좌표, 반경, polyline 마지막 선분의 바깥 방향 단위 접선, 실제 node incidence, 원본 근거와 추출 방식을 기록한다. 접선은 voxel 추출 polyline의 국소 방향이며 매끄러운 해부학 접선으로 검증되지 않았다. 반경 역시 원본 표면의 voxel 추정이다.

153개 역할 쌍의 모든 끝점 조합을 기록한다. 최근접만 남기거나 임계거리로 후보를 버리지 않는다. 쌍마다 거리·서로를 향하는 접선 cosine·원본 node 공유 여부를 기록하고, 연결 상태는 모두 UNADJUDICATED이다. 멀리 떨어진 관계없는 역할 쌍도 포함하므로 목록 자체를 예상 해부학 연결 목록으로 사용하면 안 된다.

## 다음 적용 조건

원본 표면을 함께 보며 각 접합의 정확한 edge·endpoint 또는 필요한 내부 분할점을 지정한다. 합성으로 보충하는 구간은 근거·선택 이유·handle 길이를 명시하고 별도 모델에 추가한다. [합성 접근 경로 모듈](SYNTHETIC_ACCESS_ROUTES.md)이 원본 hash와 앵커를 확인하며, 원본의 미확정 해부학 상태는 유지한다.

인벤토리 생성은 PASS, 해부학 연결은 UNKNOWN, 실제 네 접근 경로 생성·표면 접합·충돌 검사는 NOT RUN이다.
