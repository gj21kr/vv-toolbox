# 병변 합성 표면의 생성 출처

`build_surface_neck_union`은 모혈관과 임시 폐곡면 병변의 점유 격자를 따로 보관한 뒤 합집합 표면을 만든다. 생성된 모든 삼각형에 `surface_origin.face_labels`를 기록한다. 면 순서는 반환된 `faces` 배열과 같다.

| 값 | 의미 |
|---|---|
| 0 | 세 정점과 중심에서 모혈관 점유 보간값이 더 큼 |
| 1 | 세 정점과 중심에서 병변 점유 보간값이 더 큼 |
| 2 | 표본별 우세가 달라지거나 같은 값인 혼합·동률 면 |
| 3 | 모든 표본에서 두 격자의 지지가 없음 |

두 점유값은 동일한 내부 격자의 trilinear 보간으로 계산한다. 이 값은 확률이나 면적 비율이 아니다. 혼합 면을 임의로 어느 쪽에 배정하지 않는다. 유효하지 않은 면 인덱스, 격자 밖 표면, 서로 다른 격자 크기를 거부한다.

이 정보는 **생성 시점의 표본 기반 출처**다. 표면 평활화가 면 연결과 순서를 유지하면 면 ID의 이력으로 보존할 수 있지만, 이동 후 면의 실제 영역 분류가 검증됐다는 뜻은 아니다. 면 재분할·순서 변경 시 그대로 사용해서는 안 된다.

실제 neck 경계는 아직 아니다. 다음 단계는 혼합 영역의 연결 성분과 모혈관·병변 우세 영역 사이의 경계를 조사하고, 이 경계가 하나의 유효한 목을 정의하는지 확인하는 것이다. 단순한 source label을 해부학적 구간 라벨로 사용하지 않는다.

## 검사

독립 격자 fixture에서 모혈관·병변·동률 면의 분류와 격자 밖 거부를 확인했다. 폐곡면 병변 합성 fixture에서는 모든 면의 label 존재, 세 영역의 실제 존재, 지지 없는 면 0개, 원본 불변을 확인했다.

Docker: `PYTHONPATH=src python -m pytest -q -p no:cacheprovider tests/test_surface_origin.py tests/test_surface_neck_union.py`

결과: **4 passed, 49 warnings, 14.74초**. 경고는 scikit-image의 NumPy 배열 shape 대입 폐기 예정 경고다. 기존 실제 MCA 산출물과 현재 데모는 변경하지 않았다. 새 출처 label을 포함한 실제 MCA 재생성과 목 경계 승인은 미완료다.

## 실제 MCA 재생성

동일한 평활화 모혈관·병변 사양·격자·후처리로 출처 정보를 포함한 후보를 재생성했다. 기존 후보와 **정점 배열 및 면 배열이 완전히 동일**했다. 기존 파일 바이트도 보존됐으며 새 metadata를 가진 별도 NPZ를 저장했다.

| 영역 | 삼각형 수 | 연결 성분 | 경계 |
|---|---:|---:|---|
| 모혈관 우세 | 46,506 | 1 | 닫힌 고리 1개, 38점 |
| 병변 우세 | 6,538 | 1 | 닫힌 고리 1개, 46점 |
| 혼합·동률 | 84 | 1 | 닫힌 고리 2개, 38점·46점 |
| 지지 없음 | 0 | 0 | 없음 |

혼합 patch의 Euler 수는 0이며 비다양체 edge는 0개다. 이는 한 개의 연결된 띠 형태와 일치한다. 병변과 모혈관 영역도 각각 한 성분이므로, 이전 field 등고선 204개 중 하나를 선택하지 않고 생성 출처를 기반으로 제한된 접합 영역을 확보했다.

이 영역은 평활화 이전 표본 출처의 면 ID를 따라간 것이다. 두 고리를 실제 neck 치수의 상·하한으로 승인하거나 해부학적 경계로 표시하지 않는다. 이후 두 고리의 좌표·설계 곡선 대응과 치수를 검사해야 한다.

- 새 후보: `exports/mca-surface-origin/surface.npz`
- 출처 표시 그림: `exports/mca-surface-origin/ownership.png`
- [형상 일치·영역 위상 기록](evidence/mca-surface-origin.json)
- 재현: Docker에서 `scripts/inspect_mca_surface_origin.py`, `scripts/plot_mca_surface_origin.py`.
- 현재 데모는 변경하지 않았다.

## 접합 띠 양쪽 경계 측정

선택된 면 영역의 edge 사용 횟수로 경계를 추출하고, 원래 mesh vertex ID를 유지한 닫힌 순서열로 저장했다. 분기되거나 점 하나에서 접하는 경계는 단순 고리로 승인하지 않는다.

| 생성 출처 경계 | 투영 폭 × 깊이 (mm) | 둘레 (mm) | 경계 정점→설계 곡선 최대 거리 (mm) |
|---|---|---:|---:|
| 모혈관 쪽 | 2.236500 × 1.388457 | 6.138710 | 0.213938 |
| 병변 쪽 | 2.138017 × 1.325056 | 5.507413 | 0.173040 |

설계 입력은 2×1 mm다. 양쪽 경계 모두 특히 깊이 방향으로 더 넓으며, 두 고리 중 작은 것을 택해도 설계 깊이와 0.325056 mm 차이가 난다. 둘은 source 영역 경계이므로 실제 해부학적 neck 치수의 상·하한이라고 해석하지 않는다. 목 치수 승인은 `UNKNOWN`을 유지한다.

이 결과는 기존 최근접점 집합의 깊이 증가가 단지 임의 점 대응에서만 나타나는 현상은 아니라는 추가 근거다. 생성기의 접합 띠와 설계 곡선 사이 차이를 줄이는 작업이 필요하다. 기록한 거리는 정점→선분 거리이며 연속 곡선 전체의 Hausdorff 거리를 보증하지 않는다.
