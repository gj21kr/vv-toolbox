# 낭상 배치 프레임 제안

`vv-case saccular-frame case.snapshot.json --edge EDGE_ID --station-mm 10 --reference-direction 1 0 0 --search-mm 8`

명시한 기준 방향을 선택한 경로의 국소 접선에 수직으로 투영한다. 평행하여 투영이 퇴화하면 지정한 호길이 탐색 범위 안에서 가장 가까운 유효 구간을 찾고, 그 구간의 방향을 인접 접선 사이의 최소 회전으로 전달한다. 임의 world 축으로 바꾸지 않는다. 유효 구간이 없거나 반대 접선으로 회전이 모호하면 오류를 반환한다.

출력에는 원본 revision, 기준 방향, 탐색 범위, 시작·목표 interval, 방향 벡터와 목 중심을 기록한다. `CANDIDATE`는 배치 제안 상태다. 해부학적 외측 방향과 실제 부착 타당성은 각각 UNKNOWN/NOT RUN이며 프레임 성공이 형상 성공을 의미하지 않는다. 추출 경로의 순서를 뒤집으면 width 축의 방향이 같다는 보장은 없다.
