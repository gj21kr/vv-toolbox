# 네 접근 조합의 현재 그래프 결손

궁–좌측 경동맥 합성 후보 revision `2b77c5e97f7d7b6c51625b82bb5c8ef7165fb12eb3979a64c2a15646d9c264ae`에서 좌우 대퇴 × 좌우 경동맥 네 조합을 각각 근위 ACA·MCA 원본 요소까지 검사했다. 총 8개 경로 선언의 공통 연결은 17종이며 **그래프 연결 존재 3종, 결손 14종**이다.

## 존재하는 연결

- 대동맥궁 → 좌측 총경동맥: 별도 합성 측분지.
- 좌측 총경동맥 → 좌측 내경동맥: 별도 합성 목 연결.
- 우측 총경동맥 → 우측 내경동맥: 별도 합성 목 연결.

원본의 실제 내강 연결을 승인한 결과가 아니다.

## 남은 연결

| 위치 | 결손 연결 종류 수 | 대상 |
|---|---:|---|
| 좌우 대퇴·장골 | 6 | 각 측 대퇴–외장골, 외장골–총장골, 총장골–복부 대동맥 |
| 대동맥 | 2 | 복부–흉부 하행, 흉부 하행–궁 |
| 우측 경동맥 기시 | 2 | 궁–팔머리동맥, 팔머리동맥–우측 총경동맥 |
| 좌우 ICA 말단 | 4 | 각 측 ICA–ACA 및 ICA–MCA |

위 연결은 원자료 표면을 보고 접합 위치와 방향을 지정할 작업 목록이다. 최근접 끝점을 자동으로 잇는 규칙으로 전환하지 않는다. 총장골·흉부 하행 대동맥처럼 하나의 역할에 여러 추출 edge가 있는 경우 내부 경로의 완전성도 별도로 확인해야 한다.

## 검사 범위

각 연결의 두 역할 edge와 명시된 합성 bridge만 허용하여 그래프를 탐색했다. 관계없는 혈관을 우회한 경로를 해당 연결의 근거로 쓰지 않는다. 원본 slot의 source hash와 현재 사례를 대조하고 분할된 궁만 두 child ID로 대응했다.

현재 8개 경로 선언 모두 `INCOMPLETE`다. 연결 쌍 각각의 존재만으로 순서가 맞는 하나의 비반복 경로를 보증하지 않는다. ACA A1–A3·MCA M1–M3 원위 구간의 완성과 카테터 통과 가능성도 이 검사 범위가 아니다.
