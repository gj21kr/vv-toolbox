# 결합 표면의 원본 혈관별 변형

`union_radius.scale_selected_radius`는 결합 표면의 특정 원본 혈관 영역을
명시된 중심선 주위로 반경 방향 변형한다. 입력 표면은 변경하지 않으며
출력은 별도 후보로 반환한다.

## 경계 보존

- 원본 출처가 다른 면과 공유하는 정점을 고정한다.
- 선택하지 않은 혈관에 속한 정점과 면 인덱스를 그대로 보존한다.
- 표면 모서리 길이 기반 최단 거리와 중심선 양 끝까지의 길이로 전이 가중치를 계산한다.
- 명시한 전이 거리 안에서 smoothstep으로 변형량을 줄인다.
- 중심선의 접선 방향 성분을 제외한 반경 방향으로만 이동한다.
- 최대 이동 거리, 퇴화·뒤집힌 면, 닫힌 양의 체적 및 자기 접촉을 검사한다.

반경 배율은 전이 영역 밖에서 적용된다. 모든 단면의 측정 반경이 동일한
배율로 변했다는 뜻은 아니며, 실제 단면 측정 검사는 별도다.
다른 혈관과의 접촉 검사와 해부학적 허용 범위는 이 함수의 통과 항목에 포함하지 않는다.

## 검사

합성 원통의 중간 원본 영역을 0.9 배로 변형해 단면 반경 0.9,
공유 경계·선택 외 영역·입력 배열·면 인덱스 보존을 확인했다.
이동 한계 초과와 중복 중심선 점은 거부한다.
관련 선택·반경 검사 8개 PASS (`evidence/union-radius-tests.xml`).

실제 사례 실행:
`PYTHONPATH=src python scripts/build_carotid_radius_candidates.py`.
좌우 경동맥 결합 모델에서 추정 목 연결부만 선택하고,
배율 0.9, 전이 5 mm, 최대 이동 0.5 mm를 적용한다.
좌우 모두 닫힌 체적·면 뒤집힘 방지·자기 접촉 검사를 통과했다.
왼쪽 11,468개 정점이 최대 0.367260 mm, 오른쪽 14,664개 정점이
최대 0.388568 mm 이동했다. 공유 경계, 선택 외 정점 및 면 인덱스는
양쪽 모두 동일하게 유지했다.
[실제 검사 기록](evidence/carotid-radius-candidates.json)에 입출력 해시와
자기 접촉 검사 결과를 보존했다.
원본과 데모는 변경하지 않는다.

출력 형상은 입력과 다르므로 원본 후보의 해시 기반 검사 결과를 그대로
승계할 수 없다. 원본 면 번호는 출처 정보로 유지할 수 있지만,
변형 뒤의 면이 기존 원본 삼각형 위에 있다는 의미로 사용해서는 안 된다.
앱의 반경 편집 연결, 단면 측정, 주변 충돌 및 내보내기 반영은 남아 있다.

## 반경 변형 후 단면 측정

`scripts/inspect_carotid_radius_sections.py`는 동일한 기존 중심선 위치와
인접 점의 chord에 수직인 평면에서 입력·출력을 비교한다.
좌우 각각 94/94개 단면에서 유일한 닫힌 윤곽을 측정했다.
중앙부는 양 끝에서 선언된 전이 거리의 두 배(10 mm) 이상 떨어진
위치로 사전에 정의했으며, 각 66개 단면이 해당했다.

| 후보 | 중앙부 등가 반경 비율 범위 | 목표 0.9와 최대 절대 차이 |
|---|---|---:|
| 왼쪽 | 0.899999305–0.900005322 | 0.000005322 |
| 오른쪽 | 0.899996086–0.900009397 | 0.000009397 |

[단면 검사 기록](evidence/carotid-radius-sections.json)에 전이 영역을 포함한
모든 측정값을 보존했다. 이는 이 두 후보의 단면 측정 결과이며,
연속 구간 전체의 반경 오차 상한이나 모든 배율·혈관에 대한 수용 기준은 아니다.
결과를 본 뒤 통과 한계를 새로 정하지 않았다.

`inspect_carotid_union_neighbors.py --radius-edit`로 수정 전 결합 표면과
수정 후 표면의 주변 혈관 접촉을 비교하는 검사를 완료했다.
양쪽 변형을 동시에 적용한 별도 검사 장면이며 데모는 변경하지 않았다.
좌우 각 805개, 총 1,610개 비교에서 새 접촉 혈관과 미확정 결과는
0개였다 ([기록](evidence/carotid-radius-neighbors.json)).
같은 혈관과의 접촉 위치 동등성 및 완전 포함에 의한 부피 중첩은
이 표면 접촉 비교에서 확인하지 않았다.

## 편집용 중심선 연결

결합 후보를 읽을 때 동일한 사례 revision의 원본 부분과 중심선을 연결한다.
좌우 내경동맥·총경동맥·추정 목 연결부의 여섯 부분에서 각각 하나의 경로를
확인했다. 추정 연결부는 생성 시 선언된 중심선을 사용한다.
복수 경로 또는 중복·비정상 좌표는 편집 불가 사유로 반환하며,
길이가 긴 경로를 임의로 선택하지 않는다. 원본 사례 revision이 다르면
연결을 거부한다. 경로 배열은 별도 복사하여 원본 자료를 보존한다.

관련 단위 검사 4개가 통과했다
([검사 기록](evidence/candidate-centerline-binding-tests.xml)).
이는 편집 기준 경로의 연결 검사이며 중심선의 해부학적 정확성이나
반경 편집의 앱 적용·복원 완료를 의미하지 않는다.

## 반경 편집 상태와 복원

`CandidateRadiusSession`은 원본과 분리한 사본에서 계산한 후보를 보관한다.
미리보기 계산은 현재 표면을 변경하지 않으며, 최신 후보의 토큰으로 적용한다.
적용 또는 복원 이후 도착한 이전 계산 결과는 거부한다. 같은 후보의 중복 적용,
교체된 미리보기 토큰 사용도 거부한다. 복원은 표면과 검사 요약을 함께 되돌린다.

변형 결과에서는 원본 표면 해시를 부모 출처로 보관하고 새 좌표·면 배열의
해시를 기록한다. 이전 표면의 중심선 포함 검사, 원본 삼각형 일치 검사,
주변 접촉 검사를 새 결과에 승계하지 않고 `NOT RUN`으로 표시한다.
면의 출처 정보는 유지하지만 원본 삼각형과의 공간적 일치를 의미하지 않는다.

편집 상태·반경 변형·중심선 연결·후보 로더 관련 검사 17개가 통과했다
([검사 기록](evidence/candidate-radius-session-tests.xml)).
앱은 `/api/candidate-radius-preview`에서 잠금 안에서 현재 장면과 편집 대상을
고정하고 잠금 밖에서 후보를 계산한다. 계산 이후 장면 generation이 달라지면
결과를 표시하지 않는다. `/api/candidate-radius-action`은 미리보기 취소,
후보 적용, 적용 되돌리기를 처리한다. 표시 실패 시 적용 및 복원 이력을
소비하지 않는다. 미리보기는 전체 결합 표면을 표시하며 적용 여부를 별도 표시한다.

좌측 작업 패널의 합성 후보 검토에서 좌우 경동맥 결합 후보를 선택한 후,
원본 혈관 부분을 고르면 반경 배율·접합 전이 거리·최대 이동 허용값을 입력할 수 있다.
미리보기 또는 적용한 변경이 남아 있으면 원본으로 돌아가기 전에 취소·복원한다.
편집 이력은 아래 파일 저장·재로드 절차로 보관할 수 있다.
임의 편집 결과의 주변 혈관 검사는 남아 있다.

앱 연결 관련 검사 22개가 통과했다
([검사 기록](evidence/candidate-radius-app-tests.xml)).
전체 회귀 검사는 1,076개 통과, 의존성 경고 355개였다
([기록](evidence/candidate-radius-full-tests.xml)).
전체 검사 수집 이후 추가한 연속 편집의 부모 해시·역순 복원 검사는 위의
22개 검사에 포함했다.

실제 브라우저의 좌우 추정 목 연결부에서 배율 0.9, 전이 거리 5 mm,
최대 이동 허용값 0.5 mm로 미리보기→적용→되돌리기를 확인했다.
좌측은 미리보기 취소 후 원본 해시 복원도 확인했다. 양쪽 모두 적용 후
되돌리기에서 원본 해시가 복원되었고 Atlas 모드로 복귀했다.
[브라우저 기록](evidence/candidate-radius-ui.json)의 범위는 작업 패널과
요청·상태 전환이다. 별도 Viser 3D 렌더러는 이 검사에서 제외했으며,
실제 표면 표시와 움직임의 시각적 확인은 `NOT RUN`이다.

## 편집 파일 저장과 재로드

`vv-toolbox.candidate-radius-session/1` 파일은 원본 후보 ID, 사례 revision,
좌표·면·면 출처·중심선의 내용 해시와 적용한 반경 편집 순서를 기록한다.
각 편집에는 대상, 배율, 전이 거리, 이동 허용값, 결과 형상 해시가 포함된다.
파일 전체 내용의 체크섬도 확인한다. 체크섬은 손상 검사용이며 서명이나
작성자 인증을 의미하지 않는다.

미리보기는 적용 또는 취소한 뒤 저장한다. 되돌린 편집은 저장 순서에서 제거한다.
불러오기는 동일한 원본 후보를 새로 읽고 각 편집을 순서대로 재계산하며
자기 접촉·폐곡면·면 뒤집힘·이동 한계 검사를 다시 실행한다.
단계별 결과 해시가 저장 당시와 다르면 실패하며 현재 장면은 유지한다.
저장 파일의 좌표나 통과 상태를 신뢰하여 그대로 적용하지 않는다.
복원 후에도 역순으로 되돌릴 수 있다.

작업 패널에는 **편집 파일 저장**, **편집 파일 불러오기** 버튼이 있다.
현재 편집을 먼저 되돌린 후 동일한 후보에서 불러오며, 계산 중 다른 탭에서
장면이 변경되면 복원 결과를 폐기한다. 파일 저장 및 복원은 원본 Atlas 파일을
변경하지 않는다.

관련 검사 23개가 통과했다
([검사 기록](evidence/candidate-radius-save-tests.xml)).
이 기록에는 2회 연속 편집·재로드·역순 복원, 원본 좌표·중심선·revision·면 출처
변경 거부, 파일 손상 및 결과 해시 불일치 거부가 포함된다.

브라우저에서 좌측 추정 목 연결부의 편집을 다운로드하고 되돌린 뒤,
체크섬을 훼손한 파일의 HTTP 400 거부와 현재 원본 해시 유지를 확인했다.
정상 파일은 입력 요소를 통해 다시 불러왔고 저장 당시 결과 형상 해시와
정확히 일치했다. 복원된 편집을 다시 되돌려 원본 해시 일치 및 Atlas 복귀를
확인했다 ([브라우저 저장·복원 기록](evidence/candidate-radius-save-ui.json)).
이 검사는 작업 패널과 서버 상태를 다루며 별도 Viser 렌더러의 시각 검증은
포함하지 않는다.

## 주변 혈관 검사와 적용 조건

반경 편집의 주변 검사는 후보에 포함된 원본 부분을 제외한 동맥·정맥·문맥
표면과 기존 추정 연결부를 대상으로 한다. 앱 요청 시 현재 Atlas 수정 표면까지
복사하여 검사 입력을 고정한다. 비교 대상의 식별자·좌표·면 배열 내용 해시를
기록하고, 계산 중 장면 generation이 바뀌면 결과를 폐기한다.

변형 전후의 접촉 삼각형 쌍을 비교하므로 같은 혈관과 접촉하더라도 새 삼각형
쌍은 별도로 검출한다. 표면 교차가 없는 근접 조합은 닫힌 표면 여부와 자기
접촉을 확인한 뒤 성분별 포함 검사를 수행한다. 원본 표면이 열려 있거나 검사가
불완전하면 `UNKNOWN`으로 남긴다.

| 결과 | 의미 | 앱 처리 |
|---|---|---|
| PASS | 공급된 주변 표면과 접촉·포함 없음 | 후보 적용 가능 |
| FAIL | 새 접촉·접촉 쌍 추가 또는 새로운 완전 포함 | 미리보기만 가능 |
| UNKNOWN | 검사 입력 또는 계산의 완전성 미확인 | 미리보기만 가능 |
| UNKNOWN | 기존 접촉 또는 포함의 접합 타당성 미확인 | 미리보기만 가능 |

기존 접촉이 있다는 사실을 해부학적 접합의 승인으로 취급하지 않는다.
같은 삼각형 쌍 내부에서 접촉 위치가 얼마나 달라졌는지는 아직 측정하지 않는다.
반경 편집 파일 복원도 현재 주변 표면에 대한 검사를 다시 통과해야 적용된다.
앞 절의 브라우저 저장·복원 기록은 이 주변 검사 조건을 추가하기 전의 기록이다.

주변 검사와 편집 상태·저장 복원을 포함한 검사 26개가 통과했다
([검사 기록](evidence/radius-context-tests.xml)).
실제 좌우 후보의 전체 주변 검사와 좌측 미통과 후보의 적용 차단·취소
브라우저 검증을 완료했다. 상세 범위와 남아 있는 문제는 아래에 기록한다.

복원은 최종 결과뿐 아니라 적용 순서의 각 중간 형상도 현재 주변 혈관과
검사한다. 중간 단계가 통과하지 못하면 전체 복원을 거부하고 기존 장면을
유지한다. 복원 후 되돌리기 이력에도 검사된 상태를 보관한다.
새 반경 계산에서는 이전 상세 주변 검사 기록을 제거하고 다시 계산한다.
현재 Atlas 수정 표면을 검사 입력에 반영하고 입력 사본이 원본 배열과
독립적인지도 검사했다.

실제 원본 주변 표면 비교는 좌우 각 807개, 총 1,614개를 완료했다
([전체 비교 기록](evidence/carotid-radius-context.json)).
새 접촉 쌍은 양쪽 모두 없었으나, 남아 있는 접촉은 좌측 8개·우측 9개이며
양쪽 추정 척추동맥 연결부는 열린 표면 때문에 포함 검사 `UNKNOWN`이다.
이 실행은 주변 입력 해시를 추가하기 전에 시작한 버전이며, 입력·출력 후보
파일 해시는 기록에 포함되어 있다.

접촉 위치를 원본 면 출처에 대조한 결과, 17개 주변 혈관과 접촉하는
결합 표면 삼각형은 모두 변형 전후 좌표가 동일했다
([접촉 위치 기록](evidence/radius-retained-contact-locations.json)).
이 결과는 원본 접합부의 타당성 또는 부피 중첩 승인이 아니다.
원본과 추정 연결부를 포함한 전체 표면 연결의 처리가 남아 있다.

미확정 두 조합을 진단하기 위해, 기존에 생성한 폐곡면 사례의 추정 척추동맥
연결부를 별도 검사 장면에서 사용했다. 각 연결부의 원래 측면 삼각형 4,560개는
그대로이고 끝면 삼각형 48개가 추가된 형상이다. 부모·파생 사례 revision과
후보 파일 해시를 확인한 뒤 좌우 각각의 경동맥과 비교했다.
이 두 조합은 모두 접촉·완전 포함 없음으로 `PASS`였다
([폐곡면 문맥 진단](evidence/closed-vertebral-context-diagnostic.json)).

이는 원본 열린 표면의 검사 결과를 덮어쓰지 않으며, 전체 주변 문맥을
통과시킨 결과도 아니다. 별도로 남아 있는 17개 원본 접촉을 해결하지 않는다.
원본 접촉에는 ACA·MCA·PCom·안동맥과 대동맥궁·팔머리동맥 등이 포함되어
분기 및 접합 처리와 함께 검토해야 한다.

## 단계적 분지 결합의 출처

경동맥 결합 표면에 주변 분지를 추가할 때, 새 Boolean 결과의 면 출처가
중간 결합 표면 ID에서 멈추지 않도록 원본 혈관 ID와 원본 면 번호로 변환한다.
같은 원본 이름이 서로 다른 입력에서 중복되거나 부모 면 번호가 범위를 벗어나면
거부한다. 이 연결 정보만으로 형상을 승인하지 않으며, 최종 삼각형의 정점과
법선 방향을 원래 입력 삼각형에 다시 대조한다.

3개 합성 체적을 두 단계로 결합한 검사에서 원본 삼각형 대조가 통과했고,
잘못된 부모 면 번호·모호한 출처 중복·알 수 없는 중간 입력의 거부를 포함한
관련 검사 8개가 통과했다
([검사 기록](evidence/nested-union-lineage-tests.xml)).
좌측 경동맥–ACA의 실제 소스 결합 후보는 별도 검사 장면에서 생성하며,
전체 주변 접촉 또는 해부학적 접합 검증으로 확대 해석하지 않는다.

좌측 실제 후보는 단일 폐곡면, 자기 접촉 검출 없음, 25,192개 면의 원본
삼각형 출처 대조 `PASS`를 확인했다
([좌측 경동맥–ACA 후보 기록](evidence/left-carotid-aca-union.json)).
원본 출처는 FJ1654M·FJ1682M·FJ3483·추정 좌측 목 연결부로 유지된다.
이 후보는 데모 표면을 대체하지 않았다. 후속 전체 주변 검사 결과는 아래에 기록한다.

현재 데모의 기존 경동맥 반경 후보에서는 좌측 주변 검사 `UNKNOWN` 결과가
표시되고 적용 버튼이 비활성화됨을 브라우저에서 확인했다. 직접 적용 API 요청도
HTTP 400으로 거부했고 미리보기 취소 후 원본 해시 일치와 Atlas 복귀를 확인했다
([브라우저 검사 기록](evidence/candidate-radius-context-ui.json)).
별도 Viser 렌더러의 시각 검증은 이 검사에 포함하지 않는다.

접촉 검사에서는 상대 표면 전체 범위와도 겹치지 않는 삼각형을 먼저 제외하도록
계산을 개선했다. 허용오차와 실제 삼각형 접촉 판정은 유지한다.
전수 삼각형 대조와 계산 한도·불완전 상태 검사를 포함해 관련 검사 16개가
통과했다 ([검사 기록](evidence/contact-broadphase-tests.xml)).
실제 전체 사례의 전후 결과 동등성은 아래 비교에서 확인했다.

접촉 검사 변경 후 전체 회귀 검사 1,100개가 통과했다
([전체 검사 기록](evidence/contact-context-full-tests.xml), 의존성 경고 355개).
그 이후 추가한 정적 후보 문맥 검사와 판정 형식 변경은 별도의 관련 검사
32개로 확인했다 ([기록](evidence/contact-context-focused-tests.xml)).
정적 검사는 결합 전후 위상이 달라진 후보를 주변 표면 전체에 직접 비교한다.
기존 접촉의 접합 타당성이 확인되지 않은 경우는 개발계획의 상태 형식에 맞춰
`UNKNOWN`으로 기록하고, 상세 사유를 별도 필드로 남긴다.

좌우 원본 반경 후보의 전체 주변 비교를 실행한 결과, 기존 1,614개 비교의
입력·출력 해시, 이웃별 접촉 삼각형 쌍·포함 판정·미확정 상태가 정확히
일치했다 ([동등성 기록](evidence/radius-context-broadphase-comparison.json)).
새 실행은 475.0초였으며 기존 실행 시간은 별도로 기록하지 않아 속도 향상률은
주장하지 않는다. 두 실행 모두 원래의 UNKNOWN 판정을 유지한다.

좌측 경동맥–ACA 결합 후보의 주변 혈관 806개 검사도 완료했다
([후속 주변 검사](evidence/left-carotid-aca-context.json)).
결과는 접촉 11개·추정 좌측 척추동맥 연결부 포함 미확정 1개로 UNKNOWN이다.
ACA가 결합 표면에 포함되면서 ACom(FJ1655), 뇌량변연동맥(FJ1676M),
내측전두기저동맥(FJ1690M), 뇌량주위동맥(FJ1699M)과의 접합이 추가 대상이 된다.
이는 비교 표면의 범위가 넓어진 결과이며, 기존 경동맥 후보와 접촉 개수만
비교하여 악화 또는 개선으로 판정하지 않는다. 이들 원본 접촉을 해부학적
접합으로 승인하거나 자동으로 검사에서 제외하지 않았다.

## ACA 후속 접합 입력

ACom(FJ1655), 좌측 뇌량변연동맥(FJ1676M), 내측전두기저동맥(FJ1690M),
뇌량주위동맥(FJ1699M)의 원본 해시와 폐곡면 조건을 확인했다
([입력 검사](evidence/aca-branch-inputs.json)).
네 표면 모두 양의 체적을 갖지만, 이 조건은 자기 접촉 검사나 실제 ostium의
승인을 뜻하지 않는다. 현재 관계 목록에는 ACom–ACA 문헌 관계만 등록되어
있고 세 원위 분지의 대응 관계는 미등록이다.

우선 ACom만 경동맥–ACA 후보에 추가하는 별도 결합 검사를 수행한다.
`build_left_carotid_aca_union.py --acom`은 기존 후보 해시와 원본 출처를 확인하고,
원본 면 번호를 보존하여 새 결합·자기 접촉·출처 검사를 수행한다.
기존 후보와 데모 표면을 덮어쓰지 않는다. 우측 ACA와의 접합 및 전체 주변
검사는 이 생성 단계에 포함하지 않는다.

문헌 확인 범위:

- [Rhoton·Perlmutter, 1980](https://pubmed.ncbi.nlm.nih.gov/6111033/): PubMed 서지·초록을 확인했다. ACom 영역의 50개 뇌 표본 연구이며, 이 Atlas 표본의 접합 좌표를 제공하는 자료로 취급하지 않는다.
- [Perlmutter·Rhoton, 1978](https://pubmed.ncbi.nlm.nih.gov/671075/): 검색에서 확인된 초록은 50개 대뇌 반구의 원위 ACA 해부 연구를 설명한다. 현재 본문 상세 분지·도판을 확인하지 못해 세 원위 분지의 Atlas 대응을 새로 승인하지 않았다.
- 기존 전방순환 자료(PMID 34437363)는 서지를 확인했지만 연결된 PMC 본문은 접근 확인 화면으로 반환되었다. 해당 본문의 상세 관계를 이번에 재검증했다고 표시하지 않는다.

ACom 추가 후보 생성은 완료했다
([결합 검사 기록](evidence/left-carotid-aca-acom-union.json)).
단일 폐곡면, 자기 접촉 검출 없음, 25,306개 면의 원본 출처 대조 PASS이며,
다섯 원본 출처를 보존했다. 이는 우측 ACA의 연결 또는 A1/A2 경계 승인이 아니다.
주변 혈관 805개 검사도 완료했다
([ACom 후보 주변 검사](evidence/left-carotid-aca-acom-context.json)).
접촉 12개와 미확정 2개가 남아 UNKNOWN이다. 미확정은 우측 뇌량주위동맥
FJ1699의 자기 접촉 검사 미통과 또는 불완전 상태와 열린 추정 좌측 척추동맥
연결부 때문이다. 이 원본 상태를 통과로 변경하거나 데모 표면을 교체하지 않았다.

## 양측 전방순환 중심부 후보

좌측 경동맥–ACA–ACom 후보와 우측 경동맥 후보를 부모로 사용하고,
우측 ACA(FJ1654) 및 양측 MCA 근위부(FJ1692/FJ1692M)를 추가하는
별도 후보 생성을 시작했다. 기존 관계 모델의 좌우 ICA 말단 분기와 ACom
연결에 해당 ID가 실제로 등록되어 있는지 확인하며, 관계의 표본 상태
`unverified`를 그대로 보존한다. 원위 분지 또는 A1/A2·M1/M2 경계를
새로 추정하여 확정하지 않는다.

두 독립된 부모 결합과 추가 연결부를 다시 합친 합성 예제에서 원본 출처를
보존하는 검사를 추가했다. 실제 후보는 단일 폐곡면으로 생성되었고,
자기 접촉 검출 없음 및 59,132개 면의 원본 출처 대조 PASS를 확인했다
([생성 기록](evidence/anterior-core-union.json)).

11개 원본 출처에 등록된 중심선 전체를 고정된 후보 표면과 대조했다.
총 2,812개 선분의 구간 포함 검사에서 11개 경로 모두 PASS이며,
외부 증거점과 미확정 구간은 0개다
([중심선 검사](evidence/anterior-core-paths.json)).
추정 목 연결은 기존 선언 경로를 사용하고 나머지는 저장된 원본 경로를 사용했다.
검사 통과를 위해 중심선을 후보에 맞춰 이동하거나 다시 추출하지 않았다.
이는 해당 중심선의 기하학적 포함 검사이며, 대퇴부터의 전체 경로 또는
12개 해부학적 구간 경계 승인을 뜻하지 않는다.

[주변 혈관 검사](evidence/anterior-core-context.json)는 799개를 검사하여
접촉 25개와 미확정 2개로 UNKNOWN이다(330.74초).
미확정은 양측 추정 척추동맥의 열린 표면이며, 이를 분리 또는 통과로 세지 않는다.
[접촉 위치·출처 기록](evidence/anterior-core-contact-locations.json)은
후보 해시와 검사 파일 해시를 연결하고, 접촉한 삼각형의 원본 혈관과 공간 범위를 기록한다.
범위 상자는 접촉한 삼각형 전체의 범위이며 정확한 교차 곡선이 아니다.

검출된 접촉은 양측 ICA, ACA, MCA 근위부, 총경동맥의 원본 면에서 유래했다.
추정 목 연결부 또는 ACom에서 검출된 접촉은 없으나, 미확정 두 조합까지
접촉 없음으로 확장하지 않는다. 다음 처리 대상은 다음과 같이 구분한다.

| 후보 원본 부분 | 접촉한 주변 원본 |
|---|---|
| 좌우 ACA | 뇌량변연·내측전두기저·뇌량주위동맥 |
| 좌우 MCA 근위부 | 도엽부 두 부분 및 하위 말단 분지 줄기 |
| 좌우 ICA | 전맥락·안동맥·후교통동맥 및 MCA 전외측중심가지로 명명된 부분 |
| 좌측 총경동맥 | 대동맥궁 |
| 우측 총경동맥 | 팔머리동맥·우측 쇄골하동맥 |

이 표는 Atlas 이름과 기하학적 접촉의 대조이며 해부학적 연결 승인표가 아니다.
특히 이름상 MCA 가지가 ICA에 접촉하는 항목과 우측 총경동맥–쇄골하동맥
접촉을 이름만으로 자동 결합하지 않는다. 원본 접합 범위와 관계 근거를 확인한다.
관련 중심선 포함·면 출처·중복 면 처리 13개 회귀 검사는 PASS다
([실행 기록](evidence/anterior-core-support-tests.xml)).

## 우측 뇌량주위동맥 원본 중복 면

FJ1699에서 다른 면과 분리된 역방향 중복 삼각형 두 쌍을 확인했다
([원본 검사](evidence/pericallosal-source-self-contact.json)).
별도 파생 복사본에서 원본 면 번호 0, 24, 32, 33만 제거했다.
나머지 1,076개 삼각형 좌표와 계산 체적 126.67319163186248 mm³는 유지됐고,
파생 표면의 자기 접촉 검사는 통과했다
([파생 검사](evidence/pericallosal-source-cleanup.json)).
독립 중복 면 제거·정상 표면 거절·기존 표면에 붙은 중복 면 거절의
3개 회귀 검사가 통과했다([검사 결과](evidence/double-sheet-cleanup-tests.xml)).
원본 Atlas와 데모는 변경하지 않았다. 파생 복사본의 주변 혈관 검사는 NOT RUN이다.

## 팔머리 분기 확장 후보

전방순환 중심부 후보에 원본 팔머리동맥 FJ3417과 우측 쇄골하동맥 FJ3579를
추가한 별도 합성 후보를 생성했다. 공통 분기 관계의 문헌 근거는
[원본 분지 대조](AMBIGUOUS_BRANCH_CONTACTS.md)에 기록했고, 표본 연결 상태는
`unverified`를 유지한다. 총경동맥–쇄골하동맥의 독립 직접 edge를 추가하지 않았다.

[결합 결과](evidence/anterior-brachiocephalic-union.json)는 단일 폐곡면,
자기 접촉 검출 없음, 59,628개 면의 원본 출처 대조 PASS다.
부모 후보 해시 및 13개 원본 출처의 대응을 보존했다.
[중심선 검사](evidence/anterior-brachiocephalic-paths.json)는 등록된 13개 경로의
3,265개 선분 모두 PASS이며 외부 증거점·미확정 구간이 없다.
이 후보의 전체 주변 검사는 NOT RUN이며 부모 후보의 검사를 상속해 통과로
표시하지 않는다. 궁·흉부·복부·장골·대퇴 구간은 아직 이 표면에 포함하지 않았다.
원본·기존 후보·데모는 유지했다.
