# 단면 목표 달성 검사

`check_section_targets`는 원본·요청·측정 단면의 전체 ID 집합과 동일 평면을 확인하고 면적 등가 반경 배율을 비교한다. 호출자가 `absolute_scale_tolerance`를 명시해야 하며 임상적 기본값은 제공하지 않는다.

- PASS: 모든 입력 단면이 측정되었으며 각각의 배율 차이가 명시된 허용오차 이내.
- FAIL: 측정 가능한 단면 하나 이상에서 허용오차 초과.
- UNKNOWN: 단면 누락·중복, 미측정, 비유한/비양수 면적 또는 평면 불일치.

FAIL과 UNKNOWN이 함께 있으면 상태는 FAIL, `complete`는 false다. PASS는 제공된 단면의 크기 조건에만 해당하며 충돌·분기 보존의 승인과 다르다. 호출자는 원본의 전체 필수 단면 목록을 제공해야 한다.

[검사 기록](evidence/section-target-tests.xml): 관련 33개 테스트 PASS. 면적 비율과 반경 비율 구분, 목표 미달, 순서 변경, 누락·중복·잘못된 좌표 및 입력 불변성을 확인했다.

실제 후보 검사 스크립트 `inspect_closed_edit_sections.py`에 선택 인자 `--absolute-scale-tolerance`를 연결했다. 이를 생략하면 기존 기술적 측정만 수행한다. 값을 전달한 결과는 별도 파일에 기록하여 기존 측정을 덮어쓰지 않는다. 실제 후보에 대한 허용오차는 이번 구현에서 정하지 않았으며 기존 14개 후보의 수용 상태도 바꾸지 않았다.

앱의 적용 거부·원본 유지 경로에 연결하는 작업은 남아 있다.

## 적용 전 후보 실측 검사

기존 Atlas 편집 검사 모듈에 `require_section_target_match`를 추가했다. 호출자가 전달한 후보 표면에서 실제 단면을 추출하고 목표를 대조한다. 후보에 이전 PASS 메타데이터가 있어도 이를 신뢰하지 않고 다시 측정한다.

FAIL 또는 UNKNOWN이면 기존 `AtlasEditCheckFailure`를 발생시키고 후보의 `edit_checks.section_targets`에 이유를 남긴다. 호출자는 활성 상태로 교체하기 전의 별도 후보에 적용해야 한다. 이 함수 자체는 활성 상태·원본·저장 파일을 변경하지 않는다.

[후보 실측 검사 기록](evidence/section-target-guard-tests.xml): 관련 25개 테스트 PASS. 실제 크기 미달 후보 거부, 목표와 일치하는 합성 표면 통과, 단면 추출 불가 후보 거부와 입력 보존을 확인했다. 일반 Atlas 반경 조절은 아직 비원형 구간 편집 계약을 사용하지 않으므로 이 검사를 기존 조절기에 임의로 적용하지 않았다. 앱 구간 편집·전체 충돌 검사의 통합은 남아 있다.
