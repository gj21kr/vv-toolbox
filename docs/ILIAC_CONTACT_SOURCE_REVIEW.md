# 장골 접촉 6쌍의 원본 표면 대조

## 결과

기존 구형 포락체 겹침 witness 주변에서 실제 원본 mesh의 축상 단면 52개를
검사했다. 두 그림의 대표 단면 18개를 직접 확인했다. **6쌍 중 5쌍은 원본
윤곽에서도 교차가 검출됐다.** 따라서 모든 경고를 합성 과정에서 새로 생긴
관통으로 해석하거나, 겹침을 없애려고 무조건 혈관을 이동해서는 안 된다.

원본 요소의 표면 교차는 열린 내강·올바른 연결 그래프의 증명이 아니다.
특히 대동맥 이름의 중첩 요소는 중복 표현과 실제 분지를 별도로 판독해야 한다.
교차가 없는 단면도 포함·접촉·다른 평면의 교차를 배제하지 않는다.

## 외장골–고환동맥의 불일치

겹침 witness의 고환동맥 중심선 점은
`[-56.886770, -87.071586, 880.003497] mm`이며 저장 반경은 **1.160954 mm**다.
이 점에서 고환동맥 자신의 원본 삼각형 표면까지의 최단 무부호 거리는
**0.002065 mm**였다. 원본 중심에 놓인 점으로 보기 어려운 위치이며,
원본 단면과 witness 구 단면을 겹쳐 그려 위치 불일치를 확인했다.
점이 원본 표면의 어느 쪽인지는 이 무부호 거리만으로 판정하지 않는다.

외장골 witness 반경은 **5.059644 mm**, 자기 원본 표면까지 거리는
**4.297428 mm**다. 이는 원형 반경 모델이 원본 비원형 단면을 정확히 보존하지
않음을 보여준다. 경고를 없애기 위해 반경만 축소하면 고환동맥의 중심선 위치
문제를 가릴 수 있으므로 기본 보정으로 채택하지 않는다.

다음 수정은 고환동맥의 해당 경로를 원본 단면 중심과 대조하고, 원본을 보존한
별도 합성 중심선 후보를 만드는 것이다. 이후 전체 경로의 원본 형상 이탈,
접합 끝점 보존 및 외장골과의 간격을 함께 검사한다.
