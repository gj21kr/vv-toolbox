# 분기부 낭상 표면 후보

```text
vv-case bifurcation-surface case.snapshot.json specification.json candidate.npz --spacing-mm 0.16 --max-grid-voxels 2000000
```

간격과 예산은 사용자가 지정하는 공학적 계산 조건이다. 위 간격은 합성 검사 예시이며 실제 혈관의 기본값이나 임상 권장값이 아니다. 출력 NPZ에는 `vertices_mm`, `faces`, JSON 문자열 `metadata`가 포함된다. 메타데이터는 원본 revision·좌표계·전체 입력 명세·대상 분지 ID·치수와 간격 검사 결과·미검증 항목을 보존한다. 명령줄 성공 출력도 `CANDIDATE`이며 최종 사례 수용을 의미하지 않는다.

기존 출력 파일을 덮어쓰지 않고 임시 파일 작성 완료 후 새 파일로 게시한다. 명세 불일치나 검사 실패 시 후보 파일을 게시하지 않는다. 입력 사례 파일은 변경하지 않는다. `numpy.load(..., allow_pickle=False)`로 읽을 수 있다.

`build_bifurcation_candidate()`는 명시된 분기 설계와 연결된 모든 중심선·반경으로 단일 내강 표면 후보를 만든다. 각 분지를 캡슐 합집합으로 구성하고 목 아래 매몰 구간에서 주머니와 부드럽게 합친다. 분지 끝은 닫힌 캡으로 표현한다. 원본 Atlas 삼각형을 수정하는 기능은 아니다.

명세의 revision, 모든 분지 출구, 목 윤곽·매몰 조건을 확인하고 반경·목·전이 범위를 세 격자 이상으로 분해한다. 계산 예산 초과, 계산 영역 잘림, 분리된 내강, 양의 닫힌 표면 생성 실패는 오류로 처리한다. 출구 보호 영역의 분리가 미확인인 경우에도 생성을 거부한다.

내강 격자의 면 연결 성분을 검사하고 접합점·목·주머니 내부·모든 출구 중심이 같은 성분인지 확인한다. 이는 표본 연결 검사이며 연속 경로의 최소 내경을 증명하지 않는다. 테스트에서는 생성된 삼각형 표면에 대해서도 해당 지점의 내부 포함 여부를 별도로 확인한다.

생성기 `bifurcation-union-2`는 실제 삼각형 표면과 명시된 목 평면의 단면에서 목 폭·깊이를 측정한다. 평면 위로 잘라낸 삼각형 표면의 범위에서 주머니 폭·깊이·수직 높이를 측정한다. 허용오차는 기존 단일 부모 생성기와 같은 격자 간격의 두 배이며 임상 허용범위가 아니다. 단면이 하나가 아니거나 치수가 허용오차를 벗어나면 거부한다. 부모 분지가 목 평면 위에 존재할 가능성이 있으면 그 분지를 주머니로 측정하지 않고 미확인 오류로 거부한다.

생성기 `bifurcation-union-3`는 분기 노드에 직접 연결되지 않은 모든 구간에 대해 주머니·전이 영역과의 보수적 간격 하한을 계산한다. 목 좌표계의 지지 상자와 각 중심선 선분 전체 사이의 최소 거리를 구하고 선분 양 끝의 큰 반경을 뺀다. 끝점만 비교하지 않는다. 여유는 격자 간격의 두 배이며, 모든 구간이 이 여유보다 멀 때만 이 검사가 `PASS`다. 중심선이 없거나 여유를 보장하지 못하면 `UNKNOWN`으로 기록하고 생성을 거부한다. 보수적 영역의 겹침은 실제 충돌을 확정하는 결과가 아니다. 주변 구간이 하나도 없는 합성 사례는 `NOT RUN`으로 기록한다.

결과는 `CANDIDATE`, `provenance=estimated`, `accepted_for_generation=false`다. 연속 분지 개통, 원본 Atlas 삼각형 간 충돌, 전체 사례 비겹침, 해부학적 수용은 아직 검증되지 않았다. 사례 저장·앱 적용·마스크 출력에 자동 연결하지 않는다. 기존 병변이 있는 사례는 통합 병변 처리가 구현될 때까지 거부한다.

[검사 결과](evidence/bifurcation-surface-tests.xml): 세 방향 합성 분기에서 하나의 닫힌 내강 생성, 원본 보존, 보호 출구와 주머니의 내부 포함, 분지 저장 방향 반전의 형상 일관성, 부착 실패 및 예산·해상도 제한을 확인한다. 실제 Atlas 분기 결과를 검증한 자료는 아니다.

[치수 검사 결과](evidence/bifurcation-dimension-tests.xml): 실제 생성 표면의 목·주머니 치수, 인위적으로 늘린 표면의 치수 실패, 목 평면 위 부모 분지의 측정 거부, 강체 변환 후 측정 일관성을 포함한다.

[주변 간격 검사 결과](evidence/bifurcation-clearance-tests.xml): 관련 검사 36개 통과. 끝점이 멀지만 선분 중간이 지지 영역을 관통하는 경우, 떨어진 주변 혈관, 미해결 중심선, 주변 구간이 없는 경우, 선분 방향 반전 및 기존 표면·부착 검사를 포함한다.

[명령줄 출력 검사 결과](evidence/bifurcation-export-tests.xml): 37개 통과. 저장 후 다시 읽은 실제 표면의 닫힘과 출구·주머니 내부 포함, 원본 불변, 메타데이터 보존, 덮어쓰기 거부, 변조된 revision의 출력 거부와 임시 파일 정리를 포함한다. 공통 명령줄 분기 변경에 대해 기존 단일 부모 낭상 표면 검사도 실행했다.
