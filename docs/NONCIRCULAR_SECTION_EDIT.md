# 비원형 단면 크기 편집

`vv_toolbox.profile_scale.scale_section`은 측정된 단면 윤곽을 중심선 station 기준으로 확대·축소하여 별도 합성 단면을 반환한다. 원본 입력, 중심선 위치와 단면 평면은 보존한다.

## 파라미터 의미

- `factor`: 단면 평면 내 두 축에 동일하게 적용하는 길이 배율. 1은 동일 크기다.
- `area_equivalent_radius_mm`: 실제 윤곽 면적과 동일한 면적을 가진 원의 반경. 윤곽을 원으로 대체하지 않는다.
- `center_boundary_distance_mm`: 중심선 station에서 단면 경계 선분까지의 최소 거리. 3D 전체 표면까지의 최소 거리와 다르다.
- `contour_uv_mm`, `contour_xyz_mm`: 원래 비원형 형태와 편심을 배율에 맞게 유지하는 실제 편집 결과다.

면적은 배율의 제곱, 두 반경 지표는 배율에 비례한다. 편심 단면의 무게중심은 중심선 station을 기준으로 이동한다. 측정 메타데이터는 결과 윤곽에서 다시 계산한다.

단면이 측정되지 않았거나 좌표계·폐곡선·세계 좌표 대응이 불일치하면 거부한다. 결과에는 합성 출처, 연산 버전과 배율을 기록한다. 양의 배율이라는 수학적 조건은 부위별 질환 허용 범위를 의미하지 않는다.

## 검증 및 적용 범위

[검사 기록](evidence/profile-scale-tests.xml): 편심 직사각형, 원본 보존, 역배율 복원, 잘못된 입력 거부 및 기존 단면 추출·연결 검사 **25개 PASS**.

단면 편집 연산을 구현한 단계다. 앱 조절기, 실제 해부학적 접합점, 편집 후 연속 표면 충돌 검사와 실패 복원은 아직 연결하지 않았다. `junction_validation`, `collision_validation`, `anatomical_validation`은 NOT RUN으로 반환한다. 전체 혈관 편집 수용 완료가 아니다.

## 구간 편집 연산

`scale_profile_interval`은 첫 입력 단면부터의 실제 호길이(mm)로 시작·끝 위치를 받는다. 혈관 입구부터의 거리가 아니므로 호출자가 좌표 기준을 명시해야 한다. 입력 단면은 연속된 ID를 가져야 하며 미측정 단면을 건너뛰지 않는다.

구간 양 끝의 배율은 1, 중앙 목표 배율은 `factor`다. 양 끝과 중앙에서 1·2차 미분이 연속인 quintic 함수로 보간한다. 중앙에 표본 단면이 없으면 실제 표본은 목표 배율에 도달하지 않을 수 있다. 이 함수의 연속성은 연결된 삼각형 표면의 곡률 연속성을 보장하지 않는다.

범위 밖과 경계 단면은 원래 데이터 그대로 복사한다. 보호 단면 ID가 변경 구간 내부에 있으면 전체 연산을 거부한다. 보호 목록은 호출자가 전달하며 해부학적 분기점을 자동 식별하지 않는다. 검증·결과 생성 중 원본은 변경하지 않는다.

[구간 편집 검사](evidence/profile-interval-tests.xml): 관련 33개 PASS. 불균일 간격의 물리적 거리, 보호 단면 거부, 동일 배율 원상 유지와 결과 윤곽의 기존 loft 입력 연결을 검사했다. 합성 직사각형 loft에서 끝단 링과 face 연결은 보존되고 중앙 형상은 변경됨을 확인했다. 실제 혈관 적용·충돌 검사·앱/undo 연결은 아직 미완료다.
