# 구현 현황과 실행 순서

기준일: 2026-10-21. 기준: [개발계획서](DEVELOPMENT_PLAN.md). **M1–M7 전체 완료로 판정한 단계는 없다.** 모듈 검사와 전체 해부 모델의 수용 조건은 구분한다.

## 단계별 현황

| 단계 | 현재 구현 | 남은 주요 산출물 |
|---|---|---|
| M1 범위·자료 조사 | 자료 비교·원자료 검사·질환 문헌 조건 기록 | 완전한 문헌 변이/질환 registry와 부위별 지원 범위 |
| M2 기준 모델·계약 | 사례·snapshot·구간 분할·마스크 계약 | 실제 경계 적용, 전체 해부 구간 라벨과 연결 근거 |
| M3 기준 경로 | 순서 지정 instance 경유 검사, 미확인/합성 구분, 좌우 경동맥 체적 결합·경로 포함 검사 및 좌측 경동맥–ACA 별도 결합 후보 | 실제 네 대퇴–경동맥 조합과 ACA/MCA 전체 도달·접합·충돌 검사, 원본 분기 접촉과 12개 구간 경계 처리 |
| M4 Atlas 편집기 | 검색·선택·관계 표시, 구간 편집·복원, 결합 표면 반경 편집, 저장 표면 3D 표시와 중심선 평활화, 단일 원본의 벽 굴곡/회전 및 열린 구간 체인의 공동 변형·undo/redo·재저장, 비동기 주변 검사·작업 기록 보존·이어 보기 | 공동 편집의 실제 모델 검증과 데모 반영, 분기하는 원본의 공동 변형, 전체 그래프·접합·주변 검사 수용, 실제 전체 비동기 검사 UI 검증, 수용된 통합 모델의 전체 편집–출력 흐름 |
| M5 변이·질환 | 단일/다중 동심성 협착·수동 방추형 확장 프로파일, 병변 간 보수적 간격 검사 | 낭상·분기부 병변·근거 기반 변이와 부위별 파라미터 |
| M6 일괄 생성·출력 | 목표 통과 수 batch, 표면/마스크/병변 라벨/고해상도 ROI 출력, 저장 마스크의 좌표·사례·라벨 검증, 명시적 생성 미승인 사례 거부 | 실제 전체 대상 동맥·해부 구간 라벨·분포 보고와 전신 성능 검증 |
| M7 다중 기준 모델 | 동일 기준 모델 파생물의 split 계약 검사 | 독립 원본 등록과 실제 다중 기준 모델 관리 |

## 현재 근거

- 저장 사례의 WebGL 표면 표시, 변경 중심선의 등록 표면 내강 검사와 연결 갱신까지 포함한 Docker 전체 Python 회귀: **1,242 PASS / 0 FAIL / 0 ERROR / 0 SKIP**, 151.11초. [실행 결과](evidence/regression-saved-surface.json), [JUnit](evidence/regression-saved-surface.xml), [로그](evidence/regression-saved-surface.log), [소스 해시](evidence/regression-saved-surface-sources.json). 소스·테스트·스크립트 및 프로젝트 설정 524개 파일이 검사 전후 동일했다. 실제 브라우저 왕복·표면 표시·중심선 편집 기록은 [접근 사례 문서](ACCESS_CANDIDATE_CASE.md)에 별도 기록했다. 전체 해부학적 수용과 M1–M7 완료를 뜻하지 않는다.

- 굴곡/비틀림 후보, 검사 사례 다운로드, 생성 미승인 입력 차단 후 Docker 전체 회귀 **1,231 PASS / 360 warnings, 158.74초**. [결과](evidence/regression-shape.json), [JUnit](evidence/regression-shape.xml), [소스 해시](evidence/regression-shape-sources.json). 검사 전후 소스/테스트 298개 파일의 동일성을 확인했다. 경고는 skimage/NumPy deprecation이며 실제 해부학적 수용과 전체 편집 기능 완료를 뜻하지 않는다.

- [검사 사례 다운로드](ACCESS_CANDIDATE_CASE.md): 실제 기본 후보와 반경 1.05배 후보의 브라우저 다운로드·독립 재로드·표면/그래프/audit 보존 PASS. 실패 후보의 적용 차단과 생성 미승인 상태를 유지한다. 저장 기능 통과가 형상 수용은 아니다.
- [굴곡·비틀림 후보](ACCESS_SHAPE_EDIT.md): 실제 대퇴 bend 0.25 mm는 자기 접촉 미검출 및 전체 경로 65/65 포함 PASS다. 전체 788개 CLI 주변 검사는 FAIL이며 접촉 80개·미확인 11개가 남아 있다. 단일 구간 편집은 앱 왕복을 확인했고, 분할 구간 공동 편집은 합성 사례의 별도 브라우저 경로에서 확인했다. 실제 전체 비동기 UI 검사는 실행 중이다. twist 5°와 결합 조건은 최대 이동 1 mm 초과로 FAIL. 31개 단면의 반경 비율 0.997244–1.000026은 측정값이며 반경 보존 수용은 NOT RUN이다.

- 마스크 ROI·winding 묶음 개선·재로드 및 사례 연결 검사 후 Docker 전체 회귀 **1,204 PASS / 360 warnings, 161.99초**. [결과](evidence/regression-mask-archive.json), [JUnit](evidence/regression-mask-archive.xml), [실행 소스 해시](evidence/regression-mask-archive-sources.json). 실행 중 소스/테스트 292개 파일의 변경 없음 확인. 경고는 skimage/NumPy deprecation이다. 실제 해부 모델 수용과 브라우저 검증은 별도다.

- [접근 그래프 접합 품질](evidence/access-graph-junctions.json): 새 접합 전이 37개에서 최대 국소 방향 전환 159.64°(팔머리–우측 총경동맥), 최대 반경 차이 0.335881 mm(좌측 장골)를 확인했다. 직선 연결 21개 반경-ball envelope는 FAIL이며 실제 튜브 벽 이탈의 직접 증명은 아니다. 최근접 샘플 연결을 매끄러운 최종 경로로 승인하지 않고 부착 위치·곡선 보정이 필요하다.

- [합성 접근 그래프](evidence/access-sample-graph.json): 원본 28개 중심선의 좌표·반경을 보존하며 21개 합성 직선 연결과 1개 노드 alias를 구성했다. 좌우 대퇴 × 좌우 경동맥 네 조합에서 ACA/MCA 근위부로 향하는 8개 경로를 찾았다. 원본 근거의 미확정 상태를 보존하므로 판정은 UNKNOWN이다. [앱 중심선·경로 표](evidence/access-graph-ui.json)의 실제 표시와 전환을 확인했다. A3/M3 도달·반경 envelope·접선 연속성·전체 사례 출력은 남아 있다.

- [대퇴–전방순환 통합 표면](evidence/femoral-anterior-union.json): 원본 22개 출처를 포함한 67,128개 면의 단일 폐곡면 후보 생성, 자기 접촉 검출 없음, 원본 면 출처 대조 PASS. [모든 등록 중심선](evidence/femoral-anterior-paths.json)은 동시 질의량 조정 후 28개 경로·9,456개 선분 PASS다. [주변 검사](evidence/femoral-anterior-context.json)는 788개 모두 계산했고 접촉 80개·미확인 11개로 UNKNOWN이다. 접촉이 정상 분지인지 비접합 관통인지는 별도 판정이 필요하다. 네 접근 조합의 연결 그래프, 전체 ACA/MCA 구간·분지, 해부 라벨 및 편집–출력 수용은 아직 완료되지 않았다.

- [전체 접근 경로 원본 입력](ACCESS_TRUNK_CONTACTS.md): 대퇴–장골–대동맥–경동맥 13개 부분의 78개 원본 표면 조합 검사를 완료했다. 16개 조합에 접촉이 검출되며 네 접근 조합을 구성할 연속 입력 순서를 기록했다. 검사 완전성 PASS이며 내강 연결·전체 경로 통과 승인은 아니다. 별도 하행 대동맥 FJ3427의 중복 범위와 총장골 공통 분기부는 추가 확인이 필요하다.

- [분지 이름–원본 접촉 대조](AMBIGUOUS_BRANCH_CONTACTS.md): 원본 13개 조합을 검사했다. FJ1662/M은 ICA·MCA 모두 접촉하고 FJ1663/M은 ICA에서만 표면 접촉이 검출된다. 우측 팔머리 분기의 세 부분도 모두 서로 접촉한다. 문헌상 공통 분기 관계와 단순 표면 접촉을 분리하며 이름 변경·직접 edge 추가·표본 연결 승인은 하지 않았다.

- [양측 전방순환 중심부 후보](evidence/anterior-core-union.json): 11개 원본 출처를 결합한 단일 폐곡면 후보, 자기 접촉 검출 없음, 59,132개 면의 원본 출처 대조 PASS. [중심선 포함 검사](evidence/anterior-core-paths.json)는 등록된 11개 경로의 2,812개 선분 모두 PASS다. - [경동맥 결합 및 선택 부분 편집](UNION_SOURCE_MODIFICATION.md): 실제 단면 윤곽을 사용한 좌우 경동맥 결합 후보와 원본 면 출처 대조, 중심선 구간 포함 검사를 수행했다. 반경 편집의 미리보기·적용·복원·저장/재로드를 구현했으며 주변 검사 조건 추가 후 좌측 미통과 후보의 버튼/API 적용 차단과 취소를 브라우저에서 확인했다. 좌우 전체 주변 비교 1,614개에서 새 접촉 쌍은 없지만 기존 접촉 17개와 열린 추정 척추동맥의 포함 미확정 2개가 남아 전체 수용은 UNKNOWN이다. 별도 폐곡면 문맥 진단의 두 조합 PASS를 전체 주변 통과로 확대하지 않는다.

- [좌측 경동맥–ACA 후보](evidence/left-carotid-aca-union.json): 단일 폐곡면, 자기 접촉 검출 없음, 25,192개 면의 원본 출처 대조 PASS. 별도 후보이며 데모 표면에 적용하지 않았다. [주변 혈관 806개 검사](evidence/left-carotid-aca-context.json)는 접촉 11개·열린 추정 연결부 1개 미확정으로 UNKNOWN이다. ACA 추가 시 ACom·뇌량변연·내측전두기저·뇌량주위동맥의 추가 접합 처리도 필요하다.

- [접촉 검사 결과 동등성](evidence/radius-context-broadphase-comparison.json): 계산 전 공간 선별을 추가한 뒤 실제 좌우 1,614개 비교의 후보 해시·접촉 쌍·포함 판정·미확정 상태가 기존 기록과 정확히 일치했다. 실행 시간은 475.0초이며 기존 실행 시간이 기록되지 않아 속도 향상률은 주장하지 않는다.

- [사례의 원본·파생 표면 출력](CASE_SOURCE_SURFACES.md): 추정 포함 521개 표면·1,085개 경로의 브라우저 캡처 PASS. 원본 517개는 좌표 보존 인덱스 정규화 후 마스크 topology 조건 만족, 추정 연결 4개는 열린 표면. 1 mm probe의 기존 조밀 membership 메모리 추정 약 148 GB로 전체 실행 NOT RUN. 공간 분할·희소 출력, 추정 연결 체적, 실제 수정 표면 캡처·구간 분할은 미완료다.

## 다음 실행 순서

접근 후보의 고정 대퇴 ROI 마스크(33³, 0.5 mm)는 35,937 voxel의 독립 ray 판정과 차이 0개, 저장/로드 및 affine 검사 PASS다. 해부 구간은 미확인 상태를 보존한다. Winding 묶음 개선 관련 검사 31개와 실제 표면의 고정 729 voxel 비교도 PASS다. [범위와 결과](ACCESS_CANDIDATE_CASE.md). 이 추가 검사는 위 전체 회귀 실행 이후 수행됐으며 전체 모델·구간별 마스크 완료를 뜻하지 않는다.

1. 경계 운영 후보와 실제 source-part 접합의 근거를 보존하는 합성 기준 모델을 구성하고 네 접근 경로를 연결한다. 원본에 없는 접합·경계를 합성 출처로 기록한다.
2. 공유 접합 collar의 수용 범위를 실제 모델에서 확인하고, 자기 교차·접합 연속성·최종 표면 검사와 편집 실패 복원을 완성한다.
3. 부위별 지원 가능한 문헌 프리셋 및 동맥류·분기부 병변을 구현하고 다중 병변 조합을 검증한다.
4. 전체 대상 동맥의 geometry·graph·해부 구간/병변 라벨·마스크·고해상도 ROI를 일관된 사례로 출력한다. 배치 분포·실패 기록과 전신 자원 사용을 검사한다.
5. 원본·합성·편집 사례를 앱에서 명확히 선택하고 저장·재로드·검사·출력하는 통합 흐름을 완성한다.
6. 독립 기준 모델을 등록하고 파생물의 동일 split을 검증한다. 학습·성능 평가는 범위 밖이다.

Python·형상 검사는 Docker에서 실행한다. UI 변경은 실제 브라우저로 검증하고, 코드 존재나 부분 시험 통과를 단계 전체 완료로 표시하지 않는다.
