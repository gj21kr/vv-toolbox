# 화면 언어

메인 화면과 저장 사례 작업창의 오른쪽 상단에서 EN / 한국어를 선택한다. 선택은 브라우저의 `vv-ui-language` 설정에 저장되고 새로고침·화면 이동 후에도 유지된다. 같은 브라우저의 다른 탭에도 반영된다. 저장 설정이 없으면 브라우저의 한국어 설정을 따르고 그 외에는 영어를 사용한다.

언어 전환은 로컬 UI 문구만 변경한다. 서버에 편집 요청을 보내지 않으며 혈관 ID·입력값·사례 snapshot·검사 판정 코드를 변경하지 않는다. Atlas의 원본 혈관명은 출처의 명칭을 보존한다.

메인 화면과 작업창의 초기 고정 문구 전체를 번역 목록과 대조했다. 동적으로 생성되는 주요 선택·편집 메뉴와 일부 검사 진행 문구도 지원한다. 나머지 동적 안내, 서버 오류 메시지 및 3D 뷰어 내부 문구의 전체 번역은 진행 중이다. 아직 번역하지 않은 문구는 원래 문구를 표시한다.

- [초기 고정 문구와 자산 검사](evidence/ui-language-static-tests.xml): 2 PASS.
- [브라우저 검사](evidence/ui-language-browser.json): 전환·새로고침·화면 이동·탭 동기화·모바일 버튼 위치·사례 snapshot 불변 PASS. 전체 동적 메시지 번역을 검증한 것은 아니다.
- [실제 데모 브라우저 검사](evidence/ui-language-live-browser.json): 동일 항목 PASS. 8093에 배포했고 한국어 메인 화면과 모바일 버튼 위치를 확인했다. 3D 뷰어 내부 문구는 별도 번역 작업이 남아 있다.

외부 번역 서비스나 외부 웹 자산을 사용하지 않는다. 상태 판정 PASS / FAIL / UNKNOWN / NOT RUN은 검사 기록과 동일한 코드를 유지한다.

합성 후보·구간 미리보기·경계 주석·사례 데이터 패널과 출처 설명의 번역을 데모에 반영했다. [초기 화면 잔여 문구 점검](evidence/ui-language-gap-audit.json)은 접힌 패널과 비동기 경계 초안 로딩을 포함한다. 영어 화면의 잔여 한국어는 메인/작업창 모두 0개다. 한국어 메인 화면에는 명칭·ID·ESTIMATED 표기를 유지한 추정 혈관 항목 21개가 영어로 남고, 작업창 초기 화면은 0개다. 모든 편집·오류 분기를 전수 검증한 수치는 아니다. 실제 데모의 언어 전환·저장·탭 동기화·편집 오류/성공·Atlas 안내 회귀도 PASS다.

합성 후보의 통합 표면·반경 편집·경동맥 결합·원본/보정 비교·주변 프로파일 검사 안내를 번역했다. [후보 안내 검사](evidence/candidate-language.json)는 실제 설명 생성 함수의 9가지 경로에 합성 검사값을 입력해 실행했다. 영어에 한국어 잔여 문구가 없고 한국어 왕복 시 원문이 정확히 복원되며 배율·경로 수·검사 코드가 유지된다. 실제 후보 형상의 수용 검사나 배포 후 화면 검증을 대신하지 않는다. 이 추가 후보 문구의 데모 배포는 남아 있다.

앱이 작성한 3D 모델 안내는 서버의 원문을 상태 응답으로 전달하고 화면의 모델 정보 영역에서 탭 언어에 맞춰 표시한다. 뷰어에 중복 표시하던 공유 안내는 숨겼다. Atlas·독립 참조·개략 모델 안내의 번역을 추가했다. 형상과 서버의 안내 원문을 바꾸지 않으며, Viser 자체의 장치/렌더링 경고는 이 번역 범위에 포함하지 않는다. 합성 후보별 상세 안내 문구는 추가 점검이 필요하다.

[상태·화면 회귀 23개 PASS](evidence/scene-language-workspace-tests.xml). 실제 데모 검사에서도 편집 실패·완료 문구와 Atlas 모델 안내의 양방향 전환, source/generation/안내 원문 불변을 확인했다. 초기 3D 로딩 직후 클릭 검사가 제한 시간에 걸려 안내 데이터 준비를 기다리는 순서로 보완했으며 재검사 PASS다. 이 기록은 3D 렌더링 성능을 보증하지 않는다.

편집 진행·완료·허용 이동 초과 오류와 사례 보존 안내의 동적 번역을 추가했다. 별도 최신 UI 자산과 실제 편집 API를 이용한 브라우저 검사에서 영어 오류 → 한국어 오류 전환, 정상 편집 결과의 양방향 전환, 실패 시 사례 보존을 확인했다. 작은 합성 사례의 기본 고정 거리가 전체 경로를 덮어 오류를 유발하지 않는 테스트 조건은 고정 거리 0.1 mm·전이 거리 1 mm로 수정했다. 이 추가 동적 번역의 실제 데모 배포와 전체 서버 오류·3D 내부 문구 점검은 남아 있다.
