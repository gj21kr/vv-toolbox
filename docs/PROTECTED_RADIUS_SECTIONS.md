# 보정 표면의 저장 반경 대조

## 판정

**FAIL — 기존 저장 반경을 보정 표면의 원형 단면 반경으로 사용할 근거가 없다.**

보정 후보 8개의 실제 저장 PLY에서, 원본 및 평활화 중심선의 내부 525개 station마다 저장 반경의 원을 만들고 원주 64점을 검사했다. 모든 station에서 외부 표본을 검출했다.

| 중심선 | 실패 단면 | 외부 표본 / 전체 표본 | 모호 표본 | 최대 외부 표본–표면 거리 |
|---|---:|---:|---:|---:|
| 원본 | 525 / 525 | 27,087 / 33,600 | 0 | 0.512167 mm |
| 평활화 | 525 / 525 | 29,074 / 33,600 | 0 | 0.573170 mm |

표본 거리는 해당 외부 표본에서 가장 가까운 삼각형까지의 거리이며 연속 표면 전체의 최대 오차가 아니다. 원의 평면 법선은 이전–다음 중심선 점의 chord로 고정했다. 끝단은 제외했다. 비원형 단면과 중심선의 편심이 영향을 줄 수 있으며 이 검사만으로 원인을 분리하지 않는다.

중심선 전체 내부 포함 PASS와 반경 단면 FAIL은 서로 다른 검사 결과다. 저장 반경으로 표면을 재생성하거나 반경 일치를 승인하지 않는다. 다음 형상 계약에서는 실제 비원형 단면과 면적 등가 반경, 중심 기준 내접 반경을 구분해야 한다.

## 재현 및 근거

- 실행: `docker exec -e PYTHONPATH=src -w /workspace vv-annotation-ui python scripts/inspect_protected_centerlines.py --radius-sections`
- [검사 결과](evidence/protected-radius-sections.json): 사례 revision·후보 해시·단면별 전체 표본 수, 첫 외부 증거점과 최대 외부 거리 기록.
- [검사기 테스트](evidence/protected-radius-tests.xml): 원형 단면 및 전체 구간 포함 관련 14개 테스트 PASS. 실제 형상 FAIL을 상쇄하지 않는다.
- 입력 Atlas·사례·보정 PLY와 앱 표시를 변경하지 않았다.

해부학적 타당성과 연속 튜브 벽 검사는 NOT RUN이다.
