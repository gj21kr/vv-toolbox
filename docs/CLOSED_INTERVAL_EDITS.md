# 닫힌 혈관 표면의 구간 편집 후보

기존 8개 혈관의 비원형 내부 loft 편집(0.8/1.2배, 중앙 25–75% 구간)을 원본 face 연결을 가진 닫힌 표면에 투영했다. 원본 동맥 접촉면·끝단 보호 정점에 더하여, 최근접 중심선 위치가 편집 구간 밖인 원본 정점을 고정했다. 가까운 중심선 위치의 대응은 해부학적 구간 판정과 다르다.

설정은 기존 투영 조건인 최대 이동 **0.3 mm**, 보호 정점에서 **3개 이웃 링**의 전이로 고정했다. 실패 후 조건을 완화하지 않았다.

| 결과 | 조건 수 | 근거 |
|---|---:|---|
| 후보 생성 | 14 | 저장 후 보호 정점 정확 일치, 자기 접촉 검출 0 |
| 거부 | 2 | 좌우 FJ1692:e0의 0.8배 조건이 이동 한도 초과 |

생성 후보의 최대 이동은 0.289812 mm이며 모두 실제 이동 정점이 존재한다. 자기 접촉 검사는 실제 저장 PLY를 재로드하고 정확한 좌표 중복 index만 정리한 검사 사본에서 수행했다. 원본 삼각형 연결과 보호 좌표는 유지한다.

## 한계와 다음 검사

투영과 보호 전이 때문에 실제 단면 배율이 목표 배율에 정확히 일치한다고 주장하지 않는다. **실제 단면 변화량은 NOT RUN**이다. 원본 접촉면 고정만으로 새로운 주변 접촉의 부재를 증명할 수 없으며 주변 혈관 검사도 NOT RUN이다.

14개는 편집 승인 사례가 아닌 후보이며 앱·전체 사례에 적용하지 않았다. 두 실패는 결과에서 제외하거나 성공으로 바꾸지 않고 보존했다.
