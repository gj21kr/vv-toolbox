# 원본 단면 중심을 이용한 고환동맥 합성 보정 후보

우측 고환동맥 FJ3617:e0의 Z 870–890 mm 구간을 원본 단면의 면적 중심에
가깝게 이동한 별도 snapshot을 만들었다. Z 875–885 mm에서는 전체 변위를,
양쪽 5 mm에서는 smoothstep 가중치를 적용한다. 이 범위와 최대 허용 이동
3 mm는 실행 전에 고정했다. 반경은 축소하지 않았으며 원본 Atlas는 보존했다.

## 실제 결과

- 328개 점 중 17개 수정. 최대 이동 **1.414477 mm**.
- 수정 위치의 원본 단면 포함 검사: 보정 전 14/17, 보정 후 17/17.
- 첫 두 점·마지막 두 점 및 모든 반경 값 보존. 기존 bridge 연속성 PASS.
- 전체 고환동맥 경로와 가져온 주변 혈관의 선분 쌍을 전후 각각 **2,840,144개** 검사.
  새 경고 쌍 0개, 제거된 경고 쌍 0개. 이는 주변 간격 전체 PASS가 아니다.
- 외장골과의 전체 28,776개 선분 조합에서 최소 capsule 하한은
  **−1.768779 → −1.547037 mm**. 개선됐지만 보수적 겹침 경고는 남아 있다.

원본 단면 중심을 따르는 것만으로 전체 원형 반경 포락체의 간격이 해결되지는
않았다. 음수 하한은 실제 mesh 침투 깊이가 아니다. 국소 단면 포함 결과도
전체 경로·선분 내부의 원본 포함을 보장하지 않는다. 다음은 외장골의 비원형
단면과 양 혈관의 반경 추정 오차를 함께 검사한다. 기본 앱에는 적용하지 않았다.

## 구현과 재현

`scripts/recenter_testicular_candidate.py`가 원본 archive/mesh fingerprint와
이전 검사 revision을 확인하고, 원래 edge와 변경 규칙을 snapshot 이력에
보존한다. 출력은 `exports/synthetic-testicular-recentered/case.snapshot.json`,
revision은 `9265c1ddcdedb0af4a115dcdb1b2227dc359a12f33789f9b5561f3f135f1aaae`다.
[검사 결과](evidence/testicular-source-correction.json)에 변위와 단면 포함 여부,
전후 전체 접촉 검사 및 대상 쌍의 완전한 간격 탐색을 기록했다.

첫 실행은 2백만 선분 검사 한도에 도달해 snapshot을 저장하지 않고 종료했다.
검사 수·순서·첫 경고 기록 정책을 유지하면서 선분 bounding box 배제 계산을
벡터화했고, 명시적 한도를 2천만으로 늘려 전체 검사를 마쳤다.
단면 중심 계산과 기존 geometry 회귀 검사는 35 passed이며, 최적화의
첫 경고/검사 횟수를 무배제 전수 계산과 대조한 추가 검사도 12 passed다.
입력 불변 확인 PASS.

최종 표면 생성·충돌·시각 검토 NOT RUN. 해부학적 수용 UNKNOWN.
