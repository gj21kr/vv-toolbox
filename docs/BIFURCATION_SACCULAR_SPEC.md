# 분기부 낭상 동맥류 설계 입력

`bifurcation_saccular_spec()`은 원본 사례 revision에 연결된 수동 합성 설계 입력을 만든다. 실제 형상은 생성하지 않는다. 연결 그래프에서 열린 구간 세 개 이상이 만나는 노드를 명시하며, 모든 연결 구간의 보호 출구 거리를 입력해야 한다. 가까운 혈관을 새 연결로 추정하지 않는다.

출구 거리는 각 구간의 저장 순서와 무관하게 접합 노드에서 멀어지는 호길이로 측정한다. 중심선에서 출구 위치·접선·반경을 보간하고, 모든 출구로 열린 경로를 유지해야 한다는 조건을 기록한다. 동맥류 주머니는 병변 객체이며 새로운 해부학적 분지로 추가하지 않는다.

목 중심·평면 법선·폭 방향, 목 폭/깊이, 수직 높이, 주머니 폭/깊이, 전이 범위를 명시한다. 목은 64개 타원 표본을 사용하는 설계 윤곽이다. 부모 표면에 실제로 부착되는지, 내부 벽이 제거되는지, 모든 분지가 열려 있는지, 다른 병변과 겹치지 않는지는 `NOT RUN`이다. `geometry_status=NOT GENERATED`, `accepted_for_generation=false`를 유지한다.

```text
vv-case bifurcation-saccular-spec case.snapshot.json parameters.json
```

CLI는 설계 JSON을 출력하고 입력 사례를 변경하지 않는다. `validate_bifurcation_saccular_spec()`은 현재 사례와 입력에서 전체 명세를 다시 만들어 revision·출구·목 윤곽 변경을 거부한다.

## 부착 사전 검사

`inspect_bifurcation_attachment()`은 연결된 모든 구간의 중심선·반경 캡슐 합집합에 대해 목 윤곽 64점과 매몰 연장 윤곽 64점을 검사한다. 목 윤곽이 기존 내강 안에 있거나, 연장 윤곽이 명시한 양의 매몰 여유를 확보하지 못하면 `FAIL`이다. Atlas 원본 표면에 대한 부착 검사는 아니다.

각 보호 출구의 원판을 감싸는 구와 주머니·전이 영역의 보수적 상자 사이의 거리 하한도 기록한다. 양의 여유는 `PASS`, 겹칠 가능성은 `UNKNOWN`이다. `UNKNOWN`을 실제 충돌로 단정하지 않는다. 전체 `PASS`도 표본 필요조건만 통과했다는 의미이며, 연속 부착·분지 개통·주변 혈관 간격은 `NOT RUN`, 실제 표면은 `NOT GENERATED` 상태다.

[부착 검사 JUnit](evidence/bifurcation-attachment-tests.xml)은 합성 부착 조건 통과, 내부 목 윤곽, 떨어진 주머니, 출구 보호 영역 겹침, 강체 변환 일관성 및 입력 보존을 확인한다.

검증: [JUnit](evidence/bifurcation-saccular-spec-tests.xml). 누락/추가 혈관, 구간 밖 출구, 퇴화 방향, 작은 주머니 치수 거부, 방향 반전 및 강체 좌표 변경의 일관성, 입력 보존과 CLI 결과를 포함한다. 분기부 병변의 표면·마스크·앱 생성과 해부학적 수용은 미구현이다. 기존 단일 부모 낭상 생성기의 수용 조건을 이 입력으로 우회하지 않는다.
