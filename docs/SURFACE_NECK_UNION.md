# 비평면 목 후보의 닫힌 내강 생성

## 적응적 경계 세분화 후 우측 MCA

목 chord의 1/4·1/2·3/4 위치를 검사하고 부모 밖으로 나오는 구간에만 중간 각도의 새 표면 교차점을 추가했다. 기존 정점은 이동하지 않으며 loft와 내부 closure가 동일한 비균일 각도·정점을 사용한다. 최대 12회·512점의 계산 한도를 둔다. 이 검사는 표본 기반이며 연속적인 삼각형 충돌 판정이 아니다.

실제 FJ1692:e0는 11회 세분화 후 **64→86점**, 검사한 chord의 최대 parent field **+6.172421e−7 mm**로 기존 1e−6 mm 기준을 만족했다. 임시 폐쇄면 1,205개 정점·중점·중심 표본 검사도 통과했다. 0.15 mm, 2,515,500개 격자에서 **28,720개 정점·57,436개 삼각형**의 단일 양의 닫힌 표면과 연결된 점유 내강을 생성했다. 원본 snapshot은 불변이다.

[새 후보 근거](evidence/surface-neck-union-refined.json)는 이전 실패 [기록](evidence/surface-neck-union-inspection.json)과 별도로 저장했다. 원래 평면 neck 모델의 실패를 성공으로 바꾸지 않고, 비평면 윤곽을 사용하는 별도 생성 방법의 CANDIDATE로 관리한다.

`exports/surface-neck-union-refined/section.png`의 실제 출력 삼각형 단면을 열람했다. 주머니와 인접 부모는 한 윤곽으로 연결되며, 떨어진 부모 구간을 자른 두 번째 윤곽도 있다. 전체 3D 표면은 단일 연결 성분이다. 단면에 격자 계단 모양이 남아 접합 매끄러움 PASS로 표시하지 않는다. 재메시 후 목 치수·원본 표면 일치·주변 충돌·임상 검증·앱 적용은 아직 미완료다.

관련 검사 **14 passed, 14.83초**. 곡면 해석식 fixture에서 세분화 후 원래 64점 불변·투영 치수 보존·chord 표본 기준 통과를 검사했다.

`build_surface_neck_union`은 비평면 목 패치를 부모 내강 안쪽으로 연장하고 임시 cap을 만들어 폐쇄한다. 임시 폐쇄면의 중심·변 중간점을 부모 프로파일과 대조한 뒤, 폐쇄 sac의 winding 기반 내부 검사와 부모 프로파일 점유를 같은 목 좌표계 격자에서 합친다. marching cubes 결과를 원래 좌표로 되돌린다.

검사는 격자 경계 잘림, face-connected 내강 1개, 양의 닫힌 표면 1개를 포함한다. 이진 점유에서 생성한 표면이므로 원래 64점 목 경계는 재메시 후 정확히 보존되지 않는다. 목 치수·접합 매끄러움·삼각형 자기 교차·주변 혈관 충돌은 아직 NOT RUN이다. 이를 기존 평면 생성기의 검사 통과 결과로 대체하지 않는다.

## 실행 결과

- 원통 합성 fixture: 닫힌 단일 내강과 출력 삼각형의 중앙 단면 단일 윤곽을 확인했다. 목/loft 관련 검사와 함께 **13 passed, 14.51초**.
- 실제 우 MCA: 최초 목→anchor fan 폐쇄가 부모 밖으로 나와 거부됐다. 명시한 0.5 mm 내부 연장 ring을 추가한 폐쇄도 거부됐다.
- 정점 검사도 포함한 최종 진단에서 임시 cap 표본 **897개 중 2개**가 부모 밖이며 최대 field 값은 **+0.002823960445 mm**다. 1e−6 mm 부호 판정 기준을 완화하지 않았다. 표본 수는 연속 표면 분리 증명이 아니다.
- 실패 위치는 [근거 JSON](evidence/surface-neck-union-inspection.json)에 기록했다. 실제 Atlas의 닫힌 표면은 게시하지 않았으며 source snapshot·앱은 보존했다.

읽기 전용 추가 리뷰 후 probe index를 기록했다. 실패 index 301/652는 각각 cap triangle 36/153의 두 번째 edge midpoint다. 둘 다 첫 collar 삼각형의 rim 변이므로 원래 목 윤곽의 12–13, 51–52 구간 중점에 해당한다. 따라서 cap 깊이 변경으로 제거할 수 없고, 중간 각도에서 표면 교차를 다시 구한 shared rim 세분화가 필요하다.

재현: `PYTHONPATH=src python scripts/inspect_surface_neck_union.py`. 실패도 구조화된 기록으로 저장한다. 원본을 바꾸거나 여유 기준을 사후에 넓혀 통과시키지 않는다.
