# MCA 분지별 회전·절개 표시 검사

2026-10-20. 원본 BP3D 좌표·형상을 보존하고 좌우 M1/M2, M2/M3, M3/M4의 6개 경계군을 추가 검사했다. **정확한 경계 승인 0개, 미확인 6개**다. 검사를 수행했다는 사실과 경계 확정을 구분한다.

## 이번 검사

좌우 각각 FJ1660, FJ1694, FJ1664, FJ1718에 대응하는 8개 요소의 8개 추출 경로를 선택했다. 각 요소를 원본 M1 명칭 요소 및 insula·6개 주변 gyrus와 함께 세 방향에서 회전 표시하고, 외측 배경 삼각형을 제거한 절개 표시를 추가했다. 8장, 총 32개 시야를 생성하고 실제 그림을 확인했다. 원본 60개 OBJ와 preview의 SHA-256을 기존 검사 기록과 다시 비교했다.

절개 표시는 선택 혈관의 X 중앙값보다 외측에 중심점이 있는 배경 삼각형을 숨기는 방법이다. 실제 절단 단면, sulcus 평면 또는 새로운 조직 형상이 아니다. 검은 선은 파생 중심선이고 파랑·주황 점은 추출 순서의 양 끝이다. 혈류 방향이나 근위·원위 주석이 아니다.

## 분지별 관찰과 남은 근거

| 선택 요소 | 회전·절개 표시에서 확인한 형태 | 경계 판정에 부족한 정보 |
|---|---|---|
| FJ1660 / FJ1660M | insula 전하방에서 짧게 위쪽으로 굽는 경로. 회색 M1 요소와 인접하지만 해당 요소만으로 긴 opercular/cortical 경로가 나타나지 않는다. | M1에서 이 daughter로 이어지는 실제 접합 및 limen landmark의 위치를 함께 확정해야 한다. 가까운 요소 끝을 genu로 승인하지 않는다. |
| FJ1694 / FJ1694M | insula 하방에서 후방으로 길게 진행하며 굴곡을 보인다. FJ1660과 방향·길이가 달라 공통 X/Y/Z 평면으로 두 분지를 자를 근거가 없다. | named insular part의 끝과 circular sulcus의 실제 교차를 대응시키는 표면 landmark가 필요하다. |
| FJ1664 / FJ1664M | insula 근처에서 상방 피질까지 연속적으로 올라가는 긴 경로가 보인다. 한 source part 내부에 다른 지형 구간이 포함될 가능성을 확인하는 검사 경로다. | insula 상연 주변에서 opercular 구간으로 전환하는 곳과 더 외측 피질 출구를 각각 판독해야 한다. 그림의 gyrus 윤곽 투영을 실제 sulcus/출구로 볼 수 없다. |
| FJ1718 / FJ1718M | 짧은 굴곡 경로가 insula·temporal 배경 근처에 보이지만, 이 요소 자체만으로 원위 피질 출구까지 추적되지 않는다. | 다른 source part와의 연속성이 먼저 필요하며, 이 요소 끝을 M2/M3 또는 M3/M4로 고정할 수 없다. |

위 관찰은 본 atlas의 시각적 형상에 대한 기술이다. 46개 MCA 관련 요소 전체의 모든 daughter에 대한 개별 회전 판독은 이번 추가 검사 범위가 아니다. M3/M4는 특히 대표 경로 FJ1664/M의 상방 진행을 확인했지만 모든 cortical branch의 출구를 열거하거나 승인하지 않았다.

## 판정

- 좌우 M1/M2: 기존 4개 part-contact 탐색점은 그대로 탐색점이다. 추가 시야에서도 실제 daughter 연결과 limen/genu를 독립적으로 지정하지 못했다.
- 좌우 M2/M3: FJ1664/M을 insular→상방 전환의 추가 판독 경로로 지정했다. circular sulcus상의 혈관 교차 좌표는 미확인이다.
- 좌우 M3/M4: FJ1664/M의 외측·상방 주행은 확인했으나 opercular 출구의 정확한 점은 미확인이다. 다른 cortical branches의 개별 판독도 남아 있다.

원문 정의는 [기존 MCA 검토](MCA_BOUNDARY_REVIEW.md)의 근거를 유지한다. 분기점과 genu가 항상 같다고 가정하지 않는다. 이번 검사에서 독립 영상 또는 임상 검증은 **NOT RUN**이다.
