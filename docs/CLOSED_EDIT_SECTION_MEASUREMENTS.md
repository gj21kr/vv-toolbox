# 닫힌 편집 후보의 실제 단면 변화량

생성된 14개 후보에서 동일 중심선 위치·동일 2 mm 방향 창의 단면을 다시 추출했다. **930개 단면 모두 측정 가능**했다. 이전에 이동 한도 때문에 거부된 두 조건은 NOT RUN으로 유지했다.

비교값은 `sqrt(편집 후 단면 면적 / 원본 단면 면적)`이다. 이는 면적 등가 반경 배율이며 저장 원형 반경이나 모든 방향의 벽 이동 배율과 같지 않다.

## 결과와 판단

후보별 최대 목표 배율 절대 오차는 **0.047137–0.176138**이다. 가장 큰 차이는 좌측 ACA FJ1654M:e0, 0.8배 조건의 station 25에서 확인했다.

| 항목 | 값 |
|---|---:|
| 해당 단면 목표 배율 | 0.800494 |
| 측정 면적 등가 반경 배율 | 0.976631 |
| 절대 배율 차이 | 0.176138 |

후보가 닫혀 있고 자기 접촉이 없다는 결과만으로 요청한 크기 변화의 달성을 인정할 수 없다. 현재 보호 투영은 접촉·끝단 고정과 전이 때문에 목표 단면을 충분히 따라가지 못할 수 있다. 이는 원인에 대한 추론이며 영향 요소별 분리 실험은 하지 않았다.

이 검사는 기술적 측정으로, 관측한 오차에 맞춰 사후 허용치를 정하거나 PASS로 표시하지 않는다. 다음 편집 수용 경로에는 목표/실제 배율 비교와 미달 시 원본 유지가 필요하다. 분기 병변을 지원하려면 인접 가지를 함께 다루는 별도 편집이 필요하다.
