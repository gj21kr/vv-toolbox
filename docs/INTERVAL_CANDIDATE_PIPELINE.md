# 비원형 구간 후보 생성 경로

`build_interval_candidate`로 단면 추출 → 구간 배율 → 내부 loft → 보호 투영 → 닫힌 topology → 자기 접촉 → 실제 목표 단면 검사 순서를 연결했다.

함수는 입력을 수정하지 않고 별도 후보를 만든다. 도중에 실패하면 후보를 반환하지 않는다. 원본 face 연결, 호출자가 지정한 보호 정점과 편집 구간 밖 정점을 유지한다. 구간 밖 판정은 최근접 중심선 호길이를 사용하며 해부학적 구간 라벨과 다르다.

배율·이동 한도·단면 허용오차는 명시적 입력이다. 결과의 `interval_edit`에 설정, 실제 이동과 보호 정점 목록을 기록한다. 이전 검사 메타데이터를 복사해 통과 처리하지 않고 새 후보에서 검사한다.

## 검증

[실행 기록](evidence/interval-candidate-tests.xml): 관련 24개 테스트 PASS.

- 합성 다중 링 표면에서 실제 형상 변경과 닫힌 후보 생성.
- 원본 정점·삼각형 불변.
- 목표 단면 검사 실패 시 후보 미반환 및 원본 유지.
- 이동 한도 초과 거부.

테스트에 사용한 허용오차는 합성 fixture의 기능 검사값으로, 실제 혈관 기본값이 아니다.

## 남은 연결

후보는 활성 장면에 게시하지 않는다. `surrounding_collision=NOT RUN`을 유지한다. 전체 이웃 혈관 검사, 분기 보호 목록 연결과 앱의 적용/복원·저장 처리가 필요하다. 따라서 이 함수의 반환을 전체 편집 승인으로 사용해서는 안 된다.

## 주변 표면 접촉 검사 연결

`neighbors`와 `expected_neighbor_ids`를 함께 전달하면 후보 생성 경로가 모든 이웃 표면의 편집 전후 접촉 삼각형 쌍을 비교한다. 목록 누락·중복·자기 자신 포함 또는 검사 예산 초과는 UNKNOWN으로, 접촉 삼각형 쌍의 추가·소실은 FAIL로 처리한다. 두 경우 모두 후보 반환을 거부한다.

목록의 권위는 호출자가 제공하는 실제 장면 전체 ID 집합에 있다. 임의의 부분 목록을 전달하고 전체 장면 검사로 표시해서는 안 된다. 인자를 생략한 경우 이 검사는 실행되지 않는다.

`neighbor_surface_contacts`에 결과를 기록하되 `surrounding_collision`은 NOT RUN으로 유지한다. 표면을 교차하지 않으면서 다른 혈관 내부에 완전히 포함되는 경우는 별도의 체적 검사가 필요하기 때문이다. 원본에 이미 있던 접촉은 동일 face 쌍 보존 기준으로 비교하며 해부학적 정상 접합으로 승인하지 않는다.

[연결 검사 기록](evidence/neighbor-contact-tests.xml): 관련 10개 테스트 PASS. 신규/소실 접촉, 유지 접촉, 누락된 이웃, 예산 부족과 후보 반환 거부·원본 유지 검증. 실제 전체 Atlas 장면 연결 및 체적 검사는 미완료다.

## 분리된 표면의 완전 포함 검사

표면 접촉이 없는 이웃 조합에는 `inspect_disjoint_containment`를 추가로 적용한다. 닫힌 일관된 topology, 자기 접촉 검출 없음, 전체 표면 접촉 없음의 전제 조건을 확인한 후 모든 연결 성분마다 대표 정점의 내부 여부를 검사한다. 연결 성분은 원본 최소 face ID로 식별하여 편집 전후 포함 관계를 비교한다. 경계 근접이나 전제 미충족은 UNKNOWN이다.

새로운 완전 포함 또는 기존 포함 관계 변화는 후보 거부 사유다. 전후 경계상자가 모두 분리된 조합은 포함 불가능하므로 빠르게 제외한다. 이미 표면이 교차하는 조합의 겹침 체적 변화는 이 방법으로 검사하지 않는다. 따라서 전체 `surrounding_collision`은 여전히 NOT RUN이다.

[포함 검사 기록](evidence/disjoint-containment-tests.xml): 관련 14개 테스트 PASS. 중첩된 닫힌 표면, 여러 연결 성분 중 일부만 포함, 완전 분리, 열린 표면·접촉 표면 거부와 새 완전 포함 시 후보 거부를 확인했다. 수치적 내부 판정이며 정확 산술 증명이나 해부학적 승인으로 표시하지 않는다.
